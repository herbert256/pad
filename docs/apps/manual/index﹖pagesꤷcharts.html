Charts

{chart} draws a chart as inline SVG on the server. There is no JavaScript, so the chart prints, works where scripts do not run, and caches like any other output. A bar chart puts columns on a zero baseline; a line chart draws a line over a light wash with the last point marked.

PHP
fragments/charts_1.php 		HTML
fragments/charts_1.pad 		Result 
<?php

  $sales = [
    [ 'month' => 'Jan', 'amount' => 1200 ],
    [ 'month' => 'Feb', 'amount' =>  950 ],
    [ 'month' => 'Mar', 'amount' => 1430 ],
    [ 'month' => 'Apr', 'amount' => 1610 ]
  ];

?>
 
{chart 'bar', data='sales', label='month', value='amount',
              title='Sales per month', width=480, height=200}

Where the numbers come from

  • data='sales' - a {data} store, a sequence store, an array of the page's PHP, or a _data file of that name.
  • value= names the field with the number, label= the field for the axis. Without them the first numeric field is the value and the first other field the label.
  • sequence='fibonacci', rows=12 - the first terms of a sequence, for demo data straight away.

Sparklines

{sparkline} is a line chart the size of a word, without axes, to stand in a sentence or a table cell.

PHP
 HTML
fragments/charts_2.pad 		Result 
<p>Fibonacci grows fast: {sparkline sequence='fibonacci', rows=12}</p>

Accessible and themeable

Every chart is an image to a screen reader (role="img"), named by its title= and described by a list of its values. Each bar and point carries its own tooltip. The colours are CSS custom properties - --pad-chart-series, --pad-chart-text, --pad-chart-grid, --pad-chart-surface - set on .pad-chart, and their defaults follow the page's color-scheme, light or dark.
