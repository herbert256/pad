<h1>Types by name</h1>
<p class="lead">All 27 core tag types from A to Z.</p>

<ul class="list">
  
    <li><a class="name" href="?type/action">action:</a> <span class="about">A sequence action - reverse, sort, sum, first ... - over the terms it is given. <a class="meta" href="?groups#sequences">Sequences</a></span></li>
  
    <li><a class="name" href="?type/app">app:</a> <span class="about">A tag of the application, a file of a _tags/ directory from the page up to the root. <a class="meta" href="?groups#tags">Tags</a></span></li>
  
    <li><a class="name" href="?type/array">array:</a> <span class="about">An array of the current row or of the page, its elements the rows of the tag. <a class="meta" href="?groups#values">Values of the page</a></span></li>
  
    <li><a class="name" href="?type/bool">bool:</a> <span class="about">A boolean store - a flag set by {pad:bool}, its pair showing when it is true. <a class="meta" href="?groups#stores">Stores and data</a></span></li>
  
    <li><a class="name" href="?type/common">common:</a> <span class="about">A tag or a snippet of the shared _common application. <a class="meta" href="?groups#tags">Tags</a></span></li>
  
    <li><a class="name" href="?type/constant">constant:</a> <span class="about">A PHP constant, by its name. <a class="meta" href="?groups#values">Values of the page</a></span></li>
  
    <li><a class="name" href="?type/content">content:</a> <span class="about">A content store - a piece of template kept by {pad:content} to be shown elsewhere. <a class="meta" href="?groups#stores">Stores and data</a></span></li>
  
    <li><a class="name" href="?type/data">data:</a> <span class="about">A data store - rows kept by {format:auto} or a file of _data/ read through the format registry. <a class="meta" href="?groups#stores">Stores and data</a></span></li>
  
    <li><a class="name" href="?type/define">define:</a> <span class="about">A tag defined in the template by {pad:define} - its body the template of the tag. <a class="meta" href="?groups#tags">Tags</a></span></li>
  
    <li><a class="name" href="?type/field">field:</a> <span class="about">A field of the current row, or a variable of the page. <a class="meta" href="?groups#values">Values of the page</a></span></li>
  
    <li><a class="name" href="?type/flag">flag:</a> <span class="about">Every term a 1 or a 0: whether it belongs to the sequence type named. <a class="meta" href="?groups#sequences">Sequences</a></span></li>
  
    <li><a class="name" href="?type/function">function:</a> <span class="about">A pipe function used as a tag, over the content between its tags. <a class="meta" href="?groups#tags">Tags</a></span></li>
  
    <li><a class="name" href="?type/include">include:</a> <span class="about">A snippet of the application, a file of an _include/ directory. <a class="meta" href="?groups#tags">Tags</a></span></li>
  
    <li><a class="name" href="?type/keep">keep:</a> <span class="about">The terms that belong to the sequence type named, the others left out. <a class="meta" href="?groups#sequences">Sequences</a></span></li>
  
    <li><a class="name" href="?type/level">level:</a> <span class="about">An array field of a row of an enclosing tag, its elements the rows of the tag. <a class="meta" href="?groups#values">Values of the page</a></span></li>
  
    <li><a class="name" href="?type/local">local:</a> <span class="about">A data file of a _data/ directory, read by its file name. <a class="meta" href="?groups#stores">Stores and data</a></span></li>
  
    <li><a class="name" href="?type/macro">macro:</a> <span class="about">A tag defined in the template by {pad:macro} - its body rendered once with the options as its fields. <a class="meta" href="?groups#tags">Tags</a></span></li>
  
    <li><a class="name" href="?type/make">make:</a> <span class="about">The terms of a sequence type, made as a play - the same terms {sequence:x} gives. <a class="meta" href="?groups#sequences">Sequences</a></span></li>
  
    <li><a class="name" href="?type/pad">pad:</a> <span class="about">A built-in tag of the engine - a file of pad/tags/. <a class="meta" href="?groups#tags">Tags</a></span></li>
  
    <li><a class="name" href="?type/parm">parm:</a> <span class="about">A parameter or option of the tag around it, read by its name. <a class="meta" href="?groups#values">Values of the page</a></span></li>
  
    <li><a class="name" href="?type/php">php:</a> <span class="about">A PHP function called as a tag, its parameters the function&#039;s arguments. <a class="meta" href="?groups#tags">Tags</a></span></li>
  
    <li><a class="name" href="?type/property">property:</a> <span class="about">A property of the tag around it - its count, its current row, whether it is the first. <a class="meta" href="?groups#values">Values of the page</a></span></li>
  
    <li><a class="name" href="?type/pull">pull:</a> <span class="about">A stored sequence - the terms a {sequence:*} pushed to the store under a name. <a class="meta" href="?groups#stores">Stores and data</a></span></li>
  
    <li><a class="name" href="?type/remove">remove:</a> <span class="about">The terms that do not belong to the sequence type named. <a class="meta" href="?groups#sequences">Sequences</a></span></li>
  
    <li><a class="name" href="?type/script">script:</a> <span class="about">A shell script of a _scripts/ directory, its output the tag&#039;s. <a class="meta" href="?groups#tags">Tags</a></span></li>
  
    <li><a class="name" href="?type/select">select:</a> <span class="about">A table declared in $padSelect - its rows read from the database, joins and all. <a class="meta" href="?groups#stores">Stores and data</a></span></li>
  
    <li><a class="name" href="?type/sequence">sequence:</a> <span class="about">A sequence type of the sequence subsystem, its terms the rows of the tag. <a class="meta" href="?groups#sequences">Sequences</a></span></li>
  
</ul>
