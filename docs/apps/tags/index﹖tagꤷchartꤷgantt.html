Tags/Chart types/chart:gantt

{chart:gantt}

A row per task (label), a bar from from to to.

Chart types Either form

Syntax 

{chart:gantt data='rows', label='field', value='field'/}
{gantt data='rows', label='field', value='field'/}

Description

One of the 45 chart types of {pad:chart}, written {chart:gantt .../}, {chart 'gantt', .../}, {gantt ...}, bare, when no tag, field or store has the name.

A row per task (label), a bar from from to to - dates, or plain numbers when all are; color colours by a field with a legend, progress (0-100) draws the part done full and the rest light, mark a dashed line at a date. Options: label, from, to, color, progress, mark; width= and height=, 600 x 300 unless given.

Example

From the charts application

Its example gantt/release there, with the data it draws.

Templatecharts/gantt/release.pad 
{chart 'gantt',
       data='release',
       label='work',
       from='week',
       to='weeks',
       color='team',
       title='A release in twelve weeks, by team',
       width=640,
       height=340/}
