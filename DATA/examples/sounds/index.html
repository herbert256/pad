Short sounds for a page - a chime when something is saved, a pop, a coin, a drum - each a tag of its own: a recipe in a file of pad/subs/sounds/types/ in the engine, written {sound:name/}. No audio file anywhere: the browser makes the sound from its recipe and plays it, and the server makes the same samples into the WAV file each card links.
