Tags/Chart types/chart:spiral

{chart:spiral}

A long series wound clockwise from twelve o'clock along an Archimedean spiral, period rows.

Chart types Either form

Syntax 

{chart:spiral data='rows', label='field', value='field'/}

Description

One of the 55 chart types of chart:*, written {chart:spiral data='rows', label='field', value='field'/}.

A long series wound clockwise from twelve o'clock along an Archimedean spiral, period rows (12) to a turn; each row a segment of the band in seven steps of one hue, the scale below; the labels of the first turn around the outside, turn names each turn where it begins. Options: label, value, period, turn; width= and height=, 480 x 420 unless given.

Example

From the charts application

Its example time/icecream there, with the data it draws.

Templatecharts/time/icecream.pad 
{chart:spiral data='icecream',
       label='month',
       value='sales',
       turn='year',
       title='Ice cream sold per month over five years, in thousands',
       width=480,
       height=440/}
PHPtime/icecream.php 
<?php

  // Five years of ice cream, in thousands sold per month: every summer a peak, every year
  // a little more, and the wet summer of 2023 a dent in the pattern.

  $icecream = [];
  $months   = [ 'Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec' ];
  $season   = [ 0.15, 0.2, 0.35, 0.55, 0.8, 1.0, 1.15, 1.1, 0.7, 0.4, 0.2, 0.3 ];

  foreach ( range ( 2021, 2025 ) as $y => $year )
    foreach ( $months as $m => $month ) {

      $sales = 100 * ( 1 + 0.08 * $y ) * $season [$m];

      if ( $year == 2023 and $m >= 5 and $m <= 7 )
        $sales *= 0.7;

      $icecream [] = [ 'year' => $year, 'month' => $month, 'sales' => (int) round ( $sales ) ];

    }

?>
