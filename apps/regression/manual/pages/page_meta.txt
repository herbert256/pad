<h2>What it can say</h2>

<ul>
  <li><code>title='Monthly report'</code> - any name that is not one of the words below becomes a variable of that name, so the wrapper's <code>&lt;title&gt;{$title}&lt;/title&gt;</code> shows it.</li>
  <li><code>layout='_layouts/print'</code> - the page is framed by that layout, as <a href="?pages/layouts">extends</a> does.</li>
  <li><code>cache=600</code> - the page's own time in the server cache, in an application that has its page cache on; <code>cache=0</code> keeps the page out of it.</li>
  <li><code>access=</code> and <code>sitemap=</code> - kept for the access rules and the sitemap to read; <code>padMeta ( 'access' )</code> answers for the page being built, <code>padMeta ( 'sitemap', 'reports/monthly' )</code> reads another page's file.</li>
</ul>

<h2>When it is read</h2>

<p>The tag is read while the page is assembled: after the PHP of <code>_inits.php</code> and of the page itself, before anything renders - so it has the last word over a <code>$title</code> the PHP set, and its values may use the PHP's variables. It must stand directly in the page's own template; the tag itself prints nothing. The cache time is read from the file before the cache is looked in, so there only plain values count.</p>
