Types/Subsystems/pattern:

pattern:

A pattern, a file of pad/subs/images/patterns/types/ - a seeded SVG background, never bare.

Subsystems Type prefix required

Syntax 

{pattern:topography seed=7/}
{pattern:topography seed=7/}

Description

A seeded SVG background or piece of generative art, the kind the tag names - the pattern subsystem in PAD/subs/images/patterns/ draws it, the same bytes for the same options. 

{pattern:topography seed=7, levels=16/}
{pattern:dots size=24, as='url'/}

Resolution: a PHP file PAD/subs/images/patterns/types/<name>.php (padPatternKinds () in PAD/lib/pattern.php) that answers its default size and colours, its own options and the function that draws it: the files there are the patterns, and a pattern is added by adding its file. The type is only ever written with its prefix - a pattern's name alone (dots, grid, waves) is no tag, the names being those of fields and pages as well.

The handler

pad/types/pattern.php: pattern:kind selects a registered kind from its subsystem. The type handler runs the subsystem with the kind in the tag name and its own parameters unchanged.

Available names

26 of them, each with its page in the tags application.
