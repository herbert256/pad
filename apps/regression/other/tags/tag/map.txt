<p><code>{map}</code> draws countries filled by a value of their row - a choropleth - as
inline SVG on the server (the map subsystem in <code>pad/subs/maps/</code>), from Natural Earth's
outlines kept in PAD itself: no JavaScript, no map tiles, no remote service. The first
parameter picks the view, a file of <code>pad/subs/maps/types/</code>: the whole world, or a crop of
the same projection at full detail for a continent or a region. A region that is a list of
countries - <code>eu</code>, <code>benelux</code>, <code>middle-east</code> - draws the
countries around it quieter and without values, and names a value of theirs in the title as
one it does not show. An unknown view is an error under the strict check.</p>

<p>A view of a country's states or provinces - <code>us-states</code>,
<code>nl-provinces</code>, <code>de-states</code>, <code>au-states</code> - draws regions in
place of countries, from Natural Earth's admin-1 outlines in a file of its own, in the
projection that suits the country: the fifty states in Albers USA, Alaska, Hawaii and Puerto
Rico moved in below; the twelve Dutch provinces and the sixteen German states each in an
equal-area projection centred on the country, its neighbours around; the states and
territories of Australia in the Australian Albers projection. There
<code>key</code> names the region by its ISO 3166-2 code, with or without the country
(<code>US-CA</code>, <code>CA</code>), or by its name, in English or the country's own
(<code>Noord-Holland</code>), and the title reads <code>by state</code> or <code>by
province</code>.</p>

<p>The rows come from <code>data=</code> as for <a href="?tag/chart">{chart}</a>, or from the
content of the pair - JSON, YAML, XML or CSV, read before the level walks it. <code>key</code>
names the country, written as an alpha-2 code (<code>NL</code>), an alpha-3 code
(<code>NLD</code>) or the English name; <code>value</code> the number. Rows of one country
add up. A key that is no country is not drawn but named in the title
(<code>not on the map: ...</code>), so a typo shows instead of disappearing.</p>

<p>The values are put in seven colour steps - the heatmap's <code>--pad-chart-heat-0</code> to
<code>-6</code> - with a scale under the map. <code>scale='linear'</code> spaces the steps
evenly between the lowest and highest value; <code>scale='quantile'</code> gives each step
the same number of countries, which keeps a few very large values from washing out the rest.
A country without a value is <code>--pad-map-empty</code>, and a map without any data is
drawn all in grey.</p>

<p>Every country has a <code>&lt;title&gt;</code> - <code>Netherlands: 1,234</code>, the
tooltip on hover - and the <code>&lt;desc&gt;</code> lists the values for a screen reader.
Countries too small to keep an outline at the scale drawn are shown as small diamonds. For a
single flag, see <a href="?tag/country">{country}</a>.</p>
