<p><code>{break}</code> stops a loop dead, like PHP's <code>break</code>: what is left of the
current pass after the tag is dropped, and no further row follows. It is usually written
inside an <code>{if}</code> - stop at the first row that matches. The tag prints nothing.</p>

<p>It works on rows and on conditions alike: in a data tag or a
<a href="?tag/sequence">{sequence}</a> the rows still to come are emptied, and in a
<a href="?tag/while">{while}</a> or <a href="?tag/until">{until}</a> the loop asks for no
further pass. For a stop that lets the current pass finish, use
<a href="?tag/cease">{cease}</a>; to skip one pass only, <a href="?tag/continue">{continue}</a>.</p>

<p>Without a parameter it leaves the nearest enclosing level that is not an <code>{if}</code>
or a <code>{case}</code>. A name - <code>{break 'orders'}</code>, a tag's name or its
<code>name=</code> - leaves an outer loop, and the inner loops with it; a level number or a
negative offset picks the level by position. Under the strict syntax check a name no
enclosing level has is an error.</p>
