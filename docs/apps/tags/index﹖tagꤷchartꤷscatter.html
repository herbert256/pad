Tags/Chart types/chart:scatter

{chart:scatter}

A dot per row on two numeric axes.

Chart types Either form

Syntax 

{chart:scatter data='rows', label='field', value='field'/}
{scatter data='rows', label='field', value='field'/}

Description

One of the 45 chart types of {pad:chart}, written {chart:scatter .../}, {chart 'scatter', .../}, {scatter ...}, bare, when no tag, field or store has the name.

A dot per row on two numeric axes; color colours by a field (eight groups, the rest grey), trend adds the least-squares line. Options: x, y, label, color, trend; width= and height=, 600 x 300 unless given.

Example

From the charts application

Its example scatter/athletes there, with the data it draws.

Templatecharts/scatter/athletes.pad 
{chart 'scatter',
       data='athletes',
       x='height',
       y='weight',
       label='name',
       trend,
       title='Height and weight of twelve athletes',
       width=640,
       height=360/}
