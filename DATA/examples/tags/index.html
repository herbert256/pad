PAD tags and subsystem kinds

A page for each tag of PAD, named with its type prefix - every built-in tag, {pad:if}, every kind of the subsystems, {chart:pie}, {toy:life}, {icon:star}, and every sequence type, {sequence:fibonacci}: what it does in one line, its syntax and the options that belong to it, a longer description and live examples - every result rendered by the tag it documents. The catalogue also covers every kind selected through options and helpers: formats, validation rules, providers, channels, filters, map views, calendars, languages, formulas, themes and palettes.
