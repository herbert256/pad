Tags/Chart types/chart:calendar

{chart:calendar}

A square per day, a column per week.

Chart types Either form

Syntax 

{chart:calendar data='rows', label='field', value='field'/}

Description

One of the 45 chart types of {pad:chart}, written {chart:calendar .../}, {chart 'calendar', .../}.

A square per day, a column per week (Monday first), the day's sum of value - else a count of its rows - in seven steps, an empty day in the grid colour; from the Monday before the first date to the last, or the whole year. Options: date, value, year; width= and height=, 720 x 150 unless given.

Example

From the charts application

Its example heatmap/commits there, with the data it draws.

Templatecharts/heatmap/commits.pad 
{chart 'calendar',
       data='commits',
       date='day',
       value='count',
       year=2026,
       title='Commits in 2026',
       width=720,
       height=150/}
PHPheatmap/commits.php 
<?php

  // A year of commits: none on most weekends, more mid-week, a quiet August and a busy
  // run before the release in November - the same picture every time, from a fixed seed.

  mt_srand ( 2026 );

  $commits = [];

  for ( $day = new DateTimeImmutable ( '2026-01-01' ); $day->format ( 'Y' ) == '2026'; $day = $day->modify ( '+1 day' ) ) {

    $weekday = (int) $day->format ( 'N' );
    $month   = (int) $day->format ( 'n' );
    $chance  = ( $weekday >= 6 ) ? 0.12 : ( $month == 8 ? 0.25 : 0.8 );
    $busy    = ( $month == 11 ) ? 2.2 : ( in_array ( $weekday, [ 2, 3, 4 ] ) ? 1.3 : 1 );

    if ( mt_rand () / mt_getrandmax () < $chance )
      $commits [] = [ 'day' => $day->format ( 'Y-m-d' ), 'count' => (int) round ( mt_rand ( 1, 6 ) * $busy ) ];

  }

?>
