<ul>
  <li><code>{pad:debug $name/}</code> - one value; an array is a tree to unfold, a missing name says so.</li>
  <li><code>{pad:debug}</code> - every field visible where it stands: the rows of the enclosing levels, innermost first, and the application's variables.</li>
  <li>Only a local request sees it: the command line, or this machine asking itself with nothing forwarded. Anyone else gets nothing, and <code>$padDiagnostics = FALSE</code> switches it off for every web request - the command line still gets it.</li>
</ul>
