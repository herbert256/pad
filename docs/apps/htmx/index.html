● HTML over the wire

The server renders.
htmx swaps it in.

htmx asks the server for a part of the page and puts the answer where it belongs. PAD already speaks that language: every {fragment} of a template can be asked for alone - by its name, or by the element htmx swaps - so one template serves the whole page and every piece of it.

Start with active search How PAD answers htmx 
<input name="q" hx-get="?products"
       hx-trigger="input changed delay:300ms"
       hx-target="#results">

<ul id="results">
  {fragment 'results'}
    {products}<li>{$name}</li>{/products}
  {/fragment}
</ul>

The request carries HX-Target: results; PAD answers that fragment alone.
