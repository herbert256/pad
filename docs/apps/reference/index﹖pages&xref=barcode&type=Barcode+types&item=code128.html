Reference - Barcode types - code128

App: demo - Page: barcode
PHP
barcode.php 		HTML
barcode.pad 		Result 
<?php

  $title = 'Barcodes';

  // A product list as a shop keeps it: the EAN-13 without its check digit for two of them -
  // the tag adds it - and with it for the others, where the tag checks it.

  $products = [
    [ 'name' => 'Espresso beans, 1 kg', 'ean' => '871234567890'  ],
    [ 'name' => 'Oat milk, 1 l',        'ean' => '4006381333931' ],
    [ 'name' => 'Design Patterns',      'ean' => '9780201633610' ],
    [ 'name' => 'Paper filters',        'ean' => '540123456789'  ],
  ];

  $parcel = 'PAD-2026-000042';

?>
 
<p>The <code>{pad:ignore}{barcode:auto}{/pad:ignore}</code> tag writes EAN-13, EAN-8, UPC-A and Code 128 barcodes
as inline SVG - sharp at any size and on paper, no font, no image library. A scanner or a
phone reads them straight from the screen.</p>

<h2>Products - EAN-13</h2>

<table>
  <tr><th>Product</th><th>Barcode</th></tr>
  {array:products}
  <tr>
    <td>{$name}</td>
    <td>{barcode:auto $ean, height=50/}</td>
  </tr>
  {/array:products}
</table>

<p><code>{pad:ignore}{barcode:auto $ean, height=50/}{/pad:ignore}</code> - twelve or thirteen digits are an EAN-13;
given without its check digit, the tag adds it.</p>

<h2>A shipping label - Code 128</h2>

<div class="label">
  <strong>PAD Demo Shop</strong><br>
  Parcel {$parcel}<br>
  {barcode:auto $parcel, height=70/}
</div>

<p><code>{pad:ignore}{barcode:auto $parcel, height=70/}{/pad:ignore}</code> - letters, digits and punctuation;
runs of digits are packed two to a symbol.</p>

<h2>The other types</h2>

<table>
  <tr><th>Type</th><th>Barcode</th><th>Tag</th></tr>
  <tr>
    <td>EAN-8</td>
    <td>{barcode:ean8 '9638507'/}</td>
    <td><code>{pad:ignore}{barcode:ean8 '9638507'/}{/pad:ignore}</code></td>
  </tr>
  <tr>
    <td>UPC-A</td>
    <td>{barcode:upca '03600029145'/}</td>
    <td><code>{pad:ignore}{barcode:upca '03600029145'/}{/pad:ignore}</code></td>
  </tr>
  <tr>
    <td>Bars only, in colour</td>
    <td>{barcode:auto 'PAD', height=30, scale=3, plain, color='#2e7d32'/}</td>
    <td><code>{pad:ignore}{barcode:auto 'PAD', height=30, scale=3, plain, color='#2e7d32'/}{/pad:ignore}</code></td>
  </tr>
</table>

App: regression/framework - Page: tags/a_field_inside_the_quoted_text_of_a_qr_code_or_barcode_is_encoded_as_itself
PHP
tags/a_field_inside_the_quoted_text_of_a_qr_code_or_barcode_is_encoded_as_itself.php 		HTML
tags/a_field_inside_the_quoted_text_of_a_qr_code_or_barcode_is_encoded_as_itself.pad 		Result 
<?php

  // A field inside the quoted text of {barcode:qr} or {barcode:auto} - the usual way to make a mailto:
  // or a code from a field - is encoded as the characters it holds, the same symbol as the
  // whole text in a variable gives, where the stand-ins a value travels with went into the
  // code: the @ of the address scanned as U+E040, and a , refused a Code 128.

  $email = 'herbert@example.com';
  $sku   = 'A,B';

?>
 
{barcode:qr 'mailto:{$email}', size=21/}
{barcode:code128 'SKU-{$sku}', plain/}

  // no kind is a page not found.

    padAbort ( 404 );

?>

        <div class="cell-head"><span>Template</span><span class="cell-file">{$file}</span></div>
        <pre class="code"><code>{!padHtml}</code>
