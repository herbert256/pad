<p><code>{open}</code> answers PAD's stand-in for the character <code>&#123;</code>. The stand-in
travels through the rest of the rendering as plain text and is turned back into the brace when
the page is written out, so the brace can never start a tag - not even when the text around it
is handed to another tag or a pipe.</p>

<p>Together with <a href="?tag/close"><code>{close}</code></a> it writes a single brace pair
in running text, such as the name of a tag in documentation. For more than a few braces -
a script, a style block, a code sample - the <a href="?tag/ignore"><code>&#123;ignore&#125;</code></a>
pair is simpler, and in an HTML page the entity <code>&amp;#123;</code> works too.</p>

<p>Not to be confused with the <code>open=</code> option of a data tag, which writes a text
once before the first occurrence.</p>
