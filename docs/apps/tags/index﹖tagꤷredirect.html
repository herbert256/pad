{redirect}

Sends the browser to another page or address with a 302 and ends the request.

Navigation Single tags

Syntax 

{redirect 'name'}
{redirect 'orders/list', $status = 'open'}
{redirect 'https://example.com/'}

Parameters

target
A page of the application - 'orders/list', also in its ?page form, routes resolved - or an absolute http:// / https:// address.

Description

{redirect 'name'} answers the request with a 302 Found and a Location header, and ends it there: nothing after the tag runs and nothing of the page is sent. The browser then asks for the new address itself, so its address bar shows it - the pattern after a form post, where a reload must not post again.

Variables assigned on the tag - {redirect 'list', $status = 'open'} - are added to the new address's query string. A page name stays on this site and is resolved as {page} resolves one; under the strict check a plain page name that does not exist is an error, instead of a clean 302 into a 404.

An absolute http:// or https:// address is sent as written, with the assigned values added in front of any #fragment. That means a target taken from the request can leave the site: the template must check it first. padRedirect() in PHP takes page names only and never leaves the site; called without a page it goes back to the page that was asked for.

To show another page without a round trip, keeping the address, use {restart}.

Examples

After a form post

The post is handled, then the browser is sent to the list - a reload does not post again.

Templateexamples/redirect/1-after-post.src 
{if $saved}
  {redirect 'orders/list'}
{/if}

With values

Variables assigned on the tag go on the query string of the new address.

Templateexamples/redirect/2-values.src 
{redirect 'orders/list', $status = 'open', $page = 2}
{# Location: ?orders/list&status=open&page=2 #}

An absolute address

http:// and https:// addresses are sent as written - this one leaves the site.

Templateexamples/redirect/3-external.src 
{redirect 'https://example.com/help#contact', $from = 'shop'}
{# Location: https://example.com/help?from=shop#contact #}

See also

  • {restart} Abandons the page being built and renders another page in its place, in the same request.
  • {page} Renders another page of the application - its PHP and its template - in place of the tag.
  • {exit} Ends the request at once, with an empty body - the PAD way to stop instead of PHP's exit.
