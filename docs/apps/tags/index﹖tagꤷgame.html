Tags/Games/game

{game}

A little game played in the browser - 18 of them, from sudoku and a crossword to snake, reversi and a quiz.

Games Either form

Syntax 

{game 'name'/}
{game 'tictactoe', opens='computer'/}
{game:memory pairs=6/}
{sudoku 'puzzle'/}
{sudoku givens=26, seed=7/}
{sudoku 'puzzle', paper/}
{crossword} WORD: clue ... {/crossword}
{hangman} word ... {/hangman}
{quiz} question | right | wrong ... {/quiz}

Parameters

name
The game, a file of pad/games/types/: bullscows, crossword, fifteen, gomoku, hangman, hanoi, maze, memory, nim, nonogram, pegsolitaire, quiz, reversi, scramble, snake, sudoku, tictactoe, wordsearch. The game: type names it as well - {game:memory/}, or bare, {memory/}, when nothing else has the name.

Options

seed
A whole number: the shuffles, the boards and the puzzles are the same on every load. Without it the browser picks.
title
The name the game is shown under, else its own.
data
The words, the symbols or the questions of a game that takes them, from a {data} store, the page's array or a _data file - else they stand between the tags, one a line.
opens
tictactoe, gomoku, reversi, nim: you (the default) or computer.
two
Bare option, tictactoe, gomoku, reversi: two players at one screen instead of the computer.
size
gomoku (15), fifteen (4), snake (18), wordsearch: the size of the board.
height
maze: the rows of cells (12); width the columns (18).
pairs
memory: how many pairs (8).
tries
hangman: wrong letters allowed (6); bullscows: guesses allowed (10).
digits
bullscows: how long the secret number is (4).
disks
hanoi: how many discs (4).
heaps
nim: the heaps, '3, 4, 5'; misere - who takes the last match loses.
rounds
scramble: words a game (10).
speed
snake: steps a second it starts with (6); wrap lets it run off one side and on at the other.
givens
sudoku without a puzzle: how many squares the new puzzle shows (30).
paper
Bare option, sudoku and crossword: the puzzle drawn to print, no script.
solve
Bare option, sudoku: the puzzle drawn with its solution. solution does it for a crossword.
order
Bare option, quiz: the questions in the order written.

Description

{game} puts a little game on the page, played in the browser: the server checks what the game is given and writes its board, and the game's script - written once per page, with the CSP nonce - plays it. Every game is a file of pad/games/types/, with its script and its style beside it; the files there are the games there are.

A game is written three ways, the same game each time: the tag with the game's name, {game 'memory'/}; the game: type, {game:memory/}; and the bare name, {memory/}, when no tag, store, field or sequence has that name. The words of a word game, the clues of a crossword, the questions of a quiz and the picture of a nonogram stand between the tags, one a line - taken as written, so they may hold braces - or come from a store named by data=.

The board carries data-result="won" or "lost" when a game ends and sends a pad-game-end event, which a page can listen to. seed= makes a game the same on every load - the same shuffle, maze or puzzle. The colours are --pad-game-ink, -accent, -good, -bad and their like on .pad-game, light and dark.

Sudoku and crossword can also be printed: paper draws the puzzle without a script, solve - solution for the crossword - with the answers filled in.

Pairs of cards face down - turn two over at a time.

{game 'memory', pairs=6/}

A crossword

A line per word between the tags, WORD: clue - laid out on the server, played in the page.

Templateexamples/game/3-crossword.pad 
{crossword}
  ECHO: Writes a value without the sanitize chain
  PIPE: The | that hands a value to a function
  CHART: Draws a picture of numbers
  HTML: What a page is written in
{/crossword}

A quiz from the content

A question a line: the question, then the answers after a bar, the right one first.

Templateexamples/game/4-quiz.pad 
{quiz}
  Which tag repeats its content? | while | if | set
  Which sigil prints a field raw? | ! | $ | #
  What does a single tag end with? | a slash | a colon | a comma
{/quiz}
