Tags/Database/search:*

{search:*}

Site search without a search server: the rows of a collection, a data store or a page's array a query finds, ranked by BM25, each with a marked excerpt.

Database Either form

Syntax 

{pad:search 'blog', q=$q, fields='title^2, body', lang='en'}{$title} {$score} {!excerpt}@else@...{/pad:search}
{pad:search 'products', q=$q, words=20, excerpt='about'}...{/pad:search}
{pad:search 'blog', q=$q, link='url'/}

Parameters

source
A Markdown collection, _content/<name>/ - else a {pad:data} store, a page's array (a db() result) or a _data file of the name.

Options

q
The query: words (any of them), "a phrase" (required, in order), prefix*, -word and -"a phrase" (left out).
fields
The fields searched with their boosts, 'title^2, body' - a collection's default; other rows every field that holds text in any row.
lang
The language of the stop words and the stemmer: en, nl, de, fr, es, it, pt, sv, da, no (nb and nn are no), ru - the locale's, else English.
words
The length of the excerpt in words, default 30.
excerpt
The field the excerpt is cut from, default the last of fields.
link
The single tag's list: a field with the link of a hit - http(s), a page or an anchor.

Description

{pad:search 'blog', q=$q}...{/pad:search} hands over the rows of the source that the query finds, the best first: each the source's own row with $score and $excerpt added - the words around the first match, every matched word in a <mark>, escaped as {widget:excerpt} escapes it. It is HTML: print it with {!excerpt}. Nothing found is the @else@; the handling options work on the rows, first=10 for the ten best.

No search server: the first search makes an inverted index of the source and keeps it in DATA/cache/search/<app>/, made again when a file of the collection or the rows changed. Words are reduced to their stems by the language's Snowball stemmer - the files of pad/subs/search/types/: en, nl, de, fr, es, it, pt, sv, da, no, ru - and compared without their accents; stop words are skipped. The ranking is BM25, a field weighed by its boost in fields.

A query finds a row with any of its words; a "phrase" must be there in that order, prefix* stands for every word that begins so, -word leaves a row out. Written as a single tag the hits are a numbered list. padSearch gives the same rows to a page's PHP. A source that is not there, a language without a file, a fields that is no list of fields or a words that is no number is a strict error.

Search languages

Each kind has its own description and usage example:

da, de, en, es, fr, it, nl, no, pt, ru, sv

Examples

A collection searched

The books of _content/collectionBooks/ that a query finds, ranked, the matched words marked in the excerpt.

Templateexamples/search/1-collection.pad 
{pad:search 'collectionBooks', q='planets'}
  <p><b>{$title}</b> ({$year}) - score {$score}<br>{!excerpt}</p>
@else@
  <p>Nothing found.</p>
{/pad:search}
Resultopen alone

Solaris (1961) - score 0.461
A station orbits an ocean that may be thinking. a planet a mystery

Dune (1965) - score 0.434
A desert planet, a spice everyone wants and a family caught in the middle.

Phrases, prefixes, words left out

A phrase must be there, a prefix stands for every word that begins so, a minus leaves a row out.

Templateexamples/search/2-query.pad 
<ul>
  <li>"a dragon": {pad:search 'collectionBooks', q='"a dragon"'}{$title} {/pad:search}</li>
  <li>adv*: {pad:search 'collectionBooks', q='adv*'}{$title} {/pad:search}</li>
  <li>planet -spice: {pad:search 'collectionBooks', q='planet -spice'}{$title} {/pad:search}</li>
</ul>
Resultopen alone
  • "a dragon": The Hobbit
  • adv*: The Hobbit
  • planet -spice: Solaris

A page array as a list

The rows of the page - a db() result has this shape - searched in their fields, the single tag a list with links.

Templateexamples/search/3-rows.pad 
{pad:search 'products', q='walk', fields='name^2, about', link='url', words=8/}
PHPexamples/search/3-rows.php 
<?php

  $products = [
    [ 'name' => 'Rain jacket',   'about' => 'Waterproof and breathable, for walking in the rain.', 'url' => '?tag/search' ],
    [ 'name' => 'Walking boots', 'about' => 'Leather boots for long walks on rough paths.',       'url' => '?tag/search' ],
    [ 'name' => 'Sun hat',       'about' => 'A wide brim against the summer sun.',                'url' => '?tag/search' ] ];

?>
Resultopen alone
  1. Walking boots
    Leather boots for long walks on rough paths.
  2. Rain jacket
    Waterproof and breathable, for walking in the rain.

In Italian

lang='it' - Snowball's Italian stop words and stemmer: an elided article is no part of the word, a word is found in another form and without its accents.

Templateexamples/search/4-italian.pad 
{pad:data 'pagine'}
[ { "t": "Le università italiane" }, { "t": "Studiare all'università di Bologna" },
  { "t": "Un viaggio in treno" }, { "t": "Viaggiare con gli amici" } ]
{/pad:data}
<ul>
  <li>universita: {pad:search 'pagine', q='universita', lang='it'}{$t}; {/pad:search}</li>
  <li>viaggi: {pad:search 'pagine', q='viaggi', lang='it'}{$t}; {/pad:search}</li>
</ul>
Resultopen alone
  • universita: Le università italiane; Studiare all'università di Bologna;
  • viaggi: Un viaggio in treno; Viaggiare con gli amici;

In Portuguese

lang='pt' - Snowball's Portuguese stop words and stemmer, one for Portugal and Brazil: a word is found in another form, the singular by the plural.

Templateexamples/search/5-portuguese.pad 
{pad:data 'paginas'}
[ { "t": "As cidades brasileiras" }, { "t": "Uma cidade portuguesa" },
  { "t": "Informações e comunicação" }, { "t": "Viajar com os amigos" } ]
{/pad:data}
<ul>
  <li>cidade: {pad:search 'paginas', q='cidade', lang='pt'}{$t}; {/pad:search}</li>
  <li>informação: {pad:search 'paginas', q='informação', lang='pt'}{$t}; {/pad:search}</li>
</ul>
Resultopen alone
  • cidade: As cidades brasileiras; Uma cidade portuguesa;
  • informação: Informações e comunicação;

In Swedish, Danish and Norwegian

lang='sv', 'da' and 'no' - Snowball's stop words and stemmers: the definite and plural endings are no part of the word; nb and nn, Bokmål and Nynorsk, are Norwegian too.

Templateexamples/search/6-nordic.pad 
{pad:data 'sidor'}
[ { "t": "Flickorna i skolan" }, { "t": "En flicka på landet" }, { "t": "Tidningar och böcker" } ]
{/pad:data}
{pad:data 'sider'}
[ { "t": "Husene ved havet" }, { "t": "Et hus på landet" }, { "t": "Barna leker" } ]
{/pad:data}
<ul>
  <li>sv, flicka: {pad:search 'sidor', q='flicka', lang='sv'}{$t}; {/pad:search}</li>
  <li>da, huset: {pad:search 'sider', q='huset', lang='da'}{$t}; {/pad:search}</li>
  <li>nb, barn: {pad:search 'sider', q='barn', lang='nb'}{$t}; {/pad:search}</li>
</ul>
Resultopen alone
  • sv, flicka: Flickorna i skolan; En flicka på landet;
  • da, huset: Et hus på landet; Husene ved havet;
  • nb, barn: Barna leker;

In Russian

lang='ru' - Snowball's Russian stop words and stemmer: a word is found in another form, and ё is read as е, so ёлка finds елка.

Templateexamples/search/7-russian.pad 
{pad:data 'stranitsy'}
[ { "t": "Новые книги" }, { "t": "Книга о море" },
  { "t": "Ёлки в лесу" }, { "t": "Новогодняя елка" } ]
{/pad:data}
<ul>
  <li>книга: {pad:search 'stranitsy', q='книга', lang='ru'}{$t}; {/pad:search}</li>
  <li>ёлка: {pad:search 'stranitsy', q='ёлка', lang='ru'}{$t}; {/pad:search}</li>
</ul>
Resultopen alone
  • книга: Новые книги; Книга о море;
  • ёлка: Ёлки в лесу; Новогодняя елка;

See also

  • {widget:excerpt} Cuts a long text to whole words with an ellipsis, centred on the first match of search words, every match marked.
  • {pad:data} Reads a supported data format, a list or a range into a named data set for a later tag to iterate.
