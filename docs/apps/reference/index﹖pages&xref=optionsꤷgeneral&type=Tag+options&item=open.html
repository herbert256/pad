<?php

  // A field written inside the quoted title, label, alt, button, past= or tab name of these
  // tags is escaped once, as the field alone is: it arrived escaped by its sanitize step and
  // the tag escaped it again - Q&A Å was shown and read out as Q&amp;A &Aring;. Each line
  // counts the texts written right; a tab named by the field is the one active= and open=
  // name with it.

  $t = 'Q&A Å';

?>

App: sections - Page: index
PHP
index.php 		HTML
index.pad 		Result 
<?php

  // The landing page: built from the sections and the effects it shows, the theme switcher in
  // the bar above it. The numbers are the kinds the engine has (_lib/sections.php) - of the
  // sections those that are a block of their own, not the item of the sections that list.

  $title = 'Sections, effects, themes and palettes';

  $sectionCount = count ( array_filter ( sectionsKinds ( 'section' ), fn ( $one ) => $one ['kind'] != 'item' ) );
  $effectCount  = count ( sectionsKinds ( 'effect' ) );
  $themeCount   = count ( sectionsKinds ( 'theme' ) );
  $paletteCount = count ( sectionsKinds ( 'palette' ) );

  $spread = [ [ 'part' => 'Sections', 'kinds' => $sectionCount ], [ 'part' => 'Effects',  'kinds' => $effectCount  ],
              [ 'part' => 'Themes',   'kinds' => $themeCount   ], [ 'part' => 'Palettes', 'kinds' => $paletteCount ] ];

?>
 
{section:hero button='See every section', link='?sections', second='Try a theme', secondLink='?themes', note='Every block of this page is a tag - its template is on the page of its kind.'}
  {pad:slot 'eyebrow'}{effect:shimmer}Sections · effects · themes · palettes{/effect:shimmer}{/pad:slot}
  {pad:slot 'title'}Dress a page in {effect:gradient animate, repeat='forever', duration=8}minutes{/effect:gradient}{/pad:slot}
  Landing-page blocks in pure CSS, motion that stands still for whoever asks for less, the colours
  of every page swapped by a theme, and colour scales a chart takes with one word.
  {pad:slot 'image'}{chart:donut data='spread', label='part', value='kinds', palette='okabe-ito', title='The kinds in the box'/}{/pad:slot}
{/section:hero}

{section:stats title='In the box', align='center'}
  {section:item $sectionCount, label='Sections'}{effect:typewriter speed=20}hero to footer{/effect:typewriter}{/section:item}
  {section:item $effectCount, label='Effects'}CSS first, one script{/section:item}
  {section:item $themeCount, label='Themes'}every one WCAG AA{/section:item}
  {section:item $paletteCount, label='Palettes'}for every chart{/section:item}
{/section:stats}

{effect:reveal}
{section:features title='Four subsystems, one look', eyebrow='What is here', columns=2}
  They share the frame's palette, so a theme colours them all at once.
  {section:item 'Sections', icon='layout', link='?sections'}A hero, the features, the prices, the questions, a footer - {effect:highlighter}no script at all{/effect:highlighter}, laid out by container queries.{/section:item}
  {section:item 'Effects', icon='sparkle', link='?effects'}A typewriter, a marker, a count-up, a reveal on scroll, loaders and confetti - still and whole under reduced motion.{/section:item}
  {section:item 'Themes', icon='droplet', link='?themes'}Paper, terminal, newspaper, ocean, a high-contrast one - for a page, an application or the visitor's own choice.{/section:item}
  {section:item 'Palettes', icon='bar-chart', link='?palettes'}Viridis and its family, Okabe-Ito and Tol for every kind of colour vision, ColorBrewer's scales.{/section:item}
