Tags/Chart types/chart:ridgeline

{chart:ridgeline}

A density curve per group of label, each on a baseline of its own, stacked from the top down over one value axis.

Chart types Either form

Syntax 

{chart:ridgeline data='rows', label='field', value='field'/}

Description

One of the 55 chart types of chart:*, written {chart:ridgeline data='rows', label='field', value='field'/}.

A density curve per group of label, each on a baseline of its own, stacked from the top down over one value axis - one bandwidth for every ridge (bandwidth=, else Silverman's rule over all values), every ridge a density on one scale, never a count; overlap= the bands the tallest rises (1.5), the median a light line. Options: label, value, bandwidth, overlap; width= and height=, 600 x 400 unless given.

Example

From the charts application

Its example distribution/highs there, with the data it draws.

Templatecharts/distribution/highs.pad 
{chart:ridgeline data='days',
       label='month',
       value='celsius',
       overlap=2,
       title='The highest temperature of every day of a year, in °C, month by month',
       width=640,
       height=440/}
PHPdistribution/highs.php 
<?php

  // The highest temperature of every day of a year, in °C, made from a fixed seed: a mild
  // sea climate - around 6 in January, around 23 in July - each day the month's mean and a
  // bell of its own, wider in spring and summer, when a warm spell and a cool one take turns.

  mt_srand ( 5 );

  $bell = fn ( $mean, $sd ) => $mean + $sd * sqrt ( -2 * log ( max ( 1e-9, mt_rand () / mt_getrandmax () ) ) ) * cos ( 2 * M_PI * mt_rand () / mt_getrandmax () );

  $months = [ 'January' => [ 31, 6, 3 ],    'February' => [ 28, 7, 3.5 ], 'March'    => [ 31, 10, 3.5 ],
              'April'   => [ 30, 14, 4 ],   'May'      => [ 31, 18, 4.5 ], 'June'     => [ 30, 21, 4.5 ],
              'July'    => [ 31, 23, 4.5 ], 'August'   => [ 31, 23, 4 ],   'September' => [ 30, 19, 3.5 ],
              'October' => [ 31, 15, 3 ],   'November' => [ 30, 10, 3 ],   'December' => [ 31, 7, 3 ] ];

  $days = [];

  foreach ( $months as $month => list ( $count, $mean, $sd ) )
    for ( $day = 1; $day <= $count; $day++ )
      $days [] = [ 'month' => $month, 'celsius' => round ( $bell ( $mean, $sd ), 1 ) ];

?>
