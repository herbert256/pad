{pad:themes/} writes a switcher of the themes of pad/subs/themes/types/: a list of them, with Default first. Choosing one posts it back to the page, which keeps it in a cookie of the PAD applications - their pages are in that theme from then on, this one already: the pages built on the frame, and every page of an application that sets a $padTheme. Default takes the choice away: the application's $padTheme, or the frame's own colours.

A small script posts the form the moment a theme is chosen; without JavaScript a button does it. The list's label is there for a screen reader, not shown. The post is answered before the application runs, with a redirect back to the page, so the page's own PHP never sees it. The form writes no token of its own, so showing it or choosing starts no session, and a post from another site changes nothing; with $padCsrf on it carries the session's token as every form then does. $padTheme = FALSE turns themes off, the visitor's choice too.
