Tags/Chart types/chart:parallel

{chart:parallel}

Parallel coordinates: an upright axis per measure of value.

Chart types Either form

Syntax 

{chart:parallel data='rows', label='field', value='field'/}
{parallel data='rows', label='field', value='field'/}

Description

One of the 45 chart types of {pad:chart}, written {chart:parallel .../}, {chart 'parallel', .../}, {parallel ...}, bare, when no tag, field or store has the name.

Parallel coordinates: an upright axis per measure of value (two or more, else every numeric field), each scaled to its own round range, named on top; a line per row, coloured by color with a legend or else one lighter colour. Options: label, value, color; width= and height=, 600 x 400 unless given.

Example

From the charts application

Its example relations/cars there, with the data it draws.

Templatecharts/relations/cars.pad 
{chart 'parallel',
       data='cars',
       label='model',
       value='mpg, cylinders, horsepower, weight, acceleration, year',
       color='origin',
       title='Thirty-two cars of the seventies, six measures each',
       width=680,
       height=400/}
