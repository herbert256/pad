Every PAD type

A tag has a type, the prefix before the colon: {pad:if} is a built-in tag, {chart:pie} a chart type, {field:name} a field of the row, {sequence:fibonacci} a sequence. Every named tag must include its type prefix, on both halves of a pair. Variable and expression shorthand, such as {$name}, stays available. Each type has its syntax, available names and live examples. The options and helpers group lists subsystem kinds selected through parameters or PHP helpers.
