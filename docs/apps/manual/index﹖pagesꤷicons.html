Icons

{icon} writes an interface icon of PAD's own set - 202 of them, drawn on a 24 by 24 grid as lines in the colour of the text around it, written as inline SVG. Beside text an icon is decoration that a screen reader skips; alone in a button or a link it gets label= and is read out by that name.

PHP
 HTML
fragments/icons_1.pad 		Result 
<button type="button">{icon 'download', size=16/} Download</button>
<button type="button">{icon 'cog', size=16, label='Settings'/}</button>

An icon is a file

Every icon is a file of pad/icons/types/, <name>.svg - a whole SVG that a browser shows as it is - and the files there are the icons there are. The icon type writes one by its name, {icon:cloud-upload/}; the names are never used alone, as they are the names of fields and pages too. size= and stroke= are the size in pixels and the width of the lines.

PHP
 HTML
fragments/icons_2.pad 		Result 
{icon:cloud-upload size=32/} {icon:chart-pie size=32/} {icon:thumb-up size=32, stroke=1.5/}
  • padIconNames () lists the icons for a page's PHP, and the showcase draws every icon by its name.
  • Each icon has the classes pad-icon pad-icon-<name> for styling.
  • A name that is no icon is an error under the strict check, which names the icons close to it.
