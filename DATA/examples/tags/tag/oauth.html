{widget:oauth 'github'/} is the link that starts a login at GitHub, styled as a button with the provider's name - and its icon, when the icon set has one of its name. It goes to the page oauth/github of the application unless href= names another: one page, oauth/[provider].php, serves every provider - padOAuthStart ( $provider ) sends the visitor off with a state, a PKCE challenge and (OpenID Connect) a nonce kept in the session, and on the way back padOAuthUser ( $provider ) checks the state, exchanges the code, checks the id_token and answers the user for padLogin.

The button reads no setting and makes no request; the page it links to needs the client id and secret - GITHUB_CLIENT_ID and GITHUB_CLIENT_SECRET in .env. An unknown provider is an error under the strict check.
