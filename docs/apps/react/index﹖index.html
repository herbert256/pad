PAD + React

● PHP renders · React reacts

Server pages,
living islands.

PAD builds the page on the server - the data, the HTML, the routing by file name. React takes over the parts that move: an island here, a widget there, each handed its data by PAD and talking back to PAD while it runs.

See the patterns Build your own
PAD says: Hello from PAD at 03:48:15 - React takes this box over in a moment.

PHP gathers

The page's .php reads the database, a _data/ file, the session.

PAD writes

The template places the islands and hands each its props: data-props="{^field}".

React mounts

PadReact.island() finds the islands and renders a component on each.

React asks back

The same pages answer JSON, one fragment, or a post - padFormat=json, padFragment.
