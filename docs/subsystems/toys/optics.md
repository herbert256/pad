# toys: optics

`{toy:optics focal=100, second, mirror, paused/}` is a bounded paraxial ray bench.
A converging thin lens, optional diverging second lens and optional plane mirror
operate on seven rays. Focal points are marked on the axis. Source dragging and a
keyboard height slider change the geometry; Step ray, Play/Pause and Reset control
tracing. The model uses thin-lens slope changes and plane reflection, at most twelve
surface encounters per ray. It omits diffraction, aberrations, finite apertures and
material dispersion. It is distinct from the wave-interference ripples toy.
