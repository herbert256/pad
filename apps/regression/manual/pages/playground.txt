<p>Use <a href="http://localhost/pad/live/">Live</a> to run code on the PAD HTTP server, or
<a href="http://localhost/pad/wasm/">WASM</a> to run it in your browser. Both have template and
data editors, a PHP switch, and a link that transfers the editors to the other app.
Data may be JSON, YAML, XML or CSV: a record's keys become variables and a list becomes
<code>rows</code>. The address bar shares the template, data, PHP and selected mode.</p>

<p>Live combines the former Live and Playground apps. <b>Run page</b> saves a full page:
PHP, request values, forms that post back, sessions, scripts and the demo database work.
<b>Render template</b> previews through <code>padCode()</code>, and <b>Show HTML</b> displays
that preview's source. <b>open alone</b> opens a saved page in its own tab.</p>

<p>Live answers local requests only and checks a CSRF token for posts. Its template preview
has no PHP function calls from templates, request variables or database; it allows five
seconds, 64 KB of input and 256 KB of output. PHP in the data pane runs as written. The
preview frame keeps its scripts separate from the editor; full pages have their own frame.</p>

<p>WASM runs PHP in browser memory. It can use PHP data and the text formats above, but it
cannot read this server's files or demo database. The ▶ example icon opens WASM; ⚡ opens
Live. Examples that require the server keep only the Live icon. Links wait for an explicit
run. Existing Playground bookmarks redirect to WASM.</p>
