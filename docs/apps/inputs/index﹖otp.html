One-time code

A one-time code, the digits a text message or an app gives: a native text field that posts the code as it is typed - inputmode="numeric", autocomplete="one-time-code" so a phone offers the code it received - and where the script runs a box per character, the next box taking the focus as one is typed, Backspace going back, a pasted code filling them all. The code the form posts is then the hidden field the boxes fill. length= the number of characters, 6 unless given (4 to 10); letters takes letters and digits, in upper case, where the code is digits alone unless given.

The template 

{meta title='One-time code'/}
{about/}

{form 'try', class='inputs-try', error}
  {otp 'code', label='The code we sent you', rules='required|digits:6'/}
  {otp 'voucher', label='Voucher', length=8, letters/}
  <button class="inputs-send">Send</button>
{/form}
