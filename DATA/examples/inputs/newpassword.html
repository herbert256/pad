A password chosen, with a meter of its strength and a button that shows it: a native password field, autocomplete="new-password" so a password manager offers one, and where the script runs the button and the meter of how hard the password is to guess, its word said to a screen reader - weak, fair, good, strong. The meter judges length, the kinds of character and the patterns that make a password easy - a run like 1234 or abcd, a character repeated, a password everyone tries; rules= say what the server takes - 'required|min:12'. known makes it the field of a password known already - a login - with autocomplete="current-password" and no meter. A password is never refilled: it would stand in the page.
