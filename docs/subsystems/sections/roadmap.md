# sections: roadmap

`{section:roadmap title='Product roadmap', data='milestones'/}` groups title/status/date/text/link
records into planned, in-progress and released. Nested items use title and body text.
Statuses are explicit and validated. Dates are application-supplied labels (quarter,
month or day), not inferred commitments. Reuses section headings and step-list
primitives, with semantic ordered lists and a single-column narrow layout. Links and
row text use the existing section escaping rules.
