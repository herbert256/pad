# mastodon

Use `padOAuthUrl('mastodon', $options)` and `padOAuthUser('mastodon', $options)` with the same options. Configure MASTODON_URL as an HTTPS instance origin, MASTODON_CLIENT_ID and MASTODON_CLIENT_SECRET from an administrator-registered application; register the exact callback URL. Supported protocol range: Mastodon **4.3 and later**, where S256 PKCE is supported. Requests use read:accounts and `/api/v1/accounts/verify_credentials`; no dynamic registration or instance discovery. IDs always include the instance, even mastodon.social. Account data never supplies a verified email. Existing state, callback and instance checks remain active. Source: [Mastodon OAuth](https://docs.joinmastodon.org/methods/oauth/) and [account verification](https://docs.joinmastodon.org/methods/accounts/#verify_credentials). Fake-runtime fixture checks PKCE, identity separation and state/instance rejection; live login requires a configured application.
