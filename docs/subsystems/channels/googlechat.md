# googlechat

Configure GOOGLECHAT_WEBHOOK_URL with the secret URL of an existing space webhook. `padNotify($recipient, $template, $data, ['googlechat'])` sends the channel's rendered text as the native JSON text property. A per-channel `['googlechat' => ['url' => ...]]` overrides configuration; recipient data cannot select the server. Only HTTPS chat.googleapis.com space message webhooks with key and token are accepted. The secret URL participates in existing report redaction. User mention syntax is neutralized; text above 30000 bytes is rejected. HTTP errors (including 429) return failures to the existing notification/queue layer; no independent retry loop. Source: [Google Chat webhooks](https://developers.google.com/workspace/chat/quickstart/webhooks). Test: `php tests/subsystems/channel-googlechat.php`.
