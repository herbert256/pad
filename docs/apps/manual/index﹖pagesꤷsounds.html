Sounds

{sound:chime} plays a short sound - a chime when something is saved, a pop, a coin, a drum - made from a recipe: there is no audio file anywhere. There are 30 of them - every sound is a file of pad/subs/sounds/types/, and the sounds application is a soundboard of them all.

PHP
 HTML
fragments/sounds_1.pad 		Result 
{sound:chime/} {sound:coin button='Collect'/} {sound:snare/}

A button, or the elements of the page

Without target= the tag writes a real button that plays the sound, named after the sound or by button=. With target=, a CSS selector, it writes no button: the sound plays when an element the selector finds has the event on= names - click, pointerdown, hover, focus, change, input or submit. Once a sound has put the script on the page, any element with data-pad-sound="pop" plays that sound when it is clicked.

PHP
 HTML
fragments/sounds_2.pad 		Result 
<button type="button" id="saveIt">Save</button>
{sound:success on='click', target='#saveIt'/}

One recipe, the browser and the WAV file

A recipe is voices played together - sine, square, saw, triangle or noise - each with an envelope, a pitch that sweeps or steps through a few notes, and a filter. The server settles it, every note to its Hz, and both renderings read the settled recipe with the same arithmetic: the script renders the samples and plays them through WebAudio, and padSoundWav ( 'bell' ) renders them as a WAV file - the same samples, the noise from a seeded generator, so the same bytes on every request. download links that file: the page asked again with &padSound=bell.

PHP
 HTML
fragments/sounds_3.pad 		Result 
{sound:bell download/}
 bell.wav
  • A browser plays audio only after a gesture on the page: the first click or key lets the sounds play, so a sound bound to hover or focus is silent until then.
  • A toast plays a sound as it shows with sound= - {widget:toast 'Saved', sound='success'/}.
  • Without script the button is hidden and a link to the WAV stands in its place; a sound is never the only sign that something happened - the page says it too.
  • The script carries the CSP nonce and every recipe, written once per page.
