{widget} puts an interactive part on the page - tabs, an accordion, a carousel, a wizard, a lightbox, a modal, a drawer, a dropdown, a tooltip, a toast, a copy box, a poll, a breadcrumb. Every one is built on the server and works without JavaScript: radio buttons and CSS, <details>, <dialog>, the popover attribute, :target. Where a widget has a script it only makes it handier - Escape, the arrow keys, the focus - and is written once per page, with the CSP nonce. Every widget is a file of pad/widgets/types/, its functions in pad/widgets/_lib/, its style and script in pad/widgets/assets/; the files of types/ are the widgets there are.

A widget is written three ways, the same widget each time: the tag with the widget's name, {widget 'modal', 'terms'}, whose second parameter is the widget's own first; the widget: type, {widget:modal 'terms'}; and the bare name, {modal 'terms'}. The bare name comes after every other kind of tag, so a store, a field or an array of the name wins - a page's $tabs array is the data of {tabs}. Two names stay built-in tags: {copy}, as PHP has a copy() function a bare name would reach first, and {tab}, the item of the widgets that take a list of labelled parts - tabs, accordion, carousel, wizard and lightbox.

  • tabs - panels behind a row of tabs: a radio button and a label per tab, the arrow keys move between them, printed every panel shows. accordion - every item a <details>; single one open at a time. carousel - slides that scroll and snap sideways, links to the slides before and after, a dot per slide, no autoplay. wizard - steps one at a time, numbered above, Back and Next under each. lightbox - thumbnails whose picture opens large over the page.
  • modal - a <dialog> and its button, opened by the invoker commands, a script where the browser has none, or a :target link without scripting. drawer - the same along the side of the window.
  • dropdown - a menu under a button, a popover the browser opens, closes and places. tooltip - a tip on hover and focus, by CSS; Escape hides it. toast - a notice in an open <dialog> whose button closes it by an invoker command, a script where the browser has none - no form of its own, so it stands inside a form too; timeout= closes it by itself.
  • copy - a text and a copy-to-clipboard button. poll - a vote once per visitor, the results as bars. breadcrumb - the trail from home to the page, from the page's path, the lines of a pair or data=.

The colours are custom properties on .pad-<widget> - --pad-tabs-accent, --pad-toast-success ... - with light-dark() defaults, so a page of color-scheme: light dark gets the dark ones in dark mode. A name that is no widget, an option a widget does not know and a widget without what it needs - a name, a label, a tab - are errors under the strict check. The poll's examples are shown but not run: what it shows depends on the votes and the visitor's session.
