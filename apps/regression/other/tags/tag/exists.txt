<p><code>{exists $path}</code> is a plain file test: its content renders when the path is
there, and the <code>&#64;else&#64;</code> half when it is not. It is PHP's <code>file_exists</code>,
so a directory counts as well.</p>

<p>The path is used exactly as given - none of PAD's application, data or
<code>_include</code> lookups apply - so build it from the <code>APP</code> or
<code>DATA</code> constant: a relative path is read from the server's working directory.</p>

<p>Use <code>&#64;else&#64;</code> for the other half: <code>{exists}</code> does not cut an
<code>{else}</code> of its own the way <a href="?tag/if">{if}</a> and
<a href="?tag/auth">{auth}</a> do. Written alone, without content, it shows nothing either way.</p>
