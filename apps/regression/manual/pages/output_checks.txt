<p>Some mistakes only show in the finished HTML: two elements with the same id, an image
without alt text, a form field nothing labels, a link to a page that does not exist. With
<code>$padCheckOutput = TRUE</code> in <code>_config/config.php</code>, PAD reads every local
HTML response back once it has rendered and names them.</p>

<ul>
  <li>The findings appear in a panel at the end of the page, before <code>&lt;/body&gt;</code>,
      and their number in a <code>PAD-Output-Check</code> header. A page with nothing to report
      is left exactly as it was.</li>
  <li>The link check is exact: a <code>?page</code> link is broken when the router finds no
      page for it - in this application, or in the one a <code>/&lt;app&gt;/?page</code> link names.</li>
  <li>Only a local request is checked: the command line, or this machine asking itself. A
      remote visitor never sees the panel. One request can ask for it with
      <code>?page&amp;padCheckOutput</code>.</li>
  <li><code>develop/?links</code> runs the link check over the templates of every
      application at once, for every link written literally in them.</li>
</ul>
