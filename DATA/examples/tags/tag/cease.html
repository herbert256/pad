{cease} is the soft stop of a loop. The pass it stands in renders to its end - content after the tag included - and then the loop stops: every row after the current one is dropped. Compare {break}, which also drops the rest of the current pass, and {continue}, which only skips the rest of this pass and goes on.

Inside a {while} or {until}, which has no rows but re-tests its condition, {cease} lets the current pass finish and asks for no further one, whatever the condition says.

The parameter picks the loop as for the other loop-control tags: none for the nearest enclosing level that is not an {if} or {case}, a name ({cease 'orders'}, a tag's name or its name=) for an outer loop, or a level number or negative offset. Ceasing an outer loop from an inner one lets the inner loop finish its rows, and the outer loop ends after the current row. A name no enclosing level has is an error under the strict syntax check.
