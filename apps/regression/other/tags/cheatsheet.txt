<h1>Cheat sheet</h1>
<p class="lead">The syntax of every tag, by group.</p>


<section class="section" id="conditions">
  <div class="section-head"><h2>Conditions</h2></div>
  <div class="cheat">
    
    <div class="cheat-item">
      <a class="name" href="?tag/case">case</a> <span class="about">Renders the one branch whose {when} matches a value, with an {else} for none.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">case</span> value<span class="hl-brc">}</span> <span class="hl-brc">{</span><span class="hl-tag">when</span> <span class="hl-str">&#039;a&#039;</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">when</span> <span class="hl-str">&#039;b&#039;</span>, <span class="hl-str">&#039;c&#039;</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/case</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">case</span> value<span class="hl-brc">}</span> <span class="hl-brc">{</span><span class="hl-tag">when</span> <span class="hl-str">&#039;a&#039;</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">else</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/case</span><span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/false">false</a> <span class="about">The constant FALSE: its content is skipped and its @else@ part renders instead.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">false</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">false</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/false</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">false</span><span class="hl-brc">}</span> ... <span class="hl-var">@else@</span> ... <span class="hl-brc">{</span><span class="hl-tag">/false</span><span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/if">if</a> <span class="about">Renders its content only when a condition holds, with elseif and else branches.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">if</span> condition<span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/if</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">if</span> condition<span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">else</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/if</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">if</span> condition<span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">elseif</span> condition<span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">else</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/if</span><span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/ifchanged">ifchanged</a> <span class="about">Renders its content when a value differs from the previous row of the loop around it - a heading per group.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">ifchanged</span> value<span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/ifchanged</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">ifchanged</span> value, value<span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/ifchanged</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">ifchanged</span> value<span class="hl-brc">}</span> ... <span class="hl-var">@else@</span> ... <span class="hl-brc">{</span><span class="hl-tag">/ifchanged</span><span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/null">null</a> <span class="about">The constant NULL: its content is dropped, the @else@ part too, and a null= option fires.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">null</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">null</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/null</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">null</span> <span class="hl-opt">null</span>=<span class="hl-str">&#039;name&#039;</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/null</span><span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/switch">switch</a> <span class="about">Answers the next value of a rotating list on every call - striped rows without a counter.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">switch</span> <span class="hl-str">&#039;odd&#039;</span>, <span class="hl-str">&#039;even&#039;</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">switch</span> <span class="hl-str">&#039;red&#039;</span>, <span class="hl-str">&#039;green&#039;</span>, <span class="hl-str">&#039;blue&#039;</span><span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/true">true</a> <span class="about">The constant TRUE: its content renders once, as a level of its own.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">true</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">true</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/true</span><span class="hl-brc">}</span></code></pre>
    </div>
    
  </div>
</section>

<section class="section" id="loops">
  <div class="section-head"><h2>Loops and trees</h2></div>
  <div class="cheat">
    
    <div class="cheat-item">
      <a class="name" href="?tag/branch">branch</a> <span class="about">Inside a {tree}: renders its content only when the current row has children, its @else@ part for a leaf.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">branch</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">recurse</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/branch</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">branch</span><span class="hl-brc">}</span> ... <span class="hl-var">@else@</span> ... <span class="hl-brc">{</span><span class="hl-tag">/branch</span><span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/break">break</a> <span class="about">Leaves a loop at once: the rest of the current pass is dropped and no further row follows.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">break</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">break</span> <span class="hl-str">&#039;name&#039;</span><span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/cease">cease</a> <span class="about">Ends a loop gracefully: the current pass finishes, and no further row follows.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">cease</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">cease</span> <span class="hl-str">&#039;name&#039;</span><span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/continue">continue</a> <span class="about">Skips the rest of the current pass of a loop and goes on with its next row.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">continue</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">continue</span> <span class="hl-str">&#039;name&#039;</span><span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/recurse">recurse</a> <span class="about">Inside a {tree}: renders the tree&#039;s body once more for the children of the current row.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">recurse</span><span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/tree">tree</a> <span class="about">Renders a tree of rows: its body for every row, and {recurse} renders it again for the row&#039;s children.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">tree</span> <span class="hl-str">&#039;rows&#039;</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">recurse</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/tree</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">tree</span> <span class="hl-opt">data</span>=<span class="hl-str">&#039;rows&#039;</span>, <span class="hl-opt">children</span>=<span class="hl-str">&#039;items&#039;</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">branch</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">recurse</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/branch</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/tree</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">tree</span> <span class="hl-str">&#039;rows&#039;</span><span class="hl-brc">}</span> ... <span class="hl-var">@else@</span> ... <span class="hl-brc">{</span><span class="hl-tag">/tree</span><span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/until">until</a> <span class="about">Renders its content again and again until a condition becomes true.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">until</span> condition<span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/until</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">until</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/until</span> condition<span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/while">while</a> <span class="about">Renders its content again and again for as long as a condition holds.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">while</span> condition<span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/while</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">while</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/while</span> condition<span class="hl-brc">}</span></code></pre>
    </div>
    
  </div>
</section>

<section class="section" id="values">
  <div class="section-head"><h2>Variables and stores</h2></div>
  <div class="cheat">
    
    <div class="cheat-item">
      <a class="name" href="?tag/at">at</a> <span class="about">Looks a value up in a data set by a path of names and conditions - the @ notation as a tag.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">at</span> <span class="hl-str">&#039;field@store&#039;</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">at</span> <span class="hl-str">&quot;path.key=&#039;value&#039;.field@store&quot;</span><span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/bool">bool</a> <span class="about">Reduces its content or a value to TRUE or FALSE and keeps it under a name, for a later {name} to test.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">bool</span> <span class="hl-str">&#039;name&#039;</span><span class="hl-brc">}</span> expression <span class="hl-brc">{</span><span class="hl-tag">/bool</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">bool</span> <span class="hl-str">&#039;name&#039;</span>, value<span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">name</span><span class="hl-brc">}</span> ... <span class="hl-var">@else@</span> ... <span class="hl-brc">{</span><span class="hl-tag">/name</span><span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/content">content</a> <span class="about">Keeps a piece of template under a name instead of printing it, for a later {name} to render.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">content</span> <span class="hl-str">&#039;name&#039;</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/content</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">content</span> <span class="hl-str">&#039;name&#039;</span>, <span class="hl-str">&#039;text&#039;</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">content</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/content</span> <span class="hl-str">&#039;name&#039;</span><span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/count">count</a> <span class="about">Renders its content only when a named data set or page array holds at least one element.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">count</span> <span class="hl-str">&#039;name&#039;</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/count</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">count</span> <span class="hl-str">&#039;name&#039;</span><span class="hl-brc">}</span> ... <span class="hl-var">@else@</span> ... <span class="hl-brc">{</span><span class="hl-tag">/count</span><span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/data">data</a> <span class="about">Turns its content - JSON, XML, YAML, CSV, a list or a range - into a named data set for a later tag to iterate.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">data</span> <span class="hl-str">&#039;name&#039;</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/data</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">data</span> <span class="hl-str">&#039;name&#039;</span>, <span class="hl-opt">type</span>=<span class="hl-str">&#039;csv&#039;</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/data</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">data</span> <span class="hl-str">&#039;name&#039;</span>, source<span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">data</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/data</span> <span class="hl-str">&#039;name&#039;</span><span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/decrement">decrement</a> <span class="about">Takes one off a variable, starting it at -1 when it does not exist yet.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">decrement</span> <span class="hl-var">$name</span><span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/increment">increment</a> <span class="about">Adds one to a variable, starting it at 1 when it does not exist yet.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">increment</span> <span class="hl-var">$name</span><span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/set">set</a> <span class="about">Assigns one or more variables, as globals that outlive the level the tag stands in.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">set</span> <span class="hl-var">$name</span> = value<span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">set</span> <span class="hl-var">$name</span> = value, <span class="hl-var">$other</span> = value<span class="hl-brc">}</span></code></pre>
    </div>
    
  </div>
</section>

<section class="section" id="database">
  <div class="section-head"><h2>Database</h2></div>
  <div class="cheat">
    
    <div class="cheat-item">
      <a class="name" href="?tag/array">array</a> <span class="about">Runs a SQL query on the application database and repeats its content once per row.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">array</span> <span class="hl-str">&quot;* from table where ...&quot;</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/array</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">array</span> <span class="hl-str">&quot;* from orders&quot;</span>, <span class="hl-opt">name</span>=<span class="hl-str">&#039;orders&#039;</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/array</span><span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/check">check</a> <span class="about">Asks the application database whether a row exists, and renders its content only when one does.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">check</span> <span class="hl-str">&quot;table where ...&quot;</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/check</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">check</span> <span class="hl-str">&quot;users where email=&#039;x@y.z&#039;&quot;</span><span class="hl-brc">}</span> ... <span class="hl-var">@else@</span> ... <span class="hl-brc">{</span><span class="hl-tag">/check</span><span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/collection">collection</a> <span class="about">Reads a folder of Markdown files from _content/ and repeats its content once per file, the front matter as fields.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">collection</span> <span class="hl-str">&#039;name&#039;</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/collection</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">collection</span> <span class="hl-str">&#039;name&#039;</span>, <span class="hl-opt">slug</span>=<span class="hl-var">$slug</span><span class="hl-brc">}</span> ... <span class="hl-var">@else@</span> ... <span class="hl-brc">{</span><span class="hl-tag">/collection</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">collection</span> <span class="hl-str">&#039;name&#039;</span>, html<span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/collection</span><span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/field">field</a> <span class="about">Runs a SQL query on the application database and prints the single value it answers.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">field</span> <span class="hl-str">&quot;column from table where ...&quot;</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">field</span> <span class="hl-str">&quot;count(*) from orders&quot;</span>, <span class="hl-opt">name</span>=<span class="hl-str">&#039;orderCount&#039;</span><span class="hl-brc">}</span></code></pre>
    </div>
    
    <div class="cheat-item">
      <a class="name" href="?tag/record">record</a> <span class="about">Runs a SQL query on the application database and renders its content with the first row&#039;s columns as fields.</span>
      <pre class="code"><code><span class="hl-brc">{</span><span class="hl-tag">record</span> <span class="hl-str">&quot;* from table where ...&quot;</span><span class="hl-brc">}</span> ... <span class="hl-brc">{</span><span class="hl-tag">/record</span><span class="hl-brc">}</span>
<span class="hl-brc">{</span><span class="hl-tag">record</span> <span class="hl-str">&quot;* from users where id=5&quot;</span>, <span class="hl-opt">name</span>=<span class="hl-str">&#039;user&#039;</span><span class="hl-brc">}</span> ... <span class="hl-var">@else@</span> ... <span class="hl-brc">{</span><span class="hl-tag">/record</span><span class="hl-brc">}</span></code></pre>
    </div>
    
  </div>
</section>

<section class="section" id="pages">
  <div class="section-head"><h2>Pages and execution</h2></div>
  <div class="cheat">
    
    <div class="cheat-item">
