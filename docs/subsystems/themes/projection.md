# Projection

A light theme with 20px text, 1.65 line height, Verdana/Arial, underlined links and a 4px keyboard focus outline. It reuses the existing contrast theme's color values and declared 7:1 text contrast requirement. It is a presentation preset, not an automatic claim about a projector or viewing distance.

```pad
{pad:theme 'projection'/}
```

Print layout stays in the application's print stylesheet. The theme applies the same body typography inside a paired theme box.
