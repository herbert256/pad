Below example gives a sneak preview of The content tag and The data tag, 2 powerfull PAD tags.

HTML RESULT 
{pad:data 'myData'}
  ( "red", "green", "blue" ) 
{/pad:data}
{pad:content 'myContent'}
  <b> <font color="{$myData}"> Hello World </font> </b> <br>
{/pad:content}
{pad:pad data='myData', content='myContent'/}
