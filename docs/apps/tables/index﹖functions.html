Their names are written in any case. The examples read the sample sheet below as if they stood in its cell G1, and each shows what that cell shows.

Math

Function What it does Examples
ABS ABS(number) is a number without its sign.
  • =ABS(-4.5) 4.5
  • =ABS(3) 3
CEILING CEILING(number, significance) rounds a number up to a multiple of the significance: a positive number away from zero, a negative one toward zero with a positive significance and away from zero with a negative one. A positive number with a negative significance is #NUM!; a significance of 0 gives 0. It rounds the number as it shows, to its 15 digits: CEILING(2.5, 0.1) is 2.5.
  • =CEILING(2.5, 1) 3
  • =CEILING(-2.5, 2) -2
  • =CEILING(-2.5, -2) -4
  • =CEILING(C2, 0.25) 1.25
  • =CEILING(2.5, -1) #NUM!
EXP EXP(number) is e raised to the number.
  • =EXP(1) 2.718281828
  • =EXP(0) 1
FLOOR FLOOR(number, significance) rounds a number down to a multiple of the significance: a positive number toward zero, a negative one away from zero with a positive significance and toward zero with a negative one. A positive number with a negative significance is #NUM!, a significance of 0 #DIV/0! - for any number but 0, which stays 0. It rounds the number as it shows, to its 15 digits: FLOOR(0.3, 0.1) is 0.3.
  • =FLOOR(3.7, 2) 2
  • =FLOOR(-2.5, -2) -2
  • =FLOOR(-2.5, 2) -4
  • =FLOOR(2.5, -2) #NUM!
  • =FLOOR(5, 0) #DIV/0!
INT INT(number) rounds down to the whole number below - toward minus infinity, so -1.5 is -2.
  • =INT(8.9) 8
  • =INT(-1.5) -2
LN LN(number) is the natural logarithm; of 0 or less #NUM!.
  • =LN(EXP(2)) 2
  • =LN(0) #NUM!
LOG LOG(number, [base]) is the logarithm to a base, 10 when none is given. A number or a base of 0 or less is #NUM!, a base of 1 #DIV/0!.
  • =LOG(100) 2
  • =LOG(8, 2) 3
  • =LOG(10, 1) #DIV/0!
MOD MOD(number, divisor) is the remainder of a division, with the sign of the divisor: number - divisor * INT(number / divisor). A divisor of 0 is #DIV/0!.
  • =MOD(10, 3) 1
  • =MOD(-3, 2) 1
  • =MOD(3, -2) -1
  • =MOD(5, 0) #DIV/0!
MROUND MROUND(number, multiple) rounds a number to the nearest multiple of another - half away from zero. A number and a multiple of different signs are #NUM!, a multiple of 0 gives 0, and a logical value is #VALUE!, as Excel takes it. It rounds the number as it shows, to its 15 digits: MROUND(1.3, 0.2) is 1.4.
  • =MROUND(10, 3) 9
  • =MROUND(-10, -3) -9
  • =MROUND(1.3, 0.2) 1.4
  • =MROUND(5, -2) #NUM!
PI PI() is the number pi, to 15 digits 3.14159265358979.
  • =PI() 3.141592654
  • =ROUND(PI()*2, 4) 6.2832
POWER POWER(number, power) is a number raised to a power, as ^ does: 0 to the power 0 and a negative number to a fraction are #NUM!, 0 to a negative power #DIV/0!.
  • =POWER(2, 10) 1024
  • =POWER(4, 0.5) 2
  • =POWER(-8, 1/3) #NUM!
PRODUCT PRODUCT(number, ...) multiplies numbers, taken as SUM takes them: of a range only its numbers. Without any number it is 0.
  • =PRODUCT(2, 3, 4) 24
  • =PRODUCT(C2:C3) 0.96
QUOTIENT QUOTIENT(numerator, denominator) is the whole part of a division, cut toward 0 - the remainder left out, as MOD gives it for numbers of one sign. The division is taken on its 15 digits, so 0.3/0.1 is 3. A denominator of 0 is #DIV/0!.
  • =QUOTIENT(5, 2) 2
  • =QUOTIENT(4.5, 3.1) 1
  • =QUOTIENT(-10, 3) -3
  • =QUOTIENT(B4, B3) 4
  • =QUOTIENT(1, 0) #DIV/0!
RAND RAND() is a number from 0 up to 1. A spreadsheet gives another on every computation; here the number is the same for the same seed (the seed= of {sheet:grid}, 0 unless given), cell and call - a page answers the same twice, so a stored answer holds.
  • =RAND()<1 TRUE
  • =RAND()>=0 TRUE
RANDBETWEEN RANDBETWEEN(bottom, top) is a whole number from bottom to top, both included - bottom rounded up to a whole number and top down, a bottom then above the top #NUM!. Drawn as RAND draws: a spreadsheet gives another on every computation, here it is the same for the same seed (the seed= of {sheet:grid}), cell and call, so a page answers the same twice.
  • =RANDBETWEEN(1, 6)>=1 TRUE
  • =RANDBETWEEN(7, 7) 7
  • =RANDBETWEEN(1.5, 2.5) 2
  • =RANDBETWEEN(2, 1) #NUM!
ROUND ROUND(number, digits) rounds to a number of decimals, half away from zero - 2.5 is 3, -2.5 is -3; digits below 0 round to tens, hundreds. It rounds the number as it shows, to its 15 digits: ROUND(1.005, 2) is 1.01.
  • =ROUND(2.5, 0) 3
  • =ROUND(-2.5, 0) -3
  • =ROUND(1.005, 2) 1.01
  • =ROUND(1234.567, -2) 1200
ROUNDDOWN ROUNDDOWN(number, digits) rounds toward zero to a number of decimals - cuts the digits off.
  • =ROUNDDOWN(3.9, 0) 3
  • =ROUNDDOWN(-3.9, 0) -3
  • =ROUNDDOWN(3.14159, 3) 3.141
ROUNDUP ROUNDUP(number, digits) rounds away from zero to a number of decimals.
  • =ROUNDUP(3.2, 0) 4
  • =ROUNDUP(-3.2, 0) -4
  • =ROUNDUP(3.14159, 3) 3.142
SIGN SIGN(number) is 1 for a number above 0, 0 for 0 and -1 for a number below 0.
  • =SIGN(10) 1
  • =SIGN(4-4) 0
  • =SIGN(-0.00001) -1
  • =SIGN(E2) -1
SQRT SQRT(number) is the square root; of a negative number #NUM!.
  • =SQRT(16) 4
  • =SQRT(-1) #NUM!
SUM SUM(number, ...) adds up numbers. A number typed into the call counts, and so do TRUE (as 1) and a text that reads as a number; of a range only the numbers count - its text, logical values and empty cells are left out. An error among them is the answer.
  • =SUM(1, 2, 3) 6
  • =SUM(B2:B7) 58
  • =SUM("4", TRUE, B2) 15
SUMIF SUMIF(range, criteria, [sum_range]) adds up the cells of sum_range - else of range itself - where range meets the criteria: a value, or a text such as ">5", "<>Apples", "A*" (see COUNTIF). sum_range is read from its first cell at the size of range, as Excel reads it.
  • =SUMIF(A2:A7, "Apples", B2:B7) 25
  • =SUMIF(B2:B7, ">10") 35
SUMIFS SUMIFS(sum_range, criteria_range, criteria, ...) adds up the cells of sum_range where every criteria_range meets its criteria - pairs of a range and a criterion, as many as needed, each range the size of sum_range.
  • =SUMIFS(B2:B7, A2:A7, "Apples", C2:C7, ">1.15") 10
SUMPRODUCT SUMPRODUCT(array, ...) multiplies the cells of ranges place by place and adds the products up: the ranges are walked in step, row by row, so they must have as many rows and columns as one another, else #VALUE!. A cell that holds no number counts as 0 - a text, even the text "2", a logical value, an empty cell - and an error in any cell is the answer. A value typed into the call is a range of one cell by the same rule: SUMPRODUCT(3, 4) is 12, SUMPRODUCT("3", 4) is 0, SUMPRODUCT(B2:B7, 2) is #VALUE! - the sizes differ - and an error typed in is the answer at once. Excel computes an operator in the arguments on every cell of a range, SUMPRODUCT((A2:A7="Apples")*B2:B7); the formulas have no array evaluation, and such a formula is an error under the strict check and #VALUE! otherwise, never the number of one cell - SUMIFS adds up with criteria.
  • =SUMPRODUCT(B2:B7, C2:C7) 134.5
  • =SUMPRODUCT(A2:A7, B2:B7) 0
  • =SUMPRODUCT(B2:B7, C2:C6) #VALUE!
TRUNC TRUNC(number, [digits]) cuts a number to a number of decimals - none when digits is left out - toward zero, so -8.9 is -8 where INT makes it -9; digits below 0 cut to tens, hundreds. It cuts the number as it shows, to its 15 digits, as ROUNDDOWN does.
  • =TRUNC(8.9) 8
  • =TRUNC(-8.9) -8
  • =TRUNC(3.14159, 2) 3.14
  • =TRUNC(1234.567, -2) 1200

AVERAGE AVERAGE(number, ...) is the mean of numbers, taken as SUM takes them: of a range only its numbers, so an empty cell does not count as 0. Without any number #DIV/0!.
  • =AVERAGE(2, 4, 9) 5
  • =AVERAGE(B2:B7) 9.666666667
  • =AVERAGE(A2:A7) #DIV/0!
AVERAGEIF AVERAGEIF(range, criteria, [average_range]) is the mean of the cells of average_range - else of range - where range meets the criteria (see COUNTIF); without any #DIV/0!.
  • =AVERAGEIF(A2:A7, "Apples", B2:B7) 12.5
  • =AVERAGEIF(B2:B7, ">100") #DIV/0!
AVERAGEIFS AVERAGEIFS(average_range, criteria_range, criteria, ...) is the mean of the cells of average_range where every criteria_range meets its criteria - pairs of a range and a criterion (see COUNTIF), each range the size and shape of average_range, else #VALUE!. Only the numbers among those cells count; without any it is #DIV/0!.
  • =AVERAGEIFS(B2:B7, A2:A7, "Apples") 12.5
  • =AVERAGEIFS(C2:C7, B2:B7, ">5", B2:B7, "<20") 2.1
  • =AVERAGEIFS(B2:B7, A2:A7, "Kiwis") #DIV/0!
COUNT COUNT(value, ...) counts the numbers: typed into the call a number, TRUE or FALSE and a text that reads as a number count, another text and an error do not; of a range only its numbers.
  • =COUNT(B1:B7) 6
  • =COUNT(1, "2", "x", TRUE) 3
COUNTA COUNTA(value, ...) counts the values that are not empty - numbers, texts, logical values and errors, and the empty text a formula answers too.
  • =COUNTA(A1:A8) 7
  • =COUNTA(1, "x", #N/A) 3
COUNTBLANK COUNTBLANK(range) counts the empty cells of a range, and those holding the empty text a formula answers.
  • =COUNTBLANK(A1:E8) 5
COUNTIF COUNTIF(range, criteria) counts the cells of a range that meet the criteria: a value - 5, "Apples", TRUE - or a text starting with = <> < > <= or >=: ">5", "<>Apples", "<=2024-03-31". A number matches numbers and texts that read as that number; a text matches in any case, * standing for any characters and ? for one (~* for a *); "" matches empty cells, "<>" every cell that is not empty.
  • =COUNTIF(B2:B7, ">5") 4
  • =COUNTIF(A2:A7, "Apples") 2
  • =COUNTIF(A2:A7, "?e*") 1
  • =COUNTIF(A1:A8, "") 1
COUNTIFS COUNTIFS(criteria_range, criteria, ...) counts the places where every range meets its criteria - pairs of a range and a criterion (see COUNTIF), the ranges of one size.
  • =COUNTIFS(A2:A7, "Apples", B2:B7, ">10") 1
  • =COUNTIFS(B2:B7, ">0", C2:C7, "<2") 3
LARGE LARGE(array, k) is the k-th largest number; a k below 1 or past the count of numbers is #NUM!, a k that is no whole number is rounded up.
  • =LARGE(B2:B7, 2) 15
  • =LARGE(B2:B7, 7) #NUM!
MAX MAX(number, ...) is the largest of numbers, taken as SUM takes them; without any 0.
  • =MAX(4, -2, 7) 7
  • =MAX(C2:C7) 4
MAXIFS MAXIFS(max_range, criteria_range, criteria, ...) is the largest number among the cells of max_range where every criteria_range meets its criteria - pairs of a range and a criterion (see COUNTIF), each range the size and shape of max_range, else #VALUE!. Without any number there it is 0.
  • =MAXIFS(B2:B7, A2:A7, "Apples") 15
  • =MAXIFS(D2:D7, A2:A7, "Apples") 2024-04-01
  • =MAXIFS(B2:B7, A2:A7, "Kiwis") 0
MEDIAN MEDIAN(number, ...) is the middle number - of an even count the mean of the two in the middle; without any number #NUM!.
  • =MEDIAN(3, 1, 2) 2
  • =MEDIAN(B2:B7) 9
MIN MIN(number, ...) is the smallest of numbers, taken as SUM takes them; without any 0.
  • =MIN(4, -2, 7) -2
  • =MIN(B2:B7) 0
MINIFS MINIFS(min_range, criteria_range, criteria, ...) is the smallest number among the cells of min_range where every criteria_range meets its criteria - pairs of a range and a criterion (see COUNTIF), each range the size and shape of min_range, else #VALUE!. Without any number there it is 0.
  • =MINIFS(C2:C7, A2:A7, "Apples") 1.1
  • =MINIFS(B2:B7, C2:C7, ">2", B2:B7, ">0") 8
  • =MINIFS(B2:B7, A2:A7, "Kiwis") 0
PERCENTILE PERCENTILE(array, k) is PERCENTILE.INC under the name it had before Excel 2010, which Excel, LibreOffice and Google Sheets still read: the k-th percentile, k from 0 to 1, interpolated between the numbers at the place k*(n-1)+1.
  • =PERCENTILE(B2:B7, 0.3) 6.5
  • =PERCENTILE(C2:C7, 0.5) 1.725
PERCENTILE.EXC PERCENTILE.EXC(array, k) is the k-th percentile of the numbers - k above 0 and below 1, both left out. Between two numbers it interpolates: the numbers sorted, the percentile stands at the place k*(n+1) among them, and a place before the first number or past the last is #NUM!, as is a k of 0 or 1 or past them, or no number at all; a k that is no number is #VALUE!.
  • =PERCENTILE.EXC(B2:B7, 0.25) 3.75
  • =PERCENTILE.EXC(B2:B7, 0.5) 9
  • =PERCENTILE.EXC(B2:B7, 0.1) #NUM!
PERCENTILE.INC PERCENTILE.INC(array, k) is the k-th percentile of the numbers - k from 0 to 1, both included, so 0 is the smallest number and 1 the largest. Between two numbers it interpolates: the numbers sorted, the percentile stands at the place k*(n-1)+1 among them. Only the numbers of a range count; without any, or with a k below 0 or above 1, it is #NUM!, and a k that is no number #VALUE!.
  • =PERCENTILE.INC(B2:B7, 0.3) 6.5
  • =PERCENTILE.INC(B2:B7, 0.9) 17.5
  • =PERCENTILE.INC(B2:B7, 1) 20
  • =PERCENTILE.INC(B2:B7, 1.5) #NUM!
QUARTILE QUARTILE(array, quart) is QUARTILE.INC under the name it had before Excel 2010, which Excel, LibreOffice and Google Sheets still read: 0 the smallest number, 1 the first quartile, 2 the median, 3 the third quartile, 4 the largest.
  • =QUARTILE(B2:B7, 1) 5.75

QUARTILE.EXC QUARTILE.EXC(array, quart) is a quartile of the numbers, as PERCENTILE.EXC finds it at quart/4: 1 the first quartile, 2 the median, 3 the third. The quart is cut to a whole number toward 0; 0 or below, 4 or above, too few numbers to reach the quartile's place, or none, is #NUM!.
  • =QUARTILE.EXC(B2:B7, 1) 3.75
  • =QUARTILE.EXC(B2:B7, 3) 16.25
  • =QUARTILE.EXC(B2:B7, 4) #NUM!
QUARTILE.INC QUARTILE.INC(array, quart) is a quartile of the numbers, as PERCENTILE.INC finds it at quart/4: 0 the smallest number, 1 the first quartile, 2 the median, 3 the third quartile, 4 the largest. The quart is cut to a whole number toward 0; below 0 or above 4, or without a number, it is #NUM!.
  • =QUARTILE.INC(B2:B7, 1) 5.75
  • =QUARTILE.INC(B2:B7, 3) 13.75
  • =QUARTILE.INC(C2:C7, 2) 1.725
  • =QUARTILE.INC(B2:B7, 5) #NUM!

Logic

Function What it does Examples
AND AND(logical, ...) is TRUE when every value is: TRUE, a number that is not 0, the text TRUE; of a range its texts and empty cells are left out. Without any logical value #VALUE!.
  • =AND(TRUE, 1, "TRUE") TRUE
  • =AND(TRUE, 0) FALSE
IF IF(test, [then], [else]) is then when the test holds and else when it does not - FALSE when else is left out, 0 when the one chosen is left empty, IF(A1,,1). A test is a logical value, a number (0 is FALSE) or the text TRUE or FALSE; another text is #VALUE!, an error the answer.
  • =IF(5>3, "yes", "no") yes
  • =IF(1>2, "yes") FALSE
  • =IF("maybe", 1, 2) #VALUE!
IFERROR IFERROR(value, value_if_error) is the value, or the other one when it is an error - any of them.
  • =IFERROR(1/0, "none") none
  • =IFERROR(4/2, "none") 2
IFNA IFNA(value, value_if_na) is the value, or the other one when it is #N/A; another error stays.
  • =IFNA(#N/A, 0) 0
  • =IFNA(1/0, 0) #DIV/0!
IFS IFS(test, value, ...) is the value of the first test that holds - pairs of a test and a value; when none holds #N/A.
  • =IFS(1>2, "a", 2>1, "b") b
  • =IFS(FALSE, 1) #N/A
NOT NOT(logical) turns TRUE into FALSE and FALSE into TRUE - 0 is FALSE, another number TRUE.
  • =NOT(TRUE) FALSE
  • =NOT(0) TRUE
OR OR(logical, ...) is TRUE when one of the values is, read as AND reads them.
  • =OR(FALSE, 0, "TRUE") TRUE
  • =OR(FALSE, 0) FALSE
XOR XOR(logical, ...) is TRUE when an odd number of the values are TRUE, read as AND reads them.
  • =XOR(TRUE, TRUE, TRUE) TRUE
  • =XOR(TRUE, TRUE) FALSE

Function What it does Examples
FV FV(rate, nper, pmt, [pv], [type]) is what a loan or a saving is worth after nper periods of a payment pmt at a rate, starting from pv (0); type 1 pays at the start of each period. Money paid in is negative, what comes back positive.

IPMT IPMT(rate, per, nper, pv, [fv], [type]) is the interest part of the payment of period per - from 1 to nper, else #NUM! - of a loan or a saving whose payment PMT works out: rate the interest of a period, pv what it is worth now, fv at the end (0), type 1 to pay at the start of each period (0, at the end), when the first period pays no interest. The interest of a period is that of what is still owed at its start - what FV gives after the periods before it - so it shrinks as the loan is paid off. Money paid out is negative, as in Excel.
  • =ROUND(IPMT(10%/12, 1, 36, 8000), 2) -66.67
  • =ROUND(IPMT(10%, 3, 3, 8000), 2) -292.45

The values need a negative and a positive one; of a range only its numbers count.

  • =ROUND(IRR(E2:E6), 4) -0.0212

NPER NPER(rate, pmt, pv, [fv], [type]) is the number of periods a payment pmt takes to bring pv to fv (0) at a rate; type 1 pays at the start of each period. Terms that never get there are #NUM!.

  • =ROUND(NPER(1%, -100, -1000), 4) -9.5786

A rate of -100%, or one that discounts past what a float holds - (1-90%)^400 - is #NUM!.
  • =ROUND(PV(8%/12, 12*20, 500, , 0), 2) -59777.15
