# sections: careers

`{section:careers title='Join us', data='jobs'/}` accepts role, location, arrangement,
employment, text, link and button. Nested items use the first argument as role and
body as text. Application links remain normal anchors; jobs without links show
information only. All row values escape and links use the section safety filter.
Applications can independently emit `jsonld:job` when complete structured records
exist; this section does not invent salary, dates or employer metadata.
