# azure

Use `padAi('Question', ['provider' => 'azure', 'model' => 'deployment-name'])`. Configure AZURE_OPENAI_API_KEY and AZURE_OPENAI_ENDPOINT (an HTTPS resource origin on openai.azure.com or services.ai.azure.com); AZURE_OPENAI_DEPLOYMENT supplies the default model. The model is your deployment name, not a guessed public model. Supports only Azure **v1 chat completions** at `/openai/v1/chat/completions`, API-key authentication, and the existing text-in/text-out interface. Dated deployment URLs and api-version parameters are rejected; a url override must use the same v1 contract. No Entra token refresh or streaming. Source: [Microsoft API lifecycle](https://learn.microsoft.com/en-us/azure/foundry/openai/api-version-lifecycle). Regression: framework/ai/azure_uses_only_the_v1_contract (padCurlFake, no external requests).
