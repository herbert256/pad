# Additional dimensions

Duration: s, ms, µs/us, min, h, d, wk (elapsed time, fixed 24-hour days; no months).
Speed: m/s, km/h/kph, mph, kn/knot, ft/s. Pressure: Pa, kPa, MPa, bar, mbar,
atm (101325 Pa), psi. Energy: J, kJ, Wh, kWh, cal (thermochemical 4.184 J), kcal.
Power: W, kW, MW, hp (mechanical 745.6998715822702 W). Angle: rad, deg/degree/°,
turn, grad. Case-sensitive symbols and aliases remain globally unique. Existing
`padConvert` finite-range and cross-family checks apply; no expression parser.
