{pad:img} shows a picture of www/<application>/ at the size the page needs, not the size the camera made. The first time a size is asked the picture is resized with GD (tags/_lib/img.php) and kept in www/<application>/_thumbs/, where the web server sends it like any other asset; every later request just writes the tag.

It writes <img class="pad-img"> with its width and height (no layout shift while it loads), loading="lazy", decoding="async" and a srcset whose second picture is twice the size for a sharp screen - as far as the source reaches, the density then said as it is (1.5x), and left out under 1.2x. A picture is never made larger than its source, and a JPEG is turned upright by its EXIF orientation. fit='cover' fills the box and cuts around the centre; fit='contain' keeps the whole picture.

The thumbnail's file name is a hash of the picture's contents and the options, so a changed picture gets a new address (safe behind a far-future cache header) and every machine makes the same names. It is written under a temporary name and renamed into place, so two requests never see half a file.

alt is required - a picture without it is read out by its file name; alt='' says it is decoration. A missing alt, a file that is not there or is no picture, an unknown fit or format and a quality outside 1-100 are errors under the strict check. A _thumbs/ directory the web server cannot write is an error too, and the original picture is written instead. While no picture exists yet, {pad:placeholder} keeps its place.

filter= runs the picture through the filters of pad/subs/images/filters/types/, a comma list applied in the order written: grayscale, sepia, duotone, posterize, pixelate, blur, sharpen, vignette, invert, edges, threshold, solarize, autocontrast and the dithers - dither (Floyd and Steinberg), atkinson and bayer - change the picture, and the filter and its options are part of the thumbnail's name; halftone writes it as SVG dots and ascii as text in a <pre>, each named by the alt text; blurhash, thumbhash, dominant and lqip are placeholders - a BlurHash or a ThumbHash decoded to a small PNG, the dominant colour, a tiny blurred picture - behind the <img> while it loads. A pixel filter - pixelate and the dithers - is made at 1x and drawn with its pixels sharp. An unknown filter, an option out of its bounds, a filter after halftone or ascii and a placeholder beside them are errors under the strict check. The patterns application shows every filter on one picture.
