App: regression/framework - Page: tags/a_cached_section_holding_the_csrf_token_or_the_nonce_is_not_kept

<?php

  // A section whose rendering holds the visitor's CSRF token - a {input:form}, {pad:csrf}, a live
  // region - is rendered every time and never kept: the copy went to every later visitor,
  // who got the first one's token to post with on that visitor's behalf. The second section
  // of that name finds no stored copy and renders its own content. One holding the CSP
  // nonce is kept with a marker in its place, which a hit fills with the nonce of the
  // request it answers - the second section of that name is the first one's copy.

  padFragmentForget ( 'fwTokenSection' );
  padFragmentForget ( 'fwNonceSection' );

?>

App: regression/framework - Page: tags/a_cached_section_is_forgotten_by_its_vary_value_whatever_its_type

tags/a_cached_section_is_forgotten_by_its_vary_value_whatever_its_type.php 		HTML
tags/a_cached_section_is_forgotten_by_its_vary_value_whatever_its_type.pad 		Result 
<?php

  // A section kept per vary= value is forgotten by that value as code has it at hand: the
  // section rendered with vary=$userId, the integer 42, and padFragmentForget ( 'name', '42' )
  // - the same user, as the request or a database row spells it - missed, because the key
  // was made of the value's serialized type as well, and the old copy stayed.

  padFragmentForget ( 'fwVaryType', 42 );

  $userId = 42;

?>
 
{pad:cache 'fwVaryType', vary=$userId, ttl=60}first{/pad:cache}|{pad:set $forgot = php:padFragmentForget('fwVaryType', '42')/}{pad:cache 'fwVaryType', vary=$userId, ttl=60}second{/pad:cache}
