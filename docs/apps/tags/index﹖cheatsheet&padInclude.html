Cheat sheet

The syntax of every tag, by group.

Conditions

{pad:case} Renders the one branch whose {when} matches a value, with an {else} for none. 
{case value} {when 'a'} ... {when 'b', 'c'} ... {/case}
{case value} {when 'a'} ... {else} ... {/case}
{pad:false} The constant FALSE: its content is skipped and its @else@ part renders instead. 
{false/}
{false} ... {/false}
{false} ... @else@ ... {/false}
{pad:if} Renders its content only when a condition holds, with elseif and else branches. 
{if condition} ... {/if}
{if condition} ... {else} ... {/if}
{if condition} ... {elseif condition} ... {else} ... {/if}
{pad:ifchanged} Renders its content when a value differs from the previous row of the loop around it - a heading per group. 
{ifchanged value} ... {/ifchanged}
{ifchanged value, value} ... {/ifchanged}
{ifchanged value} ... @else@ ... {/ifchanged}
{pad:null} The constant NULL: its content is dropped, the @else@ part too, and a null= option fires. 
{null/}
{null} ... {/null}
{null null='name'} ... {/null}
{pad:switch} Answers the next value of a rotating list on every call - striped rows without a counter. 
{switch 'odd', 'even'/}
{switch 'red', 'green', 'blue'/}
{pad:true} The constant TRUE: its content renders once, as a level of its own. 
{true/}
{true} ... {/true}

Loops and trees

{pad:branch} Inside a {tree}: renders its content only when the current row has children, its @else@ part for a leaf. 
{branch} ... {recurse/} ... {/branch}
{branch} ... @else@ ... {/branch}
{pad:break} Leaves a loop at once: the rest of the current pass is dropped and no further row follows. 
{break/}
{break 'name'/}
{pad:cease} Ends a loop gracefully: the current pass finishes, and no further row follows. 
{cease/}
{cease 'name'/}
{pad:continue} Skips the rest of the current pass of a loop and goes on with its next row. 
{continue/}
{continue 'name'/}
{pad:recurse} Inside a {tree}: renders the tree's body once more for the children of the current row. 
{recurse/}
{pad:tree} Renders a tree of rows: its body for every row, and {recurse} renders it again for the row's children. 
{tree 'rows'} ... {recurse/} ... {/tree}
{tree data='rows', children='items'} ... {branch} ... {recurse/} ... {/branch} ... {/tree}
{tree 'rows'} ... @else@ ... {/tree}
{pad:until} Renders its content again and again until a condition becomes true. 
{until condition} ... {/until}
{until} ... {/until condition}
{pad:while} Renders its content again and again for as long as a condition holds. 
{while condition} ... {/while}
{while} ... {/while condition}

Variables and stores

{pad:at} Looks a value up in a data set by a path of names and conditions - the @ notation as a tag. 
{at 'field@store'/}
{at "path.key='value'.field@store"/}
{pad:bool} Reduces its content or a value to TRUE or FALSE and keeps it under a name, for a later {name} to test. 
{bool 'name'} expression {/bool}
{bool 'name', value/}
{name} ... @else@ ... {/name}
{pad:content} Keeps a piece of template under a name instead of printing it, for a later {name} to render. 
{content 'name'} ... {/content}
{content 'name', 'text'/}
{content} ... {/content 'name'}
{pad:count} Renders its content only when a named data set or page array holds at least one element. 
{count 'name'} ... {/count}
{count 'name'} ... @else@ ... {/count}
{pad:data} Turns its content - JSON, XML, YAML, CSV, a list or a range - into a named data set for a later tag to iterate. 
{data 'name'} ... {/data}
{data 'name', type='csv'} ... {/data}
{data 'name', source/}
{data} ... {/data 'name'}
{pad:decrement} Takes one off a variable, starting it at -1 when it does not exist yet. 
{decrement $name/}
{pad:increment} Adds one to a variable, starting it at 1 when it does not exist yet. 
{increment $name/}
{pad:set} Assigns one or more variables, as globals that outlive the level the tag stands in. 
{set $name = value/}
{set $name = value, $other = value/}

Database

{pad:array} Runs a SQL query on the application database and repeats its content once per row. 
{array "* from table where ..."} ... {/array}
{array "* from orders", name='orders'} ... {/array}
{pad:check} Asks the application database whether a row exists, and renders its content only when one does. 
{check "table where ..."} ... {/check}
{check "users where email='x@y.z'"} ... @else@ ... {/check}
{pad:collection} Reads a folder of Markdown files from _content/ and repeats its content once per file, the front matter as fields. 
{collection 'name'} ... {/collection}
{collection 'name', slug=$slug} ... @else@ ... {/collection}
{collection 'name', html} ... {/collection}
{pad:field} Runs a SQL query on the application database and prints the single value it answers. 
{field "column from table where ..."/}
{field "count(*) from orders", name='orderCount'/}
{pad:record} Runs a SQL query on the application database and renders its content with the first row's columns as fields. 
{record "* from table where ..."} ... {/record}
{record "* from users where id=5", name='user'} ... @else@ ... {/record}

Pages and execution

{pad:ajax} Writes an empty div and a script that has the browser fetch another page into it after the page has loaded. 
{ajax 'name'/}
{ajax 'name', fragment='fragmentName'/}
{ajax 'name', app='other'/}
{ajax 'name', $colour = 'red'/}
{pad:code} Runs its content as PAD source in a separate engine pass and outputs what that pass produced. 
{code} ... {/code}
{code sandbox} ... {/code}
{code reset} ... {/code}
{code clean} ... {/code}
{code function='name'} ... {/code}
{echo $snippet | code/}
{pad:get} Fetches another page of the application over HTTP, as a second request, and inserts its output. 
{get 'name'/}
{get 'name', $colour = 'red'/}
{pad:live} A region of the page that re-renders on the server when something in it is clicked, submitted or changed, and swaps itself in. 
{live 'name'} ... <button pad-click="event" pad-value="value">...</button> ... {/live}
{live 'name'} ... <form pad-submit="event">...</form> ... {/live}
{live 'name'} ... <select name="field" pad-change="event">...</select> ... {/live}
{pad:pad} A tag with no behaviour of its own: its content renders once, or per row with data=, carrying the generic options. 
{pad} ... {/pad}
{pad data='store', name='rows'} ... {/pad}
{pad $name = 'value'} ... {/pad}
{pad} ... {/pad | upper}
{pad:page} Renders another page of the application - its PHP and its template - in place of the tag. 
{page 'dir/name'/}
{page 'products/42'/}
{page 'name', include=false/}
{page 'name', sandbox/}
{page 'name', reset/}
{page 'name', clean/}
{page 'name', function='name'/}
{page 'name', app='other', ajax=false/}
{pad:restart} Abandons the page being built and renders another page in its place, in the same request. 
{restart 'name'/}
{restart 'name', $message = 'Saved'/}
{pad:sandbox} Runs its content as PAD source in an isolated pass that cannot see or leave behind anything of the page. 
{sandbox} ... {/sandbox}
{sandbox function='name'} ... {/sandbox}
{echo $snippet | sandbox/}

Navigation

{pad:pager} Page links for a tag written with the page option: first and last, a window round the current page, previous and next. 
{pager 'name'/}
{pager 'name', window=2, query='p'/}
{pager 'name'} ... {$kind} {$page} {$label} {$href} ... @else@ ... {/pager}
{pad:redirect} Sends the browser to another page or address with a 302 and ends the request. 
{redirect 'name'/}
{redirect 'orders/list', $status = 'open'/}
{redirect 'https://example.com/'/}
{pad:sitemap} Lists the pages of the application, read from the file tree, as rows with page, url and lastmod. 
{sitemap} ... {$page} {$url} {$lastmod} ... {/sitemap}
{sitemap 'dir'} ... {/sitemap}

Users and access

{auth} ... {/auth}

{auth} ... @else@ ... {/auth}
{pad:can} Renders its content when the user may do something a gate decides, and its else half when not. 
{can 'ability'} ... {/can}

{rows}{can 'ability', $rows} ... {/can}{/rows}
{pad:cannot} Renders its content when the user may not do something a gate decides - can turned round. 
{cannot 'ability', $value} ... {/cannot}
{cannot 'ability', $value} ... {else} ... {/cannot}
{pad:feature} Renders its content while a feature flag is on for this visitor, and its else half while it is off. 
{feature 'flag'} ... {/feature}
{feature 'flag'} ... {else} ... {/feature}
{pad:guest} Renders its content when nobody is logged in, and its else half for a user. 
{guest} ... {/guest}
{guest} ... {else} ... {/guest}

{exists $path} ... {/exists}

{files 'dir', base='app', onlyDirs} ... {/files}
