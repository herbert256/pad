App: regression/main - Page: errors/index
PHP
errors/index.php 		HTML
errors/index.pad 		Result 
<?php

  // Overview of the Errors suite - the tests that fail on purpose, every case an expected
  // HTTP 500 answered under the boot action: lean, deterministic, and no dump on disk.
  // Test here reruns this suite; a page load reads the last run.

  getSuitePage ( 'errors' );

?>
 
{include:suiteHead}

<p>
  Every test here fails on purpose: the strict syntax checks, the expression evaluator's
  reports, the pages that end a request, and the error handler family, each answering an
  expected <code>HTTP 500</code> asserted by a pattern over the message. The application
  declares the <code>boot</code> error action, so an expected failure is the lean JSON
  answer - no heavy error page, nothing under <code>DATA/dumps</code>, and the same shape
  for every requester. These cases live in <code>apps/regression/errors/</code>, with
  <code>_common</code> switched off.
</p>

{include:suiteTableWhat}

App: regression/main - Page: framework/index
PHP
framework/index.php 		HTML
framework/index.pad 		Result 
<?php

  // Overview of the Framework suite - the engine cases as fetched pages, one request per
  // case, each fetched directly from regression/framework. Test here reruns the suite; a page load
  // reads the last run, because running means nine hundred requests.

  getSuitePage ( 'framework' );

?>
 
{include:suiteHead}

<p>
  The engine cases as fetched pages, exactly the Pages model: every case is a triple in a
  group directory of <code>apps/regression/framework/</code> - the <code>.pad</code> its template,
  the <code>.txt</code> the outcome beside it, an optional <code>.php</code> its variables -
  and each is fetched directly as the page it is. A request per case grants each one its
  isolation by construction; the price is nine hundred requests a run, which is why Test
  runs and a page load only reads.
</p>

{include:suiteTable}

App: regression/main - Page: manual/index
PHP
manual/index.php 		HTML
manual/index.pad 		Result 
<?php

  // Overview of the Manual suite - every page of apps/manual/, fetched over HTTP one
  // request at a time and compared with the prediction of the same name in
  // apps/regression/manual/. The pages stay in their own application; the store holds
  // nothing but what each must answer. Test here reruns this suite; a page load reads the
  // last run.

  getSuitePage ( 'manual' );

?>
 
{include:suiteHead}

<p>
  Every test here is a page of the <a href="{$padHost}manual">manual</a> application,
  fetched over HTTP a dozen at a time, and compared with the prediction of the same
  name in <code>apps/regression/manual/</code>. The pages stay in their own application;
  the store holds nothing but what each must answer. An index is fetched full, everything
  else bare with <code>&amp;padInclude</code>, the same rule the harvest applies - and a page
  that draws answers a <code>/pattern/</code> pinning its skeleton, everything else an
  exact body.
</p>

{include:suiteTable}

App: regression/main - Page: pages/index
PHP
pages/index.php 		HTML
pages/index.pad 		Result 
<?php

  // Overview of the Pages suite - the regression/pages tests, the pages that run with _common
  // switched off. Every test is fetched over HTTP, against the outcome recorded beside it.
  // Test here reruns this suite; a page load reads the last run, because running means one
  // request per test. The pages that use _common are the Common suite, one menu entry along.

  getSuitePage ( 'pages' );

?>
 
{include:suiteHead}

<p>
  Every test here is an ordinary page, fetched over HTTP with
  <code>&amp;padInclude</code> so it renders bare, and compared with the outcome written beside
  it. That makes it a real request, with a page's own
  <code>.php</code> half in scope for its <code>.pad</code> half. These tests live in
  <code>apps/regression/pages/</code>, which has <code>_common</code> switched off, so each one also
  proves it needs nothing but its own application; the pages that use <code>_common</code> are
  the <a href="?common/index">Common</a> suite.
</p>

{include:suiteTableWhat}
