# widgets: imagecompare

`{widget:imagecompare before='/before.png', after='/after.png', beforelabel='Original', afterlabel='Restored'/}`
shows two labeled images without script. Enhancement overlays them and reveals the
after image to the right of a native 0–100 range divider (arrows, Home, End supported).
Use images of matching dimensions for aligned comparison. Print shows both images.
URLs pass the shared safe-link filter; supply local or HTTP(S) images and meaningful
labels. Multiple instances and fragments initialize independently.
