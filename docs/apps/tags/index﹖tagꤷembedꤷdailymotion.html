{embed:dailymotion}

A Dailymotion video: dailymotion.com/video/<id>, dai.ly/<id> and dailymotion.com/embed/video/<id>.

Embed providers Single tags

Syntax 

{embed:dailymotion 'address', title='...'/}
{dailymotion 'address', title='...'/}

Description

One of the 12 embed providers of {pad:embed}, written {embed:dailymotion 'address'/}, {embed 'address'/}, the provider known by the address, {dailymotion ...}, bare, when no tag, field or store has the name.

A Dailymotion video: dailymotion.com/video/<id>, dai.ly/<id> and dailymotion.com/embed/video/<id>; named, a bare id as well, {dailymotion 'x8j4k2c'}. at= is the moment to start at; a ?start= in the address says it too.

Example

An dailymotion embed

Nothing of the provider is asked before the click.

Template 
{embed:dailymotion 'https://www.dailymotion.com/video/x7tgad0', title='A video on Dailymotion'/}
