# effects: flipnumber

`{effect:flipnumber value='1250.50'/}` displays a canonical numeric text value.
Change the element's `data-value` to update it; decimal strings allow up to 15 integer
and 6 fractional digits. The actual accessible text always holds the complete current
value; individual animated glyphs are aria-hidden. Scriptless output remains readable.
Reduced motion skips animation. The effect never computes or rounds application data.
