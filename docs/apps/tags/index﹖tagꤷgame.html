Tags/Games/game:*

{game:*}

A little game played in the browser - 22 of them, from sudoku and a crossword to snake, reversi and a quiz.

Games Either form

Syntax 

{game:name/}
{game:tictactoe opens='computer'/}
{game:memory pairs=6/}
{game:sudoku 'puzzle'/}
{game:sudoku givens=26, seed=7/}
{game:sudoku 'puzzle', paper/}
{game:crossword} WORD: clue ... {/game:crossword}
{game:hangman} word ... {/game:hangman}
{game:quiz} question | right | wrong ... {/game:quiz}

Parameters

kind after colon
The game, a file of pad/subs/games/types/: bullscows, crossword, dotsandboxes, fifteen, gomoku, hangman, hanoi, klondike, mancala, maze, memory, morris, nim, nonogram, pegsolitaire, quiz, reversi, scramble, snake, sudoku, tictactoe, wordsearch. The game: prefix selects it - {game:memory/}.

Options

seed
A whole number: the shuffles, the boards and the puzzles are the same on every load. Without it the browser picks.
title
The name the game is shown under, else its own.
data
The words, the symbols or the questions of a game that takes them, from a {pad:data} store, the page's array or a _data file - else they stand between the tags, one a line.
opens
tictactoe, gomoku, reversi, nim, dotsandboxes, mancala, morris: you (the default) or computer.
two
Bare option, tictactoe, gomoku, reversi, dotsandboxes, mancala, morris: two players at one screen instead of the computer.
size
gomoku (15), fifteen (4), snake (18), wordsearch: the size of the board.
height
maze: the rows of cells (12), width the columns (18); dotsandboxes: the rows of boxes (4), width the columns (4).
level
mancala, morris: how far the computer looks ahead - easy, normal (the default) or hard.
seeds
mancala: the seeds each house starts with (4).
pairs
memory: how many pairs (8).
tries
hangman: wrong letters allowed (6); bullscows: guesses allowed (10).
digits
bullscows: how long the secret number is (4).
draw
klondike: the cards the stock turns up at a time (1, up to 3).
disks
hanoi: how many discs (4).
heaps
nim: the heaps, '3, 4, 5'; misere - who takes the last match loses.
rounds
scramble: words a game (10).
speed
snake: steps a second it starts with (6); wrap lets it run off one side and on at the other.
givens
sudoku without a puzzle: how many squares the new puzzle shows (30).
paper
Bare option, sudoku and crossword: the puzzle drawn to print, no script.
solve
Bare option, sudoku: the puzzle drawn with its solution. solution does it for a crossword.
order
Bare option, quiz: the questions in the order written.

Description

{game:memory} puts a little game on the page, played in the browser: the server checks what the game is given and writes its board, and the game's script - written once per page, with the CSP nonce - plays it. Every game is a file of pad/subs/games/types/, its script and its style in www/assets/games/; the files of types/ are the games there are.

The game is selected by its prefix and name: {game:memory/}. The words of a word game, the clues of a crossword, the questions of a quiz and the picture of a nonogram stand between the tags, one a line - taken as written, so they may hold braces - or come from a store named by data=.

The board carries data-result="won" or "lost" when a game ends and sends a pad-game-end event, which a page can listen to. seed= makes a game the same on every load - the same shuffle, maze or puzzle. The colours are --pad-game-ink, -accent, -good, -bad and their like on .pad-game, light and dark.

Sudoku and crossword can also be printed: paper draws the puzzle without a script, solve - solution for the crossword - with the answers filled in.

Examples

Memory

Pairs of cards face down - turn two over at a time.

Templateexamples/game/1-memory.pad 
{game:memory pairs=6/}

A crossword

A line per word between the tags, WORD: clue - laid out on the server, played in the page.

Templateexamples/game/3-crossword.pad 
{game:crossword}
  ECHO: Writes a value without the sanitize chain
  PIPE: The | that hands a value to a function
  CHART: Draws a picture of numbers
  HTML: What a page is written in
{/game:crossword}

A quiz from the content

A question a line: the question, then the answers after a bar, the right one first.

{/game:quiz}
