App: manual - Page: pages/data_handling
PHP
 HTML
pages/data_handling.pad 		Result 
<p>It is possible to process the data from a {app:tag 'tag'/} before it is used by PAD to construct the output.
<p>This is done by using one of the below options.
<p>dedup, end, first, group, last, page, random, reverse, row, rows, shuffle, slice, sort, splice, start, trim, where
<p>The options run in the order they are written. <code>where</code> keeps the rows a quoted expression holds for, evaluated per row with the row's fields; when the options leave no row at all, the tag shows its {app:construct 'else'/} branch. <code>group</code> folds the rows into one occurrence per value of a field, with subtotals - see <a href="?pages/grouping">grouping with subtotals</a>.

  {common:example 'miscellaneous/handling', onlyPHP, skipHeader/}

  {pad:page 'miscellaneous/handling'/}
