Application Description Code
_common Shared resources and utilities available to all PAD applications via symbolic links or includes. edit
classicModels Some PAD pages built on the Classic Models sample database, demonstrating the PAD Select subsystem: declared tables, relations between them, and the joins PAD derives from those. These pages were part of the manual until its examples were reorganised, after which the manual kept a page referring to them but the examples themselves were gone. They are recovered here, from commit ac148cccd, as an application of their own. edit
cli The `pad` command - new, serve, render, lint, export, test - and the command-line application it runs when it is given no command. edit
demo Interactive demo showcasing PAD framework features with practical examples. edit
develop Development utilities for building, testing, and debugging PAD applications. edit
edit A browser editor for the PAD applications on this server, behind a login: the files of an application on the left, Monaco on the right with PAD colouring, completion, documentation and checks in .pad files and PHP completion in .php files. edit
examples A search box over the harvested examples in `DATA/examples/` - the store the build's harvest fills with every page's `.php` and `.pad` sources and its rendered `.html`. A hit opens the example with the two sources on the left, coloured, and the rendered result beside them; on a narrow screen the result drops below the sources. The search matches the example's name first and the contents of its three files second, so `sequence/random` and `upper` both find their way. edit
hello The simplest possible PAD application demonstrating the basic page pairing concept. edit
manual Interactive documentation and examples for the PAD framework. edit
nono A plain PHP application that runs without the PAD template engine. edit
pad The main PAD framework reference and documentation application. edit
playground Type a PAD template and its data, and see what they render to - for trying a tag, checking a bug report, or showing someone an example through a link. edit
react Demonstrates how to combine PAD (server-side template engine) with React (client-side JavaScript framework). edit
reference Cross-reference and directory listing utilities for PAD applications. edit
regression/main The regression tests of the PAD framework: eight suites, every page in the tree asserted by exactly one of them, with an overview that reports all eight on one line each and a fresh build that regenerates everything a build owns. edit
sequence Demonstration and testing of PAD's mathematical sequence subsystem. edit
structure Demonstrates the PAD directory structure and how special `_xxx` directories work at different levels of the application hierarchy. edit
test A scratch application for trying things out. `_common` is switched off in its configuration, so everything a page here uses has to come from this application itself. edit
