A PAD custom tag writes the custom element with its shadow root already in it - declarative shadow DOM - so it shows, styled and slotted, before any script ran.

🃏→

Cards with slots

{app:card title='Revenue'} is a PAD custom tag that writes <pad-card> with its shadow root: encapsulated styles inlined by {widget:shadow css=}, named slots the browser fills from the light DOM - and not a line of JavaScript.

{widget:shadow}_tags/card.pad{pad:parms}shadowrootmode<slot>::slotted

A small module defines the element: it finds the root PAD rendered and adds behaviour - keys, clicks, a post back, a value in a form.

Tabs, upgraded

The tabs are complete HTML when they arrive - the first panel shows. Once tabs.js defines <pad-tabs>, the element takes the root PAD rendered and adds clicks and arrow keys.

A rating that posts

<pad-rating value="4"> gets its value from PAD and its stars from the server; a click posts the new rating with the session's CSRF token, and the element shows the average PAD answers.
