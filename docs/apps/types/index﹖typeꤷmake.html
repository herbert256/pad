Types/Sequences/make:

make:

The terms of a sequence type, made as a play - the same terms {sequence:x} gives.

Sequences Only with its prefix

Syntax 

{make:fibonacci rows=8}{$sequence} {/make:fibonacci}

Description

Creates new sequence values. 

{make:fibonacci/}
{fibonacci:make}

Resolution: Sequence exists + make type available.

Implementation: Delegates to PQ/start/types/make.php.

The handler

pad/types/make.php: Type handler for the sequence make operation ({make:fibonacci}): delegates to the sequence subsystem's entry point, which builds the sequence.
