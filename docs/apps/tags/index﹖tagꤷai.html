Tags/Network and mail/ai:*

{ai:*}

Prints the answer of a language model to the prompt its content renders, as text, kept for a while.

Network and mail Either form

Syntax 

{pad:ai provider='anthropic', model='name', system='text', tokens=500, ttl=86400} ... {/pad:ai}
{pad:ai 'prompt'/}

Parameters

prompt
The prompt of the single form. As a pair the rendered content is the prompt.

Options

provider
A file of pad/subs/ai/types/: anthropic, bedrock, cloudflare, cohere, gemini, lmstudio, mistral, ollama, openai - PAD_AI_PROVIDER, else anthropic.
model
The model - the provider's own default unless given.
system
The system prompt.
tokens
The most the answer may take.
ttl
The seconds an answer is kept - 3600 unless given, 0 keeps nothing.

Description

{pad:ai}...{/pad:ai} renders its content first - fields, loops, anything - and sends what it rendered to a language model as the prompt; the answer is printed as text. It is a value, never template code: markup and PAD tags in it are shown, not run. The single form takes the prompt as its parameter: {pad:ai 'Name three rivers of France.'/}.

The key is the provider's .env value - ANTHROPIC_API_KEY, OPENAI_API_KEY, MISTRAL_API_KEY, GEMINI_API_KEY, COHERE_API_KEY, CLOUDFLARE_API_TOKEN, AWS_BEARER_TOKEN_BEDROCK; Ollama and LM Studio run on this machine and need none. An answer is kept under a hash of the provider, model, system prompt and prompt for ttl= seconds, a failed one never. A missing key or an error of the API is an error under the strict check; without it the tag answers nothing and the error is logged. From PHP: padAi ( $prompt, $options ).

The tag asks a service on the internet, so its examples are shown, not run.

AI providers

Each kind has its own description and usage example:

anthropic, bedrock, cloudflare, cohere, gemini, lmstudio, mistral, ollama, openai

Examples

A summary, kept a day

The content renders first and is the prompt; the answer is kept a day for the same prompt.

Templateexamples/ai/1-summary.src 
{array:articles}
  <h3>{$title}</h3>
  <p>{pad:ai provider='anthropic', ttl=86400}Summarise in one sentence: {$body}{/pad:ai}</p>
{/array:articles}

A model on this machine

Ollama needs no key; system= sets the tone, tokens= bounds the answer.

Templateexamples/ai/2-local.src 
<p>{pad:ai 'Name three rivers of France.', provider='ollama', model='llama3.2', system='Answer in one line.', tokens=40/}</p>

Cohere

The Chat API v2 of Cohere, the key in COHERE_API_KEY: the text blocks of the answer joined, a thinking block passed over.

Templateexamples/ai/3-cohere.src 
<p>{pad:ai 'Suggest a name for a bakery by the sea.', provider='cohere', model='command-a-plus-05-2026', tokens=60/}</p>

Cloudflare Workers AI

A model of the Workers AI catalogue, run under the account of CLOUDFLARE_ACCOUNT_ID with the token CLOUDFLARE_API_TOKEN.

Templateexamples/ai/4-cloudflare.src 
<p>{pad:ai 'Write a haiku about the sea.', provider='cloudflare', model='@cf/meta/llama-3.3-70b-instruct-fp8-fast', tokens=80/}</p>

Amazon Bedrock

The Converse API of Amazon Bedrock in the region of AWS_REGION, a Bedrock API key in AWS_BEARER_TOKEN_BEDROCK; model= a model id, an inference profile or an ARN.

Templateexamples/ai/5-bedrock.src 
<p>{pad:ai 'Explain a lighthouse to a child in one sentence.', provider='bedrock', model='us.anthropic.claude-sonnet-4-6', tokens=80/}</p>

LM Studio on this machine

The native chat API of LM Studio at 127.0.0.1:1234, no key; model= a model downloaded there.

Templateexamples/ai/6-lmstudio.src 
<p>{pad:ai 'Give three names for a grey cat.', provider='lmstudio', model='ibm/granite-4-micro', system='Answer in one line.', tokens=40/}</p>

See also

  • {pad:cache} Keeps a named section of the page rendered for a number of seconds - the fragment cache.
  • {pad:markdown} Renders its content, or the value of its parameter, as Markdown and writes the HTML.
