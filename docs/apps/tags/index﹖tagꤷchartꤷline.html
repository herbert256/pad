Tags/Chart types/chart:line

{chart:line}

A line over a light wash, the last point marked.

Chart types Either form

Syntax 

{chart:line data='rows', label='field', value='field'/}
{line data='rows', label='field', value='field'/}

Description

One of the 45 chart types of {pad:chart}, written {chart:line .../}, {chart 'line', .../}, {line ...}, bare, when no tag, field or store has the name.

A line over a light wash, the last point marked; several value fields a line each, named at the end. Options: label, value; width= and height=, 600 x 300 unless given.

Example

From the charts application

Its example line/shares there, with the data it draws.

Templatecharts/line/shares.pad 
{chart 'line',
       data='shares',
       label='month',
       value='price',
       title='Closing price per month',
       width=640,
       height=340/}
