# basketweave

Interlocking alternating horizontal and vertical bundles. `size` is the two-bundle repeat; `strands` is 1–12 (fractional values are rounded down), and `gap` is the fraction of each strand left clear (0–0.8). The repeat has exactly four bundles and at most 48 rectangles, independent of picture size. Alternating bundles use the first two inks if supplied.

`{pattern:basketweave size=48, width=480, height=240/}`

Standard colors, opacity, title and SVG/data-URI options apply. Geometry is deterministic and seed-independent. No per-pixel or per-area shape growth.
