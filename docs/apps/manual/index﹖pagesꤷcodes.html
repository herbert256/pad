Barcodes and QR codes

{barcode:auto} and {barcode:qr} write a code a scanner reads. It is encoded on the server and drawn as inline SVG - no image library, no font, no remote service - so a page with a code prints, caches and goes in an e-mail like any other. There are 19 symbologies, every one a file of pad/subs/codes/types/. Twelve or thirteen digits are an EAN-13, with the check digit added when it is left off; any other text is Code 128.

PHP
 HTML
fragments/codes_1.pad 		Result 
{barcode:auto '871234567890'/}
{barcode:auto 'PAD-2026-0042', height=50/}

Two ways to write one

The name after barcode: selects the symbology: {barcode:upce '0425261'/}. The barcode type does the same, {barcode:upce '0425261'/}. Both forms require their type prefix and draw the same UPC-E.

PHP
 HTML
fragments/codes_2.pad 		Result 
{barcode:upce '0425261'/}
{barcode:upce '0425261'/}
{barcode:upce '0425261'/}

Products, parcels and labels

The product codes - ean13, ean8, upca and upce - check the digit a number ends in, or add it; databar, GS1 DataBar, writes a GTIN in the small symbol of loose fruit and vegetables. Code 128 and Code 93 take printable ASCII, Code 39 capital letters, digits and a few signs, with check for its check symbol. itf and itf14 are the digits of cartons, codabar the code of libraries and blood banks, msi that of shelf labels. gs1128 writes the GS1 element strings of a logistics label - (01)09501101530003(17)261231(10)AB-123 - with every value checked as GS1 defines it; datamatrix with gs1 writes them as GS1 DataMatrix, the code of medicine packs. bookland is the barcode of a book, its ISBN as an EAN-13 with the ISBN above the bars, and addon= puts two or five more digits beside an EAN or UPC - a magazine's issue, a book's price.

PHP
 HTML
fragments/codes_3.pad 		Result 
<p>{barcode:code39 'PAD-2026', check, height=40/}</p>
<p>{barcode:itf14 '1540014128876', height=40/}</p>
<p>{barcode:codabar '40156', height=40/}</p>

Two-dimensional codes

qr is the code of {barcode:qr}, which a phone camera reads; datamatrix the square code of parts and medicine packs. Both take any text and choose the smallest symbol that holds it, and both take size= in pixels in place of the height and scale of the bars. aztec, the code of train tickets and boarding passes with a bullseye in its middle, does the same, with ecc= for the share of its codewords that corrects errors. pdf417, the code of boarding passes and driving licences, stacks rows of codewords instead, each row telling the scanner where it stands; columns= sets how wide it is and level= its error correction.

PHP
 HTML
fragments/codes_4.pad 		Result 
{barcode:qr 'https://example.com/order/42', size=140/}
{barcode:datamatrix 'https://example.com/order/42', size=120/}
  • The colours are black on white unless color= and background= say otherwise - fixed, whatever the page's colour scheme, as a scanner needs the contrast.
  • The SVG is role="img" with the text, or title=, as its name.
  • A wrong check digit, a character the symbology has no bars for or a text too long for it is an error under the strict check, and nothing is drawn.
