{pad:ai}...{/pad:ai} renders its content first - fields, loops, anything - and sends what it rendered to a language model as the prompt; the answer is printed as text. It is a value, never template code: markup and PAD tags in it are shown, not run. The single form takes the prompt as its parameter: {pad:ai 'Name three rivers of France.'/}.

The key is the provider's .env value - ANTHROPIC_API_KEY, OPENAI_API_KEY, MISTRAL_API_KEY, GEMINI_API_KEY, COHERE_API_KEY, CLOUDFLARE_API_TOKEN, AWS_BEARER_TOKEN_BEDROCK; Ollama and LM Studio run on this machine and need none. An answer is kept under a hash of the provider, model, system prompt and prompt for ttl= seconds, a failed one never. A missing key or an error of the API is an error under the strict check; without it the tag answers nothing and the error is logged. From PHP: padAi ( $prompt, $options ).

The tag asks a service on the internet, so its examples are shown, not run.
