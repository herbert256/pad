Tags/Chart types/chart:area

{chart:area}

Filled areas over the label axis, a line on each and a legend for several value fields.

Chart types Either form

Syntax 

{chart:area data='rows', label='field', value='field'/}
{area data='rows', label='field', value='field'/}

Description

One of the 45 chart types of {pad:chart}, written {chart:area .../}, {chart 'area', .../}, {area ...}, bare, when no tag, field or store has the name.

Filled areas over the label axis, a line on each and a legend for several value fields; stacked lays them on top of each other (the top edge the running total), percent stacks every column to 100% - no negative values when stacked; a column per label carries all values in its tooltip. Options: label, value, stacked, percent; width= and height=, 600 x 300 unless given.

Example

From the charts application

Its example area/devices there, with the data it draws.

Templatecharts/area/devices.pad 
{chart 'area',
       label='year',
       value='desktop, mobile, tablet',
