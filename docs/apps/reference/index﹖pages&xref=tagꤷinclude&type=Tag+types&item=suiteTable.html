App: regression/main - Page: framework/index
PHP
framework/index.php 		HTML
framework/index.pad 		Result 
<?php

  // Overview of the Framework suite - the engine cases as fetched pages, one request per
  // case, each fetched directly from regression/framework. Test here reruns the suite; a page load
  // reads the last run, because running means nine hundred requests.

  getSuitePage ( 'framework' );

?>
 
{include:suiteHead}

<p>
  The engine cases as fetched pages, exactly the Pages model: every case is a triple in a
  group directory of <code>apps/regression/framework/</code> - the <code>.pad</code> its template,
  the <code>.txt</code> the outcome beside it, an optional <code>.php</code> its variables -
  and each is fetched directly as the page it is. A request per case grants each one its
  isolation by construction; the price is nine hundred requests a run, which is why Test
  runs and a page load only reads.
</p>

{include:suiteTable}

App: regression/main - Page: manual/index
PHP
manual/index.php 		HTML
manual/index.pad 		Result 
<?php

  // Overview of the Manual suite - every page of apps/manual/, fetched over HTTP one
  // request at a time and compared with the prediction of the same name in
  // apps/regression/manual/. The pages stay in their own application; the store holds
  // nothing but what each must answer. Test here reruns this suite; a page load reads the
  // last run.

  getSuitePage ( 'manual' );

?>
 
{include:suiteHead}

<p>
  Every test here is a page of the <a href="{$padHost}manual">manual</a> application,
  fetched over HTTP a dozen at a time, and compared with the prediction of the same
  name in <code>apps/regression/manual/</code>. The pages stay in their own application;
  the store holds nothing but what each must answer. An index is fetched full, everything
  else bare with <code>&amp;padInclude</code>, the same rule the harvest applies - and a page
  that draws answers a <code>/pattern/</code> pinning its skeleton, everything else an
  exact body.
</p>

{include:suiteTable}

<?php

  // Overview of the Regression suite - the self-testing applications under regression/,
  // every page fetched over HTTP one request at a time and compared with the prediction of
  // the same name in apps/regression/regression/. The pages stay in their own applications;
  // the store holds nothing but what each must answer. Test here reruns this suite; a page
  // load reads the last run.

  getSuitePage ( 'regression' );

?>
 
{include:suiteHead}

<p>
  Every test here is a page of one of the self-testing applications - the cache, error,
  output, info, config and try families under <code>regression/</code> - fetched over HTTP
  one request at a time, and compared with the prediction of the same name in
  <code>apps/regression/regression/</code>. The pages stay in their own applications; the
  store holds nothing but what each must answer. An index is fetched full, everything else
  bare with <code>&amp;padInclude</code>, the same rule the harvest applies - and a prediction
  is an exact body, an <code>HTTP</code> code with an optional pattern over the dump, or a
  <code>/pattern/</code> for a page that draws.
</p>
