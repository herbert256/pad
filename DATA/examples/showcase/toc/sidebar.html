Installation

Clone the repository and point the web server at www/.

Requirements

PHP 8.1 or newer; a database only when the application uses one.

Extensions

mbstring is required, intl is used when it is there.

First run

Open the hello application to see a page and its template.

Configuration

Settings stand in _config/config.php and in .env files.

Error handling

Choose what happens when something goes wrong: a page, a log line or a dump.

Deployment

Copy the files; there is no build step.
