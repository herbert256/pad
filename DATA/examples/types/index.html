Every PAD type

A tag has a type, the prefix before the colon: {pad:if} is a built-in tag, {chart:pie} a chart type, {field:name} a field of the row, {sequence:fibonacci} a sequence. Written without its prefix a name is the first type that has it. A page for each type: what it reaches, how it is written, where it stands in the order a bare name is tried in, the tags it has and live examples.
