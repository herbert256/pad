Cheat sheet

The syntax of every tag, by group.

Conditions

caseRenders the one branch whose {when} matches a value, with an {else} for none.
{case value}{when'a'} ... {when'b', 'c'} ... {/case}{case value}{when'a'} ... {else} ... {/case}
falseThe constant FALSE: its content is skipped and its @else@ part renders instead.
{false}{false} ... {/false}{false} ... @else@ ... {/false}
ifRenders its content only when a condition holds, with elseif and else branches.
{if condition} ... {/if}{if condition} ... {else} ... {/if}{if condition} ... {elseif condition} ... {else} ... {/if}
ifchangedRenders its content when a value differs from the previous row of the loop around it - a heading per group.
{ifchanged value} ... {/ifchanged}{ifchanged value, value} ... {/ifchanged}{ifchanged value} ... @else@ ... {/ifchanged}
nullThe constant NULL: its content is dropped, the @else@ part too, and a null= option fires.
{null}{null} ... {/null}{nullnull='name'} ... {/null}
switchAnswers the next value of a rotating list on every call - striped rows without a counter.
{switch'odd', 'even'}{switch'red', 'green', 'blue'}
trueThe constant TRUE: its content renders once, as a level of its own.
{true}{true} ... {/true}

Loops and trees

branchInside a {tree}: renders its content only when the current row has children, its @else@ part for a leaf.
{branch} ... {recurse} ... {/branch}{branch} ... @else@ ... {/branch}
breakLeaves a loop at once: the rest of the current pass is dropped and no further row follows.
{break}{break'name'}
ceaseEnds a loop gracefully: the current pass finishes, and no further row follows.
{cease}{cease'name'}
continueSkips the rest of the current pass of a loop and goes on with its next row.
{continue}{continue'name'}
recurseInside a {tree}: renders the tree's body once more for the children of the current row.
{recurse}
treeRenders a tree of rows: its body for every row, and {recurse} renders it again for the row's children.
{tree'rows'} ... {recurse} ... {/tree}{treedata='rows', children='items'} ... {branch} ... {recurse} ... {/branch} ... {/tree}{tree'rows'} ... @else@ ... {/tree}
untilRenders its content again and again until a condition becomes true.
{until condition} ... {/until}{until} ... {/until condition}
whileRenders its content again and again for as long as a condition holds.
{while condition} ... {/while}{while} ... {/while condition}

Variables and stores

atLooks a value up in a data set by a path of names and conditions - the @ notation as a tag.
{at'field@store'}{at"path.key='value'.field@store"}
boolReduces its content or a value to TRUE or FALSE and keeps it under a name, for a later {name} to test.
{bool'name'} expression {/bool}{bool'name', value}{name} ... @else@ ... {/name}
contentKeeps a piece of template under a name instead of printing it, for a later {name} to render.
{content'name'} ... {/content}{content'name', 'text'}{content} ... {/content'name'}
countRenders its content only when a named data set or page array holds at least one element.
{count'name'} ... {/count}{count'name'} ... @else@ ... {/count}
dataTurns its content - JSON, XML, YAML, CSV, a list or a range - into a named data set for a later tag to iterate.
{data'name'} ... {/data}{data'name', type='csv'} ... {/data}{data'name', source}{data} ... {/data'name'}
decrementTakes one off a variable, starting it at -1 when it does not exist yet.
{decrement$name}
incrementAdds one to a variable, starting it at 1 when it does not exist yet.
{increment$name}
setAssigns one or more variables, as globals that outlive the level the tag stands in.
{set$name = value}{set$name = value, $other = value}

Database

arrayRuns a SQL query on the application database and repeats its content once per row.
{array"* from table where ..."} ... {/array}{array"* from orders", name='orders'} ... {/array}
checkAsks the application database whether a row exists, and renders its content only when one does.
{check"table where ..."} ... {/check}{check"users where email='x@y.z'"} ... @else@ ... {/check}
collectionReads a folder of Markdown files from _content/ and repeats its content once per file, the front matter as fields.
{collection'name'} ... {/collection}{collection'name', slug=$slug} ... @else@ ... {/collection}{collection'name', html} ... {/collection}
fieldRuns a SQL query on the application database and prints the single value it answers.
{field"column from table where ..."}{field"count(*) from orders", name='orderCount'}
recordRuns a SQL query on the application database and renders its content with the first row's columns as fields.
{record"* from table where ..."} ... {/record}{record"* from users where id=5", name='user'} ... @else@ ... {/record}

Pages and execution

ajaxWrites an empty div and a script that has the browser fetch another page into it after the page has loaded.
{ajax'name'}{ajax'name', fragment='fragmentName'}{ajax'name', app='other'}{ajax'name', $colour = 'red'}
codeRuns its content as PAD source in a separate engine pass and outputs what that pass produced.
{code} ... {/code}{code sandbox} ... {/code}{code reset} ... {/code}{code clean} ... {/code}{codefunction='name'} ... {/code}{echo$snippet | code}
getFetches another page of the application over HTTP, as a second request, and inserts its output.
{get'name'}{get'name', $colour = 'red'}
liveA region of the page that re-renders on the server when something in it is clicked, submitted or changed, and swaps itself in.
{live'name'} ... <buttonpad-click="event"pad-value="value">...</button> ... {/live}{live'name'} ... <formpad-submit="event">...</form> ... {/live}{live'name'} ... <selectname="field"pad-change="event">...</select> ... {/live}
padA tag with no behaviour of its own: its content renders once, or per row with data=, carrying the generic options.
{pad} ... {/pad}{paddata='store', name='rows'} ... {/pad}{pad$name = 'value'} ... {/pad}{pad} ... {/pad | upper}
pageRenders another page of the application - its PHP and its template - in place of the tag.
{page'dir/name'}{page'products/42'}{page'name', include=false}{page'name', sandbox}{page'name', reset}{page'name', clean}{page'name', function='name'}{page'name', app='other', ajax=false}
restartAbandons the page being built and renders another page in its place, in the same request.
{restart'name'}{restart'name', $message = 'Saved'}
sandboxRuns its content as PAD source in an isolated pass that cannot see or leave behind anything of the page.
{sandbox} ... {/sandbox}{sandboxfunction='name'} ... {/sandbox}{echo$snippet | sandbox}

Navigation

pagerPage links for a tag written with the page option: first and last, a window round the current page, previous and next.
{pager'name'}{pager'name', window=2, query='p'}{pager'name'} ... {$kind}{$page}{$label}{$href} ... @else@ ... {/pager}
redirectSends the browser to another page or address with a 302 and ends the request.
{redirect'name'}{redirect'orders/list', $status = 'open'}{redirect'https://example.com/'}
sitemapLists the pages of the application, read from the file tree, as rows with page, url and lastmod.
{sitemap} ... {$page}{$url}{$lastmod} ... {/sitemap}{sitemap'dir'} ... {/sitemap}

Forms and security

csrfThe hidden form field holding the CSRF token of the visitor's session, or the bare token.
{csrf}{csrf token}
flashThe flash messages of this request - set with padFlash on the page before - one occurrence each.
{flash}{$message}{$type}{/flash}{flash} ... @else@ ... {/flash}{flash'error'}{$message}{/flash}
formA form that posts back to the page, carrying the session's CSRF token and its own name, its fields refilling when it came back.
{form'name'} ... {/form}{form'name', method='get', class='search'} ... {/form}{form'name', error='Please correct the errors below.'} ... {/form}{form'name', client, error} ... {/form}
inputA form field with its label that refills from what its form sent and shows the error validation found for it.
{input'name'}{input'email', type='email', label='E-mail', value='', id='mail', placeholder='you@example.org', required}{input'terms', type='checkbox', label='I agree', value='yes', checked}{input'email', type='email', label='E-mail', rules='required|email'}
nonceThis request's Content-Security-Policy nonce, for a script or style the policy lets run.
{nonce}
textareaA text area with its label that refills from what its form sent and shows the error validation found for it.
{textarea'message'}{textarea'message', label='Message', value='', id='msg', rows=6, required}{textarea'message', label='Message', rows=6, rules='required|max:2000'}
validatorThe browser's checker of the validation rules as one inline script, for a form a component draws.
{validator}

Users and access

authRenders its content when a user is logged in, with the user's row as its data, and its else half for a guest.
{auth} ... {/auth}{auth} Hello {$name}{else} ... {/auth}{auth} ... @else@ ... {/auth}
canRenders its content when the user may do something a gate decides, and its else half when not.
{can'ability'} ... {/can}{can'ability', $value} ... {else} ... {/can}{rows}{can'ability', $rows} ... {/can}{/rows}
cannotRenders its content when the user may not do something a gate decides - can turned round.
{cannot'ability', $value} ... {/cannot}{cannot'ability', $value} ... {else} ... {/cannot}
featureRenders its content while a feature flag is on for this visitor, and its else half while it is off.
{feature'flag'} ... {/feature}{feature'flag'} ... {else} ... {/feature}
guestRenders its content when nobody is logged in, and its else half for a user.
{guest} ... {/guest}{guest} ... {else} ... {/guest}

Files

dirLists the names in a directory, one occurrence each - the plain version of files.
{dir$path}{$dir}{/dir}
existsRenders its content when a file or directory is there, its else half when not.
{exists$path} ... {/exists}{exists$path} ... @else@ ... {/exists}
fileWrites its rendered content to a file under DATA/ instead of to the page.
{filedir='exports', name='orders', ext='csv'} ... {/file}{filedir='reports', name='daily', ext='html', date, stamp, id=8} ... {/file}
filesScans a directory and iterates its entries, with path, file, ext, item and dir for each.
{files'dir', base='app'}{$item}{$file}{$ext}{/files}{filesdir='dir', base='data', mask='*.txt', exclude='old*', recursive, onlyFiles, includeHidden} ... {/files}{files'dir', base='app', onlyDirs} ... {/files}
