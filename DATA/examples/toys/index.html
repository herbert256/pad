Small live simulations and visual toys that run in the page, each one a tag of its own - a file of pad/toys/types/ in the engine, written {toy 'name'/}, as {toy:name/} or, when nothing else has the name, bare. The server checks the options, a script in the page runs the toy: draw on it, drag it, click it, change its sliders.
