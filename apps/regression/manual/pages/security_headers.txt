/^\<h1\>Security headers\<\/h1\>

\<p\>Every web response carries a few headers that cost nothing and close common holes\:\<\/p\>

\<table border\="1" cellpadding\="8" cellspacing\="0" style\="border\-collapse\: collapse;"\>
  \<tr\>\<th\>header\<\/th\>\<th\>default\<\/th\>\<th\>what it does\<\/th\>\<\/tr\>
  \<tr\>\<td\>\<code\>X\-Content\-Type\-Options\<\/code\>\<\/td\>\<td\>\<code\>nosniff\<\/code\>\<\/td\>\<td\>the browser takes the content type as sent, and does not guess one\<\/td\>\<\/tr\>
  \<tr\>\<td\>\<code\>Referrer\-Policy\<\/code\>\<\/td\>\<td\>\<code\>strict\-origin\-when\-cross\-origin\<\/code\>\<\/td\>\<td\>other sites see where a visitor came from, not the full address\<\/td\>\<\/tr\>
  \<tr\>\<td\>\<code\>Content\-Security\-Policy\<\/code\>\<\/td\>\<td\>\<code\>frame\-ancestors 'self'\<\/code\>\<\/td\>\<td\>no other site can show your pages in a frame\<\/td\>\<\/tr\>
\<\/table\>

\<p\>\<code\>\$padSecurityHeaders\<\/code\> in \<code\>_config\/config\.php\<\/code\> lists the first two,
name \=&gt; value \- an empty value leaves one out, \<code\>\[\]\<\/code\> sends none \- and
\<code\>\$padCsp\<\/code\> is the policy, \<code\>''\<\/code\> for none\. A header the page's own PHP sent
stands over the default\.\<\/p\>

\<h2\>A strict policy and the \{nonce\} tag\<\/h2\>

\<p\>A strict policy refuses inline scripts \- which is the point\: a script someone smuggled
into the page does not run\. Your own inline script runs when it carries the request's nonce\.
Write \<code\>'nonce'\<\/code\>, with the quotes, in the policy, and \<b\>\{nonce\}\<\/b\> in the script
tag; the engine puts the same random value in both, new for every request\:\<\/p\>

\<pre\>\$padCsp \= "default\-src 'self'; script\-src 'self' 'nonce'; frame\-ancestors 'self'";\<\/pre\>
