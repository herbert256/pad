Reference - Tag types - named

App: regression/pages - Page: select/demo/values
PHP
select/demo/values.php 		HTML
select/demo/values.pad 		Result 
<?php

  // A key value bound on a declared select table reaches the SQL as a value, whatever it
  // holds: a comma is still a comma and matches, and a quote cannot end the string and
  // become part of the condition. Over the customers table of the demo database.

  $padSelect ['named'] = [ 'db' => 'customers', 'key' => 'customerName' ];

?>
 
a comma in the value: [{named $customerName="Australian Collectors, Co."}{$customerNumber}{/named}]
a quote in the value: [{named $customerName="x' or customerNumber > '0"}{$customerNumber},{/named}]
