Tags/Widgets/widget:*

{widget:*}

An interactive part of the page that works without JavaScript - 17 of them, from tabs, a modal and a carousel to a toast, a dropdown and a wizard.

Widgets Either form

Syntax 

{widget:name ...} ... {/widget:name}
{widget:tabs active='label'} {pad:tab 'label'} ... {/pad:tab} ... {/widget:tabs}
{widget:accordion single, open=1} {pad:tab 'label'} ... {/pad:tab} ... {/widget:accordion}
{widget:carousel label='name'} {pad:tab 'caption'} ... {/pad:tab} ... {/widget:carousel}
{widget:wizard active=1, next='Next', back='Back'} {pad:tab 'step'} ... {/pad:tab} ... {/widget:wizard}
{widget:lightbox label='name'} {pad:tab 'caption'} <img ...> {/pad:tab} ... {/widget:lightbox}
{widget:splitpane size=30, min=20, max=60, stacked, collapse, height='16rem'} {pad:tab 'label'} ... {/pad:tab} {pad:tab 'label'} ... {/pad:tab} {/widget:splitpane}
{widget:sortable 'name', label='text'} {pad:tab 'key'} ... {/pad:tab} ... {/widget:sortable}
{widget:modal 'name', title='heading', button='text'} ... {/widget:modal}
{widget:drawer 'name', title='heading', button='text', side='left'} ... {/widget:drawer}
{widget:dropdown 'text', align='end'} <a href="..."> ... </a> ... {/widget:dropdown}
{widget:contextmenu 'name', area='tr'} <a href="..."> ... </a> ... {/widget:contextmenu}
{widget:commandpalette 'text', data='rows', key='k', placeholder='hint', empty='text'} <a href="..."> ... </a> ... {/widget:commandpalette}
{widget:tooltip 'tip'} ... {/widget:tooltip}
{widget:toast 'title', tone='success', place='top', timeout=5} ... {/widget:toast}
{widget:copy 'text', label='Copy'/}
{widget:poll 'name', options='Yes, No', title='question', button='Vote', results/}
{widget:breadcrumb home='Home', label='Breadcrumb'/}

Parameters

kind after colon
The widget, a file of pad/subs/widgets/types/: accordion, breadcrumb, carousel, commandpalette, contextmenu, copy, drawer, dropdown, lightbox, modal, poll, sortable, splitpane, tabs, toast, tooltip, wizard. The widget: prefix selects it - {widget:modal 'terms'}.
first
The widget's own first parameter, used after {widget:modal}: the name of a modal, a drawer, a poll, a context menu or a sortable, the text of a copy box, the title of a toast, the button of a dropdown, the tip of a tooltip, the button of a command palette.

Options

active
tabs, wizard: the tab or step shown first, by its number from 1 or its label.
single
Bare option, accordion: one item open at a time.
open
accordion: the item open at first, by its number or its label; bare, every item.
label
carousel, lightbox, wizard, breadcrumb, sortable: the name for a screen reader; copy: the button's text.
title
modal, drawer: the heading that names the dialog; poll: the question.
button
modal, drawer: the text of the button that opens it (Open); poll: the vote button.
side
drawer: right (the default), left or bottom.
align
dropdown: start (the default) or end - the menu's edge under the button's.
place
tooltip: top or bottom; toast: inline, top or bottom - in the flow, or in that corner of the window.
tone
toast: info, success, warning or error.
timeout
toast: seconds, 1 to 600, after which it closes by itself, which its script does.
next
wizard: the text of the Next button (Next).
back
wizard: the text of the Back button (Back).
options
poll: the answers, separated by commas - two or more.
results
Bare option, poll: the results to everyone, also before a vote.
home
breadcrumb: the first step's text when the trail is the page's path (Home).
data
breadcrumb: the steps from rows - their label and link fields - of a store, the page's array or a _data file; commandpalette: the commands from rows - label, link, group and keywords.
size
splitpane: the first pane's share in percent, a whole number (50).
min
splitpane: the smallest share of the first pane, in percent (10).
max
splitpane: the largest share of the first pane, in percent (90).
stacked
Bare option, splitpane: the panes one above the other, the bar between them across.
collapse
Bare option, splitpane: Enter on the bar or a double click folds the first pane away and back.
height
splitpane: the height of the panes, a CSS length - 300px, 24rem, 60vh; stacked 20rem when not given.
area
contextmenu: the part a right click opens the menu on - the nearest element around it of a tag name or a class, tr, .card; the element it stands in when not given.
key
commandpalette: the letter of the shortcut with Ctrl or ⌘ (k).
placeholder
commandpalette: the hint in the search box (Type a command).
empty
commandpalette: what shows when nothing is found (No command found).

Description

{widget:tabs} puts an interactive part on the page - tabs, an accordion, a carousel, a wizard, a lightbox, a split pane, a modal, a drawer, a dropdown, a context menu, a command palette, a tooltip, a toast, a copy box, a poll, a breadcrumb, a sortable list. Every one is built on the server and works without JavaScript: radio buttons and CSS, <details>, <dialog>, the popover attribute, :target. Where a widget has a script it only makes it handier - Escape, the arrow keys, the focus - and is written once per page, with the CSP nonce. Every widget is a file of pad/subs/widgets/types/, its functions in pad/subs/widgets/_lib/, its style and script in www/assets/widgets/; the files of types/ are the widgets there are.

A widget uses a qualified name: {widget:modal 'terms'}. Its first parameter is the widget's value. The widget: prefix selects the widget even when the page has an array or store with the same name. {widget:copy} writes a copy box; {pad:tab} supplies the labelled parts of tabs, accordion, carousel, wizard, lightbox, splitpane and sortable.

  • tabs - panels behind a row of tabs: a radio button and a label per tab, the arrow keys move between them, printed every panel shows. accordion - every item a <details>; single one open at a time. carousel - slides that scroll and snap sideways, links to the slides before and after, a dot per slide, no autoplay. wizard - steps one at a time, numbered above, Back and Next under each. lightbox - thumbnails whose picture opens large over the page. splitpane - two panes and the bar between them, dragged or moved by the arrow keys; the browser's resize grip without scripting.
  • modal - a <dialog> and its button, opened by the invoker commands, a script where the browser has none, or a :target link without scripting. drawer - the same along the side of the window. commandpalette - a dialog with a search box over the commands, opened by its button or Ctrl+K: typing narrows them, Enter runs one; without scripting the whole list.
  • dropdown - a menu under a button, a popover the browser opens, closes and places. contextmenu - the actions on a part of the page: a right click, Shift+F10 or its button of three dots, which opens the same popover without scripting. tooltip - a tip on hover and focus, by CSS; Escape hides it. toast - a notice in an open <dialog> whose button closes it by an invoker command, a script where the browser has none - no form of its own, so it stands inside a form too; timeout= closes it by itself.
  • copy - a text and a copy-to-clipboard button. poll - a vote once per visitor, the results as bars. sortable - a short list put in order by hand, every item posted with its place: dragged, moved by buttons or the keyboard, number fields without scripting. breadcrumb - the trail from home to the page, from the page's path, the lines of a pair or data=.

The colours are custom properties on .pad-<widget> - --pad-tabs-accent, --pad-toast-success ... - with light-dark() defaults, so a page of color-scheme: light dark gets the dark ones in dark mode. A name that is no widget, an option a widget does not know and a widget without what it needs - a name, a label, a tab - are errors under the strict check. The poll's examples are shown but not run: what it shows depends on the votes and the visitor's session.

  {/pad:tab}
  {pad:tab 'Is there a warranty?'}

  {/pad:tab}

See also

  • {pad:tab} One item of a tabs, accordion, carousel, wizard, lightbox, splitpane or sortable widget: its label and its content, handed to that owner.
  • {widget:copy} The text in a <pre><code> that selects as a whole with a click, and a button that puts it on the clipboard.
  • {pad:live} A region of the page that re-renders on the server when something in it is clicked, submitted or changed, and swaps itself in.
  • {pad:form} A form that posts back to the page, carrying the session's CSRF token and its own name, its fields refilling when it came back.
