Types/Sequences/flag:

flag:

Every term a 1 or a 0: whether it belongs to the sequence type named.

Sequences Type prefix required

Syntax 

{flag:prime rows=8}{$sequence} {/flag:prime}

Description

Turns each value of a sequence into 1 or 0: whether it belongs to the named sequence type. 

{flag:prime/}
{flag:mySeq even}

Resolution: padTypeSeq() - a sequence type or a stored sequence.

Implementation: Delegates to PQ/start/types/flag.php. (In an expression, flag:name reads the bool store instead.)

The handler

pad/types/flag.php: Type handler for a sequence flag ({flag:name}): delegates to the sequence subsystem's entry point for flags.

122 of them, each with its page in the tags application.
