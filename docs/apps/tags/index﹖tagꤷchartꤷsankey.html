Tags/Chart types/chart:sankey

{chart:sankey}

Flows from source to target as wide as value, in columns along the longest path.

Chart types Either form

Syntax 

{chart:sankey data='rows', label='field', value='field'/}

Description

One of the 51 chart types of chart:*, written {chart:sankey data='rows', label='field', value='field'/}.

Flows from source to target as wide as value, in columns along the longest path; flows that go round in a circle are an error. Options: source, target, value; width= and height=, 600 x 400 unless given.

Example

From the charts application

Its example sankey/energy there, with the data it draws.

Templatecharts/sankey/energy.pad 
{chart:sankey data='flows',
       source='from',
       target='to',
       value='twh',
       title='Energy from source to use',
       width=640,
       height=400/}
