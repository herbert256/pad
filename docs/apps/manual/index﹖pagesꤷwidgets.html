Widgets

{widget} puts an interactive part on the page - tabs, an accordion, a carousel, a modal, a dropdown, a toast and more, 13 of them. Every one is built on the server and works without JavaScript; where a widget has a script it only makes it handier, and it is written once per page with the CSP nonce. Every widget is a file of pad/widgets/types/, and the files there are the widgets there are.

PHP
 HTML
fragments/widgets_1.pad 		Result 
{tabs active='Specs'}
  {tab 'Overview'}<p>A kettle in steel.</p>{/tab}
  {tab 'Specs'}<p>1.7 litres, 2200 W.</p>{/tab}
  {tab 'Delivery'}<p>Tomorrow.</p>{/tab}
{/tabs}

A kettle in steel.

1.7 litres, 2200 W.

Tomorrow.

Three ways to write one

The tag names the widget, and its second parameter is the widget's own first: {widget 'toast', 'Saved'/}. The widget: type does the same, {widget:toast 'Saved'/}, and so does the bare name, {toast 'Saved'/}. The bare name comes after every other kind of tag: a store, a field or an array of the name wins, so a page's $tabs array is the data of {tabs}.

PHP
 HTML
fragments/widgets_2.pad 		Result 
{widget 'toast', 'The widget tag', tone='success'/}
{widget:toast 'The widget: type'/}
{toast 'The bare name', tone='warning'/}

The widget tag

The widget: type

The bare name

What the browser does itself

Each widget stands on what HTML and CSS can do: radio buttons and CSS for tabs and the wizard, <details> for the accordion, a <dialog> for the modal, the drawer and the toast, the popover attribute for the dropdown, :hover and :focus-within for the tooltip, :target for the carousel's links and the lightbox. The keyboard works because the browser's own controls are underneath; the scripts add the arrow keys of a menu, Escape on a tooltip, the focus of a lightbox.

PHP
 HTML
fragments/widgets_3.pad 		Result 
{dropdown 'Sort'}
  <a href="?pages/widgets">By name</a>
  <a href="?pages/widgets">By price</a>
{/dropdown}
<div>The {tooltip 'Billed monthly'}Starter{/tooltip} plan.</div>
By name By price
The StarterBilled monthly plan.

Items made by a loop

Tabs, an accordion, a carousel, a wizard and a lightbox take {tab} items. A tab hands its content to the nearest of them above it, so it may stand in an {if} or in a loop over data - a step per row of a {data} store here.

PHP
 HTML
fragments/widgets_4.pad 		Result 
{data 'steps'}
  ["Order", "Pack", "Deliver"]
{/data}
{wizard}
  {steps}
    {tab $steps}<p>{$steps}.</p>{/tab}
  {/steps}
{/wizard}

Order.

Pack.

Deliver.

  • The colours are custom properties on .pad-<widget> - --pad-tabs-accent, --pad-toast-success and their like - with light and dark defaults.
  • {copy} stays a built-in tag that runs the copy widget, as PHP has a copy() function that a bare name would reach first; {tab} is a built-in tag too.
  • A name that is no widget, an unknown option value and a widget without what it needs - a name, a label, a tab - are errors under the strict check.
