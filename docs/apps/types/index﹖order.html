The order of the types

A name written without its prefix - {orders} - is the first of these types that has it: an application tag before a built-in one, a store before a field, a field before a sequence type of the same name. A prefix says which is meant, {pad:orders} or {data:orders}.

Tried in this order

31 types
  1. app: A tag of the application, a file of a _tags/ directory from the page up to the root.
  2. common: A tag or a snippet of the shared _common application.
  3. pad: A built-in tag of the engine - a file of pad/tags/.
  4. pull: A stored sequence - the terms a {sequence} pushed to the store under a name.
  5. bool: A boolean store - a flag set by {bool}, its pair showing when it is true.
  6. content: A content store - a piece of template kept by {content} to be shown elsewhere.
  7. define: A tag defined in the template by {define} - its body the template of the tag.
  8. macro: A tag defined in the template by {macro} - its body rendered once with the options as its fields.
  9. select: A table declared in $padSelect - its rows read from the database, joins and all.
  10. data: A data store - rows kept by {data} or a .json, .xml, .yaml or .csv file of _data/.
  11. include: A snippet of the application, a file of an _include/ directory.
  12. property: A property of the tag around it - its count, its current row, whether it is the first.
  13. field: A field of the current row, or a variable of the page.
  14. array: An array of the current row or of the page, its elements the rows of the tag.
  15. parm: A parameter or option of the tag around it, read by its name.
  16. level: An array field of a row of an enclosing tag, its elements the rows of the tag.
  17. constant: A PHP constant, by its name.
  18. local: A data file of a _data/ directory, read by its file name.
  19. script: A shell script of a _scripts/ directory, its output the tag's.
  20. php: A PHP function called as a tag, its parameters the function's arguments.
  21. sequence: A sequence type of the sequence subsystem, its terms the rows of the tag.
  22. action: A sequence action - reverse, sort, sum, first ... - over the terms it is given.
  23. chart: A chart type, a file of pad/charts/types/, drawn as inline SVG.
  24. game: A game, a file of pad/games/types/, played in the browser.
  25. toy: A toy, a file of pad/toys/types/ - a live simulation in the browser.
  26. diagram: A diagram type, a file of pad/diagrams/types/, laid out on the server.
  27. widget: A widget, a file of pad/widgets/types/, that works without JavaScript.
  28. barcode: A barcode symbology, a file of pad/codes/types/, encoded on the server.
  29. embed: An embed provider, a file of pad/embeds/types/ - loaded only on a click.
  30. input: A rich form field, a file of pad/inputs/types/, posted by any form.
  31. function: A pipe function used as a tag, over the content between its tags.

A PHP function gives way to a pipe function of the same name - {trim}, {date} - and common: is tried only where the application has _common switched on. A name that is only a request value comes after them all: a visitor's ?prime=x never takes the place of what the template names.

Only with their prefix

6 types
  • flag: Every term a 1 or a 0: whether it belongs to the sequence type named.
  • keep: The terms that belong to the sequence type named, the others left out.
  • make: The terms of a sequence type, made as a play - the same terms {sequence:x} gives.
  • remove: The terms that do not belong to the sequence type named.
  • fake: A fake kind, a file of pad/fakes/types/ - the same values for the same seed, never bare.
  • icon: An icon, a file of pad/icons/types/, drawn as inline SVG - never bare.
