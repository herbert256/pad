Tags/Widgets/widget:tabs

{widget:tabs}

Tabs without JavaScript: a radio button and a label per tab, the CSS shows the panel of the checked one.

Widgets Either form

Syntax 

{widget:tabs}{tab 'Overview'}...{/tab}{tab 'Specs'}...{/tab}{/widget:tabs}

Description

One of the 13 widgets of {pad:widget}, written {widget:tabs ...}, {widget 'tabs', ...}, {tabs ...}, bare, when no tag, field or store has the name.

{tabs}{tab 'Overview'}...{/tab}{tab 'Specs'}...{/tab}{/tabs} - tabs without JavaScript: a radio button and a label per tab, the CSS shows the panel of the checked one, the arrow keys move between them as in any radio group. active= names the tab shown first, by its number from 1 or its label; the first one otherwise. widgets/_lib/tabs.php.

Like {live} it runs twice: first it opens the collection its {tab}s hand their content to and asks for the end walk, then it builds the tab set from what they handed over.

Example

From the tags application

Its example on the page of {pad:widget}.

Templateexamples/widget/tabs-1-basic.pad 
{tabs active='Specifications'}
  {tab 'Overview'}
    <p>A 1.7 litre kettle in brushed steel that boils a full jug in under four minutes.</p>
  {/tab}
  {tab 'Specifications'}
    <table>
      <tr><th>Capacity</th><td>1.7 litres</td></tr>
      <tr><th>Power</th><td>2200 W</td></tr>
    </table>
  {/tab}
  {tab 'Reviews'}
    <p>Quiet, fast, and the light is a nice touch.</p>
  {/tab}
{/tabs}
Resultopen alone

A 1.7 litre kettle in brushed steel that boils a full jug in under four minutes.

Capacity 1.7 litres
Power 2200 W

Quiet, fast, and the light is a nice touch.
