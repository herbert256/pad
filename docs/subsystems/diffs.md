# Structured comparisons

`padDiffCompare($kind, $before, $after, $options = [])` returns change records with `op` (`add`, `remove`, `replace`), JSON Pointer `path`, and `before`/`after` only when present. No records are emitted for equal values. `padDiffRender($records, $side, $from, $to)` renders an escaped accessible HTML table. It never applies changes.

Kinds: `words`, `lines`, `json`, `rows`. Text comparisons report token or line positions. The structured `lines` API preserves empty trailing fields, so adding a terminal newline or a blank trailing line is a change; newline styles themselves are normalized. Its records are descriptive, not an executable JSON Patch. Existing `padDiffWords` and `padDiffLines` output is preserved. Named tags `{diff:words $old, $new/}`, `{diff:lines $old, $new/}` and `{diff:side $old, $new/}` provide those layouts. `side` is a tag layout, not a fifth record-comparison kind.

`json` accepts JSON text or PHP JSON values (list arrays, associative arrays, stdClass, finite scalars). A string input is decoded as JSON: encode a string scalar with `json_encode`. Integer literals outside `PHP_INT_MIN`..`PHP_INT_MAX` are rejected before rounding can hide changes; quoted numeric strings remain strings. Decimal/exponent numbers use PHP floating-point precision, so values that round to the same float compare equal; encode exact decimal identifiers or quantities as strings. Object key order is ignored; array positions and scalar types matter, including integer versus float. Missing properties differ from null. Empty PHP arrays represent JSON arrays; use `(object) []` for an empty object.

`rows` requires lists of arrays and `['key' => 'id']`. Keys must be nonempty strings or integers, unique on each side. Integer 1 and string "1" are distinct identities. Row reordering alone produces no changes. Paths start with the escaped typed key (`/i:1` or `/s:1`); each record also contains the original `key`. Missing/duplicate keys throw an exception. Nested properties use the JSON rules.

The named `{diff:json $before, $after/}` and `{diff:rows $before, $after, key='id'/}` tags retain their separate presence-flag contract, `same` option, untyped row-key paths and string-normalized identities: integer `1` and string `"1"` name the same row there. See [the tag subsystem](../../pad/subs/diffs/README.md). The old `{pad:diff}` tag is removed. Use `padDiffCompare` when typed identities and operation records are needed, and `padDiffRender` to display those records.

Inputs to `padDiffCompare` are bounded to 20000 nodes per side, depth 64 and 1 MiB per text; the record API bounds text comparisons to 20000 tokens in total. Invalid JSON, non-finite numbers and non-JSON objects are rejected. Run `php tests/subsystems/diffs.php`, then `php tests/subsystems/diffs-merge.php tags` and `php tests/subsystems/diffs-merge.php records` to check both API load orders.
