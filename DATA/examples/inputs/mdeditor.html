Markdown written beside its preview: a native <textarea>, which posts the Markdown as it is, and where the script runs a bar of buttons - bold, italic, a heading, a link, a list, a quote, code - and the text as it will read, kept in step as it is typed. Ctrl or Cmd with B, I and K make bold, italic and a link of the selection. The preview is the script's own reading of the common Markdown - headings, emphasis, code, links, lists, quotes, rules - with every tag of the text written as text and a link only to http, https, mailto or the site itself; {markdown} renders the stored text on the server. rows= the textarea's height, 8 unless given; the text before a post is value= or the content between the tags, as written.
