Tags/Chart types/chart:errorbar

{chart:errorbar}

An estimate per row with the interval around it, already computed.

Chart types Either form

Syntax 

{chart:errorbar data='rows', label='field', value='field'/}

Description

One of the 51 chart types of chart:*, written {chart:errorbar data='rows', label='field', value='field'/}.

An estimate per row with the interval around it, already computed: a point at value and an upright whisker with caps from low to high, the categories (label) along the bottom, one scale taking in every bound; interval names what the whisker is in the legend, never made up. A row without both bounds draws its point alone, a low above its high is an error naming the row. Options: label, value, low, high, interval; width= and height=, 600 x 300 unless given.

Example

From the charts application

Its example distribution/battery there, with the data it draws.

Templatecharts/distribution/battery.pad 
{chart:errorbar data='battery',
       label='laptop',
       value='hours',
       low='lower',
       high='upper',
       interval='95% CI of ten runs',
       title='Hours of video on one charge, the mean of ten runs per laptop',
       width=640,
       height=340/}
