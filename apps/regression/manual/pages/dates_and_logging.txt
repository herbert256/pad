<p>A page's PHP asks for the date all the time: to stamp a record, to say how old a comment
is, to write down what happened. These helpers give "now" in the application's timezone, read
a date whatever form it arrives in, put an age into words and keep a log of the
application's own - plain functions, loaded on every request.</p>

<table border="1" cellpadding="6" cellspacing="0" style="border-collapse: collapse;">
  <tr><th>function</th><th>what it answers</th></tr>
  <tr><td><code>padNow ( $format = NULL )</code></td><td>now, as a <code>DateTimeImmutable</code> in <code>$padTimezone</code> (else PHP's zone) - or, with a format, the formatted text</td></tr>
  <tr><td><code>padToday ( $format = NULL )</code></td><td>today at midnight</td></tr>
  <tr><td><code>padNowFreeze ( $time = NULL )</code></td><td>fixes now for the rest of the request; <code>NULL</code> lets the clock run again</td></tr>
  <tr><td><code>padDateParse ( $value )</code></td><td>a <code>DateTimeImmutable</code> from a timestamp, a date in text or a date object - <code>NULL</code> for what is none of those</td></tr>
  <tr><td><code>padAgo ( $date, $now = NULL )</code></td><td>the age in words: just now, 5 minutes ago, yesterday, in 3 days</td></tr>
  <tr><td><code>padLog ( $message, $level = 'info', $context = [] )</code></td><td>appends one line to the application's log of the day</td></tr>
</table>

<ul>
  <li>A number is a Unix timestamp, as the <code>date</code> pipe reads it; text is read the
  way PHP's <code>DateTime</code> reads it. A timestamp and text without a zone are in the
  application's zone; a zone that was given is kept.</li>
  <li>A date that does not exist - <code>2026-02-30</code>, which PHP itself would make
  2 March - is no date, nor are <code>NULL</code>, <code>''</code> and booleans:
  <code>padDateParse</code> answers <code>NULL</code> for them, never an error.</li>
  <li><code>$padTimezone</code> is read when a function is called, so a page can set it for
  itself.</li>
</ul>

<h2>Freezing the clock</h2>

<p><code>padNowFreeze ( '2026-10-05 14:30:00' )</code> fixes now for the rest of the request:
<code>padNow</code>, <code>padToday</code>, <code>padAgo</code>, the time stamp of
<code>padLog</code>, and text like <code>tomorrow</code> or <code>+1 week</code> given to
<code>padDateParse</code> all count from that moment. A test gets the same answer on every
run, and a page can be looked at as it will be on another day.
<code>padNowFreeze ()</code> lets the clock run again.</p>

<h2>How long ago</h2>

<p><code>padAgo</code> says the age of a moment in words, and the <code>ago</code> pipe does
the same in a template: <code>{$posted | ago}</code>.</p>

  <li>A moment still to come is said the other way round: <em>in 3 days</em>,
  <em>tomorrow</em>.</li>
  <li>A second argument - <code>padAgo ( $start, $end )</code>, or
  <code>{$start | ago($end)}</code> - counts from that moment instead of now. An
  empty value answers nothing.</li>
</ul>

<h2>Logging</h2>

<p><code>padLog</code> appends one line to
<code>DATA/logs/&lt;application&gt;/&lt;Y-m-d&gt;.log</code>: the time, the level, the
message and the context as JSON. The levels are those of PSR-3 - debug, info, notice,
warning, error, critical, alert and emergency - and <code>{name}</code> in the
message is filled from the context.</p>

<ul>
  <li>One call is always one line: a newline in the message is written <code>\n</code>.</li>
  <li>A message that is no text is written as JSON; a <code>Throwable</code> in the context
  as its class, message, file and line.</li>
  <li>A log line never stops the page: a disk that refuses the write is answered
  <code>FALSE</code>, not an exception. An unknown level is an error, the author's
  mistake.</li>
  <li>The engine's own errors go to PHP's error log; this log is for what the application
  wants to remember - a payment, a login, a failed import.</li>
</ul>
