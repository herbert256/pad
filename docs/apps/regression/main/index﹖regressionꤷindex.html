Every test here is a page of one of the self-testing applications - the cache, error, output, info, config and try families under regression/ - fetched over HTTP one request at a time, and compared with the prediction of the same name in apps/regression/regression/. The pages stay in their own applications; the store holds nothing but what each must answer. An index is fetched full, everything else bare with &padInclude, the same rule the harvest applies - and a prediction is an exact body, an HTTP code with an optional pattern over the dump, or a /pattern/ for a page that draws.
