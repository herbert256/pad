App: manual - Page: pages/remote_data
PHP
 HTML
pages/remote_data.pad 		Result 
{pad:meta title='Remote data with a cache'/}

<p>Data can come from another server: a URL as the data of a tag, a <code>.curl</code> file
in <code>_data/</code>, or the {app:tag 'curl'/} tag for the raw answer. Each of them takes a
<code>ttl</code> - the seconds to keep the answer - and within that time the page is served
from the copy instead of asking the source again. A dashboard on an external API then costs
one call per ttl, not one per visitor.</p>

<p>A <code>.curl</code> file names the URL and the ttl. Here <code>_data/rates.curl</code>
reads the rates from a page of this manual standing in for an API:</p>

{pad:ignore}
<code><curl>
  <url>SELF://manual/?fragments/rates&amp;amp;padInclude</url>
  <ttl>600</ttl>
</curl></code>
{/pad:ignore}

<p>Its name is a tag, like any data file:</p>

{common:example 'fragments/remote_1'/}

<p>The same with the URL in the template - the ttl is an option of the tag the data is
for, <code>{pad:pad data='https://...', ttl=600}</code> - or the answer as it came,
with {app:tag 'curl'/}:</p>

{common:example 'fragments/remote_2'/}

<p>When the source fails after the ttl - it is down, or answers with an error - the last good
copy is served and the failure is written to the error log, where an
<a href="?pages/events">event hook</a> on <code>curl</code> hears it too. Only a good answer
is kept, and a copy stays a day beyond its ttl for that purpose
(<code>$padCurlStale</code>). <code>$padCurlCache</code> chooses where the copies live:
<code>'file'</code>, <code>'apcu'</code>, <code>'redis'</code>, <code>'memcached'</code>,
or <code>FALSE</code> to fetch every time.</p>

App: regression/framework - Page: helpers/http_fake_answers_every_road_a_fetch_takes_and_records_it
PHP
helpers/http_fake_answers_every_road_a_fetch_takes_and_records_it.php 		HTML
helpers/http_fake_answers_every_road_a_fetch_takes_and_records_it.pad 		Result 
<?php

  // The fetches of this request answered from fakes: padCurl, padCurlCached (which passes
  // its cache by while faking), padPrefetch, and in the template {pad:curl} and data=. The
  // URLs fetched are read back after the template made its own.

  padCurlFake ( [
    'https://api.example.com/rates'  => [ 'data' => [ 'eur' => 1.08 ] ],
    'https://api.example.com/list*'  => [ 'status'  => 200, 'data' => "name,price\nTea,2\nCake,3",
                                          'headers' => [ 'Content-Type' => 'text/csv', 'X-Fake' => 'yes' ] ],
    'api.example.com/down'           => 503,
    'https://api.example.com/echo'   => fn ( $request ) => $request ['method'] . ' ' . $request ['post']
  ] );

  $rates  = padCurl ( 'https://api.example.com/rates' );
  $cached = padCurlCached ( 'https://api.example.com/rates', 600 );
  $down   = padCurl ( 'https://api.example.com/down' );
  $echo   = padCurl ( [ 'url' => 'https://api.example.com/echo', 'post' => 'a=1' ] );

  padPrefetch ( [ 'menu' => 'https://api.example.com/list?for=menu' ] );

  $summary = json_encode ( [
    'rates'  => [ $rates ['result'], $rates ['type'], $rates ['data'] ],
    'cached' => [ $cached ['result'], $cached ['cache'] ],
    'down'   => [ $down ['result'], $down ['data'] ],
    'echo'   => $echo ['data'],
  ], JSON_UNESCAPED_SLASHES );

  function httpFakeCalls () {
    return implode ( ' | ', array_map ( fn ( $call ) => $call ['method'] . ' ' . $call ['url'], padCurlRecorded () ) );
  }

?>
 
{!summary}
{data:menu}{$name}={$price} {/data:menu}
{pad:curl 'https://api.example.com/list.csv'/}
{pad:pad data='https://api.example.com/list?for=data'}{$name} {/pad:pad}
{php:httpFakeCalls/}
