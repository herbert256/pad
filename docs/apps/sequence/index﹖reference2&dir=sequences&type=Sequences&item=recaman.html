{meta title='Sequences'}

<p>The <code>{sequence}</code> tag generates values instead of reading them: a
range, a mathematical series, letters - over eighty types, each iterated like any data
tag:</p>

{example 'fragments/sequences_1'}

<p>That is the smallest corner of a whole subsystem: plays that keep, remove or flag terms,
stores that pass a sequence from one tag to the next, actions that transform it, and random
draws with their own rules. It has an application of its own, which is its manual:</p>

<p><b><a href="{$padHost}sequence/">The sequence application</a></b> - every type, play,
action and option, demonstrated live.</p>
<h2>Seeing and hearing them</h2>

<p>A sequence is data like any other, so {tag 'chart'} and {tag 'sparkline'} draw it
straight away with <code>sequence=</code>:</p>

{example 'fragments/sequences_2'}

<p>The sequence application has three pages built on that: the
<a href="{$padHost}sequence/?gallery">Gallery</a> draws every type beside the OEIS entry its
terms come from, <a href="{$padHost}sequence/?listen">Listen</a> plays a sequence as notes -
Recamán's is the famous one - in an audio file written into the page, and
<a href="{$padHost}sequence/?guess">Guess</a> shows the start of a sequence and asks for the
next term.</p>

App: sequence Page: gallery
PHP
gallery.php 		HTML
gallery.pad 		Result 
<?php

  // The gallery: every sequence type that needs no parameter, its first 24 terms drawn as a
  // {sparkline}, the first eight written out, and the OEIS entry the terms come from - a
  // link to oeis.org, found in the table the oeis type reads (seqFunOeis in _lib/fun.php).

  $drawn = [];

  foreach ( seqFunTypes () as $type ) {

    $terms = seqFunTerms ( $type, 24 );
    $oeis  = seqFunOeis ( $terms );

    $drawn [] = [
      'type'  => $type,
      'first' => implode ( ', ', array_slice ( $terms, 0, 8 ) ),
      'oeis'  => $oeis ? sprintf ( 'A%06d', $oeis ) : ''
    ];

  }

?>
 
<p>Every sequence type that needs no parameter, its first 24 terms drawn by
<code>{sparkline sequence=$type, rows=24}</code>, beside the
<a href="https://oeis.org">OEIS</a> entry the terms come from. Follow a name to hear it.</p>

<table cellpadding="4">
  {drawn}
    <tr>
      <td align="right"><a href="?listen&type={$type}">{$type}</a></td>
      <td>{sparkline sequence=$type, rows=24}</td>
      <td align="left"><small>{$first}, ...</small></td>
      <td>{if $oeis ne ''}<a href="https://oeis.org/{$oeis}">{$oeis}</a>{/if}</td>
    </tr>
  {/drawn}
</table>
App: sequence Page: guess
PHP
guess.php 		HTML
guess.pad 		Result 
<?php

  // Guess the next term: the first seven terms of a well-known sequence, picked at random,
  // and a form that asks for the eighth. The form sends back which sequence it was by its
  // place in the list (pick) with the guess; ?guess&pick=0 asks about a given one.
  //
  // pick and guess arrive from the request, so they are only used when they make sense:
  // a pick outside the list starts a new round, and a guess is compared as text, trimmed.

  $choices = seqFunGuessable ();

  if ( isset ( $pick ) and is_string ( $pick ) and ctype_digit ( $pick ) and isset ( $choices [ (int) $pick ] ) )
    $pick = (int) $pick;
  else {
    $pick  = random_int ( 0, count ( $choices ) - 1 );
    $guess = '';
  }

  $type     = $choices [$pick];
  $terms    = seqFunTerms ( $type, 14 );
  $shown    = implode ( ', ', array_slice ( $terms, 0, 7 ) );
  $next     = $terms [7];
  $rest     = implode ( ', ', array_slice ( $terms, 8 ) );
  $answered = ( isset ( $guess ) and is_string ( $guess ) and trim ( $guess ) !== '' ) ? 1 : 0;
  $right    = ( $answered and trim ( $guess ) === (string) $next ) ? 1 : 0;
  $oeis     = seqFunOeis ( $terms );
  $oeis     = $oeis ? sprintf ( 'A%06d', $oeis ) : '';

?>
 
{if $answered eq 1}

  {if $right eq 1}
    <p><b>Right!</b> The next term is {$next}.</p>
  @else@
    <p>Not this time - you said {$guess}, the next term is <b>{$next}</b>.</p>
  {/if}

  <p>It is <b>{$type}</b>{if $oeis ne ''}, <a href="https://oeis.org/{$oeis}">{$oeis}</a> in the OEIS{/if}:</p>
  <p>{$shown}, <b>{$next}</b>, {$rest} {sparkline sequence=$type, rows=14}</p>

  <p><a href="?guess">Another one</a> - or <a href="?listen&type={$type}">listen to it</a>.</p>

@else@

  <p>What comes next?</p>

  <h3>{$shown}, ?</h3>

  <form method="post" action="?guess">
    <input type="hidden" name="pick" value="{$pick}">
    <input name="guess" size="12" inputmode="numeric" autocomplete="off" autofocus>
    <button>Guess</button>
  </form>

{/if}
App: sequence Page: listen
PHP
listen.php 		HTML
listen.pad 		Result 
<?php

  // Listen: a sequence played as notes. Each of the first 32 terms becomes a note - the
  // term modulo 60, five octaves up from C2, the way the OEIS 'listen' button folds a term
  // into the keyboard - and the notes are written as a WAV file into the page itself
  // (seqFunWav in _lib/fun.php), so an <audio> element plays them without JavaScript.
  // Recamán's sequence, which jumps back and forth, is the famous one to listen to.
  //
  // type arrives from the query string and is used only when it names a type the gallery
  // draws.

  $choices = seqFunTypes ();

  if ( ! isset ( $type ) or ! is_string ( $type ) or ! in_array ( $type, $choices ) )
    $type = 'recaman';

  $terms = seqFunTerms ( $type, 32 );
  $oeis  = seqFunOeis ( $terms );
  $oeis  = $oeis ? sprintf ( 'A%06d', $oeis ) : '';
  $list  = implode ( ', ', $terms );
  $notes = implode ( ' ', array_map ( 'seqFunNoteName', seqFunNotes ( $terms ) ) );
  $audio = seqFunWav ( $terms );

?>
 
<p>{choices}{notFirst} | {/notFirst}{if $choices eq $type}<b>{$choices}</b>@else@<a href="?listen&type={$choices}">{$choices}</a>{/if}{/choices}</p>

<h3>{$type | ucfirst}{if $oeis ne ''} - <a href="https://oeis.org/{$oeis}">{$oeis}</a>{/if}</h3>

{chart 'line', data='terms', title='{$type | ucfirst}, the first 32 terms', width=640, height=220}

<p><audio controls preload="none" src="{$audio}"></audio></p>

<p>Each term is a note: the term modulo 60, counted in semitones up from C2.</p>

<p><small>{$list}</small></p>

<p><small>{$notes}</small></p>
