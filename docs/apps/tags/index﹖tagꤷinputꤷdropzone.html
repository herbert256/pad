Tags/Rich form fields/input:dropzone

{input:dropzone}

A file dropped on a frame or chosen, its name and size listed.

Rich form fields Single tags

Syntax 

{input:dropzone 'name', label='...'/}
{dropzone 'name', label='...'/}

Description

One of the 14 rich form fields of {pad:input}, written {input:dropzone 'name'/}, {dropzone ...}, bare, when no tag, field or store has the name.

A file dropped on a frame or chosen, its name and size listed: a native <input type="file"> in a frame a file can be dropped on - the whole frame its label, so a click opens the browser's file chooser as well. The form that holds it posts multipart by itself ({form} sees the file field), and the page's PHP takes the file with padUpload ( 'name', $types, $max ), whose refusal - a file too large, of a type the page does not take - the field shows as its message. accept= is the file field's own and says which files the chooser offers; a file dropped that it does not take is refused in the page, and so is one larger than limit= - '2M', '500K' - the size padUpload is handed too. multiple takes more than one, and then needs a name of a list - files[] - or PHP keeps the last file alone. A file field cannot be refilled, and its rules are padUpload's.

Example

A field of a form

As the inputs application's form writes it - its rules= left out, which the page's own template must hold.

Template 
{form 'try'}
  {input:dropzone 'resume', label='Your CV', accept='.pdf'/}
  <button>Send</button>
{/form}
Result
Your CV
