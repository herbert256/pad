● Any framework, one runtime

Islands of any kind
on one PAD page.

PAD writes the page and marks the places that move. A small runtime mounts a component on each - React here, Vue there, Svelte, Preact or Solid - and fetches a framework only when an island of it is on the page. Vite builds them; {pad:vite} links the build.
