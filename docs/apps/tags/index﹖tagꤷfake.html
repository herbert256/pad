Tags/Text and formatting/fake

{fake}

Makes a fake value - a name, an email, a price, an IBAN, 27 kinds - or rows of several kinds, the same on every request, for prototypes and previews.

Text and formatting Either form

Syntax 

{fake 'kind', seed=7/}
{fake:kind from=1, to=6/}
{fake 'name, email', rows=5, toData='store'/}
{fake 'field:kind, field:kind', rows=3} ... {/fake}

Parameters

kind
The kind, a file of pad/fakes/types/: address, boolean, city, colour, company, country, date, decimal, email, firstname, iban, ip, job, lastname, name, number, paragraph, phone, postcode, price, sentence, street, time, url, username, uuid, word - or several, each a field under its kind's name or as field:kind says. The fake type names one as well, {fake:email/}.

Options

rows
So many rows of the kinds - the level's data, for the content of the pair or for toData.
seed
Values of their own seed: the rows padFakeRows ( kinds, rows, seed ) gives.
from
number, decimal, price: the lowest value; date: the first moment (-1 year); time: the first clock time (08:00).
to
number, decimal, price: the highest value; date: the last moment (now); time: the last clock time (18:00).
format
date: the format of the moment, Y-m-d.
decimals
decimal: the places it is rounded to, 2.
chance
boolean: the chance of TRUE in percent, 50.
words
sentence: the number of words.
sentences
paragraph: the number of sentences.
name
email: the name the address is made from.

Description

{fake} makes values that look real enough for a prototype, a designer's preview or a demo page - a person's name, an address at example.org, a price, a date, an IBAN that passes the check of a bank that is not there - from the seeded sequence the padFake* helpers of seeders use. A kind is a file of pad/fakes/types/, a few lines that answer the value and read their options; a kind is added by adding its file.

One kind is the tag's value. Several kinds, rows= or a pair make rows: the level's data, iterated by the content or kept by toData=, each field under its kind's name - or as 'customer:name' names it. An email or a username in a row with a name is that person's. A FALSE of boolean is a miss, so the @else@ shows.

The values are the same on every request: the {fake} tags of a request share a sequence started from one seed, and seed= gives a tag values of its own - the rows padFakeRows ( 'name, email', 5, 7 ) gives in PHP. The page's own sequence, its padFakeSeed, is left where it was. The kinds are never reached bare - their names are the names of fields - only as the fake type, {fake:email/}.

Examples

A value of each kind

Single tags, the same on every request; options give the range.

Templateexamples/fake/1-values.pad 
<ul>
  <li>{fake 'name'/} - {fake:job/} at {fake 'company'/}</li>
  <li>{fake 'email'/}, {fake 'phone'/}</li>
  <li>{fake 'address'/}</li>
  <li>{fake 'number', from=1, to=6/} dots, {fake 'price', to=20/} euro, at {fake 'time'/}</li>
  <li>{fake 'iban'/}</li>
</ul>

Rows for a table

Several kinds and rows= make the data of the pair - the email of each row made from its name, seed= the same rows as padFakeRows.

Templateexamples/fake/2-rows.pad 
<table>
  <tr><th>Customer</th><th>E-mail</th><th>City</th><th>Total</th></tr>
  {fake 'customer:name, email, city, total:price', rows=4, seed=7}
  <tr><td>{$customer}</td><td>{$email}</td><td>{$city}</td><td>{$total}</td></tr>
  {/fake}
</table>

Rows into a data store

toData= keeps the rows for another tag - here a chart of fake numbers.

Templateexamples/fake/3-store.pad 
{fake 'month:word, visits:number', from=20, to=90, rows=6, seed=3, toData='visits'/}
{chart 'bar', data='visits', label='month', value='visits', width=360, height=180, title='Visits'/}
