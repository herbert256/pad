Every test here is an ordinary page, fetched over HTTP with &padInclude so it renders bare, and compared with the outcome written beside it. That makes it a real request, with a page's own .php half in scope for its .pad half. These tests live in apps/regression/pages/, which has _common switched off, so each one also proves it needs nothing but its own application; the pages that use _common are the Common suite.
