Tags/Chart types/chart:chord

{chart:chord}

Flows between the members of one group.

Chart types Either form

Syntax 

{chart:chord data='rows', label='field', value='field'/}
{chord data='rows', label='field', value='field'/}

Description

One of the 45 chart types of {pad:chart}, written {chart:chord .../}, {chart 'chord', .../}, {chord ...}, bare, when no tag, field or store has the name.

Flows between the members of one group: a node an arc around the circle as long as all that flows out of and into it, a ribbon per flow through the middle as wide as the flow, in the colour of its source; without value a row counts one. Options: source, target, value; width= and height=, 600 x 400 unless given.

Example

From the charts application

Its example relations/migration there, with the data it draws.

Templatecharts/relations/migration.pad 
{chart 'chord',
       source='from',
       target='to',
       value='people',
       title='Moves between regions in a year, in thousands',
       width=560,
       height=480}
  from,to,people
  North,South,42
  North,East,18
  North,West,25
  North,Capital,64
  South,North,30
  South,East,12
  South,Capital,48
  East,North,15
  East,West,9
  East,Capital,37
  West,North,21
  West,South,14
  West,Capital,29
  Capital,North,38
  Capital,South,52
  Capital,East,22
  Capital,West,31
{/chart}
