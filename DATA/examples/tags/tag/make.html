{make '1..5', add=10} runs a sequence in make mode: every value is replaced by what the named type makes of it - here 11 12 13 14 15. The arithmetic types take their operand as the option's value (add, subtract, multiply, divide, modulo, exponentiation, ...); other types turn a position into a term, so {make '1..6', prime} is the first six primes and {make '1..5', square} is 1 4 9 16 25. It is the same run as {sequence '1..5', make, add=10}.

Several makes apply in the order written: {make '1..5', add=10, multiply=2} adds first and doubles after, 22 24 26 28 30. A stored sequence named bare works as the source - the store itself is not changed; to rewrite it in place use {resume}.

Make is the default mode of a sequence run, so with only a type {make:fibonacci rows=8} simply generates that sequence, the same as {sequence fibonacci, rows=8}. Compare {keep}, {remove} and {flag}, the other three play modes.
