The regression tests of the PAD framework. Every suite fetches real pages over HTTP - Pages from regression/pages, which runs with _common switched off, Common from regression/common, the pages that use it, and Framework from regression/framework, where every engine case is a page of its own; Errors from regression/errors, the tests that fail on purpose; and Regression, Sequence, Manual and Other fetch every page of the remaining applications and compare each with the prediction of the same name in their store. Each line reports the last run - Test on a suite's own page reruns it.
