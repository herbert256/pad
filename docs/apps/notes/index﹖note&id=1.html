Welcome to Notes

Changed 1 Oct 2026 Written 1 Oct 2026 #offline#pad

Notes is a PAD application that keeps everything in one SQLite database.

  • On a server it is the file DATA/notes/notes.sqlite.
  • Packed with pad pack notes it runs in your browser, with no server at all: PHP compiled to WebAssembly answers every page, and the database is kept in the browser between visits.
  • Served over https it installs as an application and works offline.

Write in Markdown, tag a note, attach a picture or a PDF, pin what matters. The Backup page takes all of it with you - as JSON, or as the database file itself.
