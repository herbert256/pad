# Dynamic arrays

`FILTER(array, include, [if_empty])`, `SORT(array, [index], [order], [by_col])` and `UNIQUE(array, [by_col], [exactly_once])` return dense matrices. `FILTER` accepts a row or column Boolean/numeric mask; comparisons and arithmetic over ranges work inside dynamic function arguments, including `FILTER(A1:B5,(B1:B5>2)*(B1:B5<9))`. `SORT` is stable and uses the formula engine's scalar ordering; errors in its input propagate. `UNIQUE` compares complete rows (columns with by_col), case-insensitively for text and without coercing text to numbers. Array arguments/results are limited to 10,000 cells. General legacy formulas keep implicit scalar intersection.

A dynamic formula owns its top-left anchor and writes its remaining cells as generated, read-only spill cells. Any occupied literal or formula in that rectangle produces `#SPILL!`, with no partial writes. Blank cells may be used. Empty FILTER/UNIQUE results produce `#CALC!`; FILTER's explicit fallback is returned instead when supplied. Generated cells are rebuilt on every computation. References to generated cells depend on their anchor; the dependency graph is re-evaluated until spill ownership stabilizes, bounded to 128 passes. Cycles, including cycles through spill children, produce `#REF!`; an unstable output footprint produces `#CALC!`. A spill is bounded by worksheet dimensions as well as the cell limit.

`padFormula()` exports a dynamic result as rows of values. `padSheet()` includes generated cells in its existing named-cell or row representation. Grid and record views use the same evaluator. `sheet:record` maps `labels=['B1'=>'Quantity']` to stable spreadsheet addresses; `editable` defines input cells and all others are outputs. Cell addresses stay visible and field edits use the existing server post/recalculation contract.

SLOPE, INTERCEPT, RSQ, COVARIANCE.P and COVARIANCE.S align equally shaped ranges before dropping pairs containing text, blanks or logical values. Errors propagate. Slope/intercept use known_y followed by known_x; covariance is symmetric. The shared statistics kernel centers observations with shifted-origin compensated sums, then this layer scales deviations before accumulating moments; unrepresentable outputs return `#NUM!`.
