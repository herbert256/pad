Tags/Chart types/chart:rose

{chart:rose}

Nightingale's polar area chart.

Chart types Either form

Syntax 

{chart:rose data='rows', label='field', value='field'/}

Description

One of the 51 chart types of chart:*, written {chart:rose data='rows', label='field', value='field'/}.

Nightingale's polar area chart: a wedge per row of one angle, the first centred on twelve o'clock, its area its value (radius by the square root); several value fields lie outward as rings, a colour each with a legend; names around the circle, rings of round numbers. Options: label, value; width= and height=, 480 x 280 unless given.

Example

From the charts application

Its example radial/nightingale there, with the data it draws.
