<p>A folder of Markdown files is a data source - a small flat-file CMS. The files live in
<code>_content/&lt;name&gt;/</code>, and <b>{collection}</b> iterates them: each file is a
row, the keys of its front matter (YAML between two <code>---</code> lines) are its fields,
and three are added - <code>slug</code>, the file name without <code>.md</code>;
<code>body</code>, the Markdown written as HTML; and <code>source</code>, the Markdown as it
was.</p>
