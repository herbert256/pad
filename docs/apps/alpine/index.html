PAD + Alpine
Examples Guide
● Behaviour in the markup

PAD writes the page.
Alpine wakes it up.

Alpine adds behaviour to HTML with a few attributes - and PAD writes that HTML. Both like braces, so the trick is to let each have its own: PAD hands Alpine its state as JSON with the ^ sigil, and longer components live in a file of www/.

Start with state from PHP Braces, data and requests 
<div x-data="{^profile}">          <!-- $profile from the page's PHP -->
  <h2 x-text="name"></h2>
  <button @click="likes++">
    ♥ <span x-text="likes"></span>
  </button>
</div>

The template holds no brace of Alpine's: the state is the JSON of a PHP array.
