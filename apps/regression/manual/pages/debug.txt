<h1>Inline debug</h1>

<p><b>{debug}</b> shows a value as a collapsible tree in the page, where the template uses
it, and the rendering goes on - unlike <b>{dump}</b>, which stops the request.</p>

<ul>
  <li><code>{debug $name}</code> - one value; an array is a tree to unfold, a missing name says so.</li>
  <li><code>{debug}</code> - every field visible where it stands: the rows of the enclosing levels, innermost first, and the application's variables.</li>
  <li>Only a local request sees it: the command line, or this machine asking itself with nothing forwarded. Anyone else gets nothing, and <code>$padDiagnostics = FALSE</code> switches it off for everyone.</li>
</ul>
