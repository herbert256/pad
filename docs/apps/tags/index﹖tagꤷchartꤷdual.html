Tags/Chart types/chart:dual

{chart:dual}

Two measures on two axes.

Chart types Either form

Syntax 

{chart:dual data='rows', label='field', value='field'/}

Description

One of the 51 chart types of chart:*, written {chart:dual data='rows', label='field', value='field'/}.

Two measures on two axes: value as bars on the left axis, line as a line with ringed points on the right one, each axis's ticks in its series' colour and the right ticks on the left's grid lines when their zeros can line up; a legend names both. Options: label, value, line; width= and height=, 600 x 300 unless given.

Example

From the charts application

Its example finance/margin there, with the data it draws.
