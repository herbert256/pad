<p>It is possible to process the data from a <b>{tag}</b> before it is used by PAD to construct the output.
<p>This is done by using one of the below options.
<p>dedup, end, first, group, last, page, random, reverse, row, rows, shuffle, slice, sort, splice, start, trim, where
