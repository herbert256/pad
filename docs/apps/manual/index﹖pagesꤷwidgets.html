Widgets

{widget:tabs} puts an interactive part on the page - tabs, an accordion, a carousel, a modal, a dropdown, a toast and more, 17 of them. Every one is built on the server and works without JavaScript; where a widget has a script it only makes it handier, and it is written once per page with the CSP nonce. Every widget is a file of pad/subs/widgets/types/, and the files there are the widgets there are.

PHP
 HTML
fragments/widgets_1.pad 		Result 
{widget:tabs active='Specs'}
  {pad:tab 'Overview'}<p>A kettle in steel.</p>{/pad:tab}
  {pad:tab 'Specs'}<p>1.7 litres, 2200 W.</p>{/pad:tab}
  {pad:tab 'Delivery'}<p>Tomorrow.</p>{/pad:tab}
{/widget:tabs}

Select a widget

The qualified name selects the widget, and its first parameter is the widget's own value: {widget:toast 'Saved'/}.

PHP
 HTML
fragments/widgets_2.pad 		Result 
{widget:toast 'The widget tag', tone='success'/}
{widget:toast 'The widget: type'/}

What the browser does itself

Each widget stands on what HTML and CSS can do: radio buttons and CSS for tabs and the wizard, <details> for the accordion, a <dialog> for the modal, the drawer and the toast, the popover attribute for the dropdown, :hover and :focus-within for the tooltip, :target for the carousel's links and the lightbox, the CSS resize grip for a split pane. The keyboard works because the browser's own controls are underneath; the scripts add the arrow keys of a menu, Escape on a tooltip, the focus of a lightbox, the bar of a split pane.

PHP
 HTML
fragments/widgets_3.pad 		Result 
{widget:dropdown 'Sort'}
  <a href="?pages/widgets">By name</a>
  <a href="?pages/widgets">By price</a>
{/widget:dropdown}
<div>The {widget:tooltip 'Billed monthly'}Starter{/widget:tooltip} plan.</div>

Items made by a loop

Tabs, an accordion, a carousel, a wizard and a lightbox take {pad:tab} items. A tab hands its content to the nearest of them above it, so it may stand in an {pad:if} or in a loop over data - a step per row of a {pad:data} store here.

PHP
 HTML
fragments/widgets_4.pad 		Result 
{pad:data 'steps'}
  ["Order", "Pack", "Deliver"]
{/pad:data}
{widget:wizard}
  {data:steps}
    {pad:tab $steps}<p>{$steps}.</p>{/pad:tab}
  {/data:steps}
{/widget:wizard}

Order.

Pack.

Deliver.

  • The colours are custom properties on .pad-<widget> - --pad-tabs-accent, --pad-toast-success and their like - with light and dark defaults.
  • {widget:copy} runs the copy widget; {pad:tab} is a built-in tag too.
  • A name that is no widget, an unknown option value and a widget without what it needs - a name, a label, a tab - are errors under the strict check.
