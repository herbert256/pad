Tags/Charts and codes/barcode

{barcode}

Draws a barcode as inline SVG, encoded on the server - 13 symbologies, from EAN-13 and Code 128 to QR and Data Matrix.

Charts and codes Single tags

Syntax 

{barcode 'number'/}
{barcode $code, type='code128', height=60, scale=2, title='text', plain, color='#000', background='#fff'/}
{barcode:ean13 'number'/}
{code39 'TEXT', check/}
{barcode $text, type='datamatrix', size=160/}

Parameters

code
The number or text. An EAN or UPC number may leave its check digit off - it is added; one given is checked.

Options

type
The symbology, a file of pad/codes/types/: codabar, code128, code39, code93, datamatrix, ean13, ean8, itf, itf14, msi, qr, upca, upce. Left out, twelve or thirteen digits are an EAN-13 and anything else Code 128. The barcode type names it as well - {barcode:upce '0425261'/}, or bare, {itf14 '1540014128876'/}, when nothing else has the name.
height
The height of the bars in pixels, default 60.
scale
The width of one module - the thinnest bar - in pixels, default 2 (1 to 10).
title
The accessible name, by default the code.
plain
Bare option: the bars only, no digits under them.
color
The colour of the bars, default #000.
background
The colour behind them, default #fff.
check
Bare option, code39: the check symbol of modulo 43; itf: the check digit of weights 3 and 1. For msi it names the check digits: mod10 (default), mod1010 or none.
size
qr and datamatrix: the width and height in pixels, default 160 - they take no height, scale or plain.
level
qr: the error correction, L, M (default), Q or H.

Description

{barcode} encodes its first parameter as a barcode and writes it as inline SVG - the bars of a product, a ticket, a carton or a parcel label, or the squares of a Data Matrix, drawn on the server, no font or image needed. It is the codes subsystem of PAD (pad/codes/): a symbology is a file of pad/codes/types/, and type names it.

The symbologies

  • Products - ean13, ean8, upca and upce: digits with a check digit of weights 3 and 1, which may be left off - it is then computed and added - and is checked when given. The guard bars are drawn longer and the digits set under the bars in their groups. A UPC-E stands for a UPC-A with its zeros left out; given the 11 or 12 digits of a UPC-A, upce writes its short form when it has one.
  • Text - code128 takes printable ASCII and packs a run of four digits or more two to a symbol; code93 takes printable ASCII too, the characters Code 39 lacks as pairs; code39 digits, capital letters, space and - . $ / + %, with check for its check symbol.
  • Digits - itf (Interleaved 2 of 5, check for its check digit), itf14 (the GS1 number of a carton, between bearer bars), codabar (digits and - $ : / . + between the start and stop letters A to D, A at both ends when the text has none) and msi (a Luhn check digit, or check='mod1010' or 'none').
  • Two-dimensional - qr, the code of {qr}, and datamatrix, Data Matrix ECC 200 in the smallest of its 24 square sizes: any text - one beyond ASCII marked as UTF-8 (ECI 26) - size in pixels in place of height, scale and plain.

Without type the tag decides by the text: twelve or thirteen digits are an EAN-13, anything else Code 128. The barcode type writes a symbology by its name, {barcode:upce '0425261'/}, and so does the name alone, {itf14 '1540014128876'/}, when no tag, store, field or sequence has it.

scale is the width of the thinnest bar; keep it at 2 or more for a printed label a scanner has to read. plain leaves the human-readable text out. The colours are fixed - black on white unless color and background say otherwise - since a scanner needs the contrast.

A wrong check digit, a wrong length for the type, a character the symbology cannot hold, a text too long for it or an unknown type is an error under the strict check, and the tag writes nothing.

Examples

An EAN-13 with its check digit added

Twelve digits are taken as an EAN-13; the thirteenth, the check digit, is computed.

Templateexamples/barcode/1-ean.pad 
{barcode '871234567890'/}
Resultopen alone

Code 128 for a parcel

Text with letters is Code 128; height and scale size the bars.

Templateexamples/barcode/2-code128.pad 
{barcode 'PAD-2026-00042', type='code128', height=50, scale=1.5/}
Resultopen alone

Plain and coloured

plain leaves the digits out; color and background change the black on white.

Templateexamples/barcode/3-plain.pad 
{barcode '96385074', type='ean8', plain, color='#1a237e'/}
Resultopen alone

Three ways to name a symbology

type= on the tag, the barcode type, or the name alone when nothing else has it - one code.

Templateexamples/barcode/4-types.pad 
{barcode '0425261', type='upce'/} {barcode:upce '0425261'/} {upce '0425261'/}
Resultopen alone

Text and digits

Code 39 with its check symbol, Code 93 with small letters, Interleaved 2 of 5, Codabar and MSI.

Templateexamples/barcode/5-symbologies.pad 
<p>{code39 'PAD-2026', check, height=40/}</p>
<p>{code93 'Pad-2026!', height=40/}</p>
<p>{itf '1234567', check, height=40/}</p>
<p>{codabar 'A40156B', height=40/}</p>
<p>{msi '1234567', height=40/}</p>
Resultopen alone

Data Matrix

The square code of parts and parcels: the smallest of its 24 sizes that holds the text.

Templateexamples/barcode/6-datamatrix.pad 
{datamatrix 'PAD-2026-0042', size=120/} {barcode 'https://example.com/order/42', type='datamatrix', size=120/}
Resultopen alone
