<p><code>{map}</code> draws countries filled by a value of their row - a choropleth - as
inline SVG on the server (<code>lib/map.php</code>), from Natural Earth's outlines kept in
PAD itself: no JavaScript, no map tiles, no remote service. The first parameter picks the
view: the whole world, or a crop of the same projection at full detail for a continent. An
unknown view is an error under the strict check.</p>

<p>The rows come from <code>data=</code> as for <a href="?tag/chart">{chart}</a>, or from the
content of the pair - JSON, YAML, XML or CSV, read before the level walks it. <code>key</code>
names the country, written as an alpha-2 code (<code>NL</code>), an alpha-3 code
(<code>NLD</code>) or the English name; <code>value</code> the number. Rows of one country
add up. A key that is no country is not drawn but named in the title
(<code>not on the map: ...</code>), so a typo shows instead of disappearing.</p>

<p>The values are put in seven colour steps - the heatmap's <code>--pad-chart-heat-0</code> to
<code>-6</code> - with a scale under the map. <code>scale='linear'</code> spaces the steps
evenly between the lowest and highest value; <code>scale='quantile'</code> gives each step
the same number of countries, which keeps a few very large values from washing out the rest.
A country without a value is <code>--pad-map-empty</code>, and a map without any data is
drawn all in grey.</p>

<p>Every country has a <code>&lt;title&gt;</code> - <code>Netherlands: 1,234</code>, the
tooltip on hover - and the <code>&lt;desc&gt;</code> lists the values for a screen reader.
Countries too small to keep an outline at the scale drawn are shown as small diamonds. For a
single flag, see <a href="?tag/country">{country}</a>.</p>
