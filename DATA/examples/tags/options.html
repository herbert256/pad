Tags by option

Every option a tag takes of its own, and what it does there. The handling options every tag takes - sort, where, first, rows, group and the rest - are not listed here.

OptionTagMeaning
access{meta}Kept for access rules to read with padMeta ( 'access' ).
action{pull}Any sequence action written as an option (or named with action='last|2'), applied to the stored values in the order written: reverse, sort, sum, first=3, last=3, append='other', ... shift=n and pop=n also take the values out of the store.
{resume}Any sequence action, as an option of its own or named with action='reverse' - reverse, sort, sum, first=3, ... - or a play with a type: add=10 (make), keep, prime, remove, even, flag, odd.
{sequence}Names an action explicitly, its value after a |: action='first|3'. Usually the action is written as an option of its own, applied to the result in the order written: sum, average, median, count, reverse, sort, shuffle, dedup, first=n, last=n, append='store', ...
active{tabs}The tab shown first: its number counted from 1, or its label. The first tab when not given.
ajax{page}With app=: ajax=false fetches the other application's page on the server and inserts its body instead of leaving it to the browser.
alt{gravatar}The image text - the person's name - default Avatar.
{img}Required: the text for whoever cannot see the picture. alt='' marks it as decoration.
app{ajax}A page of another application; under the strict check it must exist there.
{page}A page of another application. It cannot be built in this process, so it is fetched over HTTP - by the browser by default (as {ajax} does).
arrow{chess}Arrows from square to square, separated by commas: 'e2-e4, g1-f3'.
arrows{chart}Bare option, network: draws the direction of the links.
background{barcode}The colour behind them, default #fff.
{qr}The light colour, default #fff.
bands{chart}Gauge and bullet: thresholds that split the track into coloured or grey steps ('60, 85').
bandwidth{chart}Density, violin: the width of the kernel, else Silverman's rule.
base{files}What the directory is relative to: app (the application), data (DATA/) or pad (the path as given); otherwise the file system root. It must lie inside the applications, the engine or DATA.
bcc{mail}Blind copy addresses.
bins{chart}Histogram: about how many bins (10).
button{modal}The text of the button that opens the dialog, Open when not given.
{poll}The text of the vote button, Vote when not given.
by{chart}Multiples: the field that splits the rows into small charts.
cache{meta}The page's own server-cache time in seconds, in an application with the page cache on; 0 or false keeps the page out of the cache.
caption{datatable}The table's <caption>.
cc{mail}Copy addresses.
cells{chart}Waffle: the number of squares (100).
checked{input}Bare option: a checkbox or radio is checked before a post.
children{tree}The field of a row that holds its children, at every depth. Default children.
clean{code}Bare option: the pass sees everything around it, but every variable it creates or changes is undone afterwards.
{page}Bare option: the page sees everything around it, but whatever it creates or changes is undone afterwards.
client{form}Bare option: check the rules= of the fields in the browser too, with the same messages - the form gets novalidate, data-pad-rules and the checker script.
color{barcode}The colour of the bars, default #000.
{chart}Scatter, bubble, gantt, parallel: a field whose values colour the marks, with a legend.
{progress}A colour slot: accent (default), success, warning, danger or neutral.
{qr}The dark colour, default #000.
{timeline}A field that groups the events: a colour each and a legend.
columns{chart}Multiples: the number of small charts side by side.
{datatable}The fields shown, in their order. Every field of the first row when not given.
cookies{curl}An array of cookies to send.
count{trans}Picks the plural form of a text with | between its forms, and replaces %d in it.
css{shadow}Stylesheets inlined as one <style> at the start of the root, separated by commas: a .css file of the application, or www: one of its www/ directory.
data{calendar}The events: a {data} store, a page array or a _data file, as for {chart}.
{chart}The rows: a {data} store, a sequence store, the page's array or a _data file of that name, or a literal (data='[3,1,4]'). Left out on a pair, the content is the data.
{datatable}The rows: a {data} store, a page array or a _data file. As a pair the content is the rows instead - JSON, YAML, XML or CSV, told apart on sight.
{jsonview}Names the value instead: a {data} store, a page array or a _data file.
{map}The rows: a {data} store, a page array or a _data file, as for {chart}. As a pair the content is the rows - JSON, YAML, XML or CSV.
{sparkline}The rows: a {data} store, a sequence store, an array of the page (or a field of the current row holding a list) or a _data file of that name, or a literal (data='[3,1,4]'). Left out on a pair, the content is the data.
{timeline}The rows: a {data} store, a page array or a _data file, as for {chart}. As a pair the content is the rows - JSON, YAML, XML or CSV.
date{calendar}The field with an event's date - by default the first field that reads as one.
{chart}Calendar: the field with the day.
{file}Bare option: _Y-m-d of today added to the name.
{timeline}The field of a moment: a year (1969), a month (2026-10) or anything strtotime reads - else the first field that reads as one.
default{gravatar}What Gravatar shows for an address it does not know: mp (default), identicon, monsterid, wavatar, retro, robohash, blank, 404, or an https:// image address.
dir{file}The directory below DATA/; none writes in DATA/ itself.
direction{diagram}TB (default), BT, LR or RL - else a first line graph LR or flowchart LR names it.
download{pdf}Bare option: sent as an attachment (Content-Disposition: attachment) instead of shown inline.
edges{diagram}How a flowchart's edges run: orthogonal (default, rounded turns), straight or curved.
ellipsis{excerpt}What stands for the text that was cut off, default ….
error{form}The message shown above the fields, in <div class="error" role="alert">, when the form came back with errors. Bare option: Please correct the errors below.
exclude{files}Leave out the names that match this shell pattern.
ext{file}The extension, ext by default.

file{highlight}A file of the application to show instead of the content - never one outside it, under _config/ or a dotfile.
{pdf}The file name of the document, default the page's name (.pdf is added).
files{source}Files after the page's, a text with commas: a file of the application, or www: one in its www/ directory.
fit{img}cover (default: fill the box, cut around the centre) or contain (all of the picture inside the box).
flip{chess}Bare option: turn the board, Black at the bottom.
fluid{placeholder}Bare option: as wide as the container (width="100%"), the height following from the proportions.
focus{shadow}Bare option: adds shadowrootdelegatesfocus.
font{pdf}helvetica (default), times or courier - code is always Courier.
format{countdown}The PHP date format of the full moment in the title, default l j F Y, H:i.
{datatable}A pipe per column, column:pipe separated by commas - total:money, date:date('j M').
{img}jpeg, png or webp - default the source's, a GIF becoming a PNG.
{timeago}The PHP date format of the full moment in the title, default l j F Y, H:i.
{timeline}A PHP date format for the dates written - else by the date's precision (1969, Oct 2026, Oct 8, 2026).
fragment{ajax}Ask the page for one of its response fragments alone - &padFragment=name - instead of the whole page.
from{chart}Gauge: the start of the scale (0). Gantt: the field with the start of a task.
{diff}The name of the old version - a column head side by side, a caption in one column.
{mail}The sender, $padMailFrom by default.

function{code}Runs the pass inside a PHP function of that name, giving it a variable scope of its own; what it creates is copied out afterwards (not with sandbox).
{page}Runs the page inside a PHP function of that name, so its PHP has a scope of its own; what it creates is copied out unless sandbox is given too.
{sandbox}Runs the pass inside a PHP function of that name, with a variable scope of its own; being sandboxed, nothing is copied out.

headers{curl}An array of request headers.
height{barcode}The height of the bars in pixels, default 60.
{chart}The height in pixels, default 300 (round kinds 280, the tall kinds 400, gauge 200, calendar 150).
{img}The height of the box in CSS pixels.
{map}The height in pixels; by default it follows from the view.

{timeline}The height in pixels; by default it follows from the cards (not in the vertical form).
highlight{chess}Squares to mark, separated by commas: 'e2, e4'.

html{collection}Bare option: raw HTML in the Markdown bodies is let through. By default it is escaped.
{excerpt}Bare option: the text is HTML - its tags (and the content of script and style) are dropped and its entities read before it is cut.
{markdown}Bare option: let the author's own raw HTML through - inline tags, and a block-level element or comment at the start of a line up to the next blank line. Without it raw HTML is escaped.
icon{rating}star (default) or heart.

includeHidden{files}Bare option: names starting with a dot too.
