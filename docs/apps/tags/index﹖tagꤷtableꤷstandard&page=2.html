Tags/Tables/table:standard

{table:standard}

Rows as a formatted table with totals, column filters, sorting and paging.

Tables Either form

Syntax 

{table:standard data='rows'/}

Description

One of the 4 tables of table:*, written {table:standard data='rows'/}.

Rows as a formatted table with totals, column filters, sorting and paging.

Example

The standard table

A complete working example.

Templateexamples/table/standard.pad 
{table:standard totals='amount', sortable, rows=3, filters='region', caption='Sales'}
region,quarter,amount
North,Q1,120
South,Q1,90
North,Q1,30
North,Q2,180
South,Q2,110
