    <h2 id="install">Installation</h2>
    <p>Clone the repository and point the web server at <code>www/</code>.</p>
    <h3 id="requirements">Requirements</h3>
    <p>PHP 8.1 or newer; a database only when the application uses one.</p>
    <h4 id="extensions">Extensions</h4>
    <p>mbstring is required, intl is used when it is there.</p>
    <h3 id="first-run">First run</h3>
    <p>Open the hello application to see a page and its template.</p>
    <h2 id="configuration">Configuration</h2>
    <p>Settings stand in <code>_config/config.php</code> and in <code>.env</code> files.</p>
    <h3 id="error-handling">Error handling</h3>
    <p>Choose what happens when something goes wrong: a page, a log line or a dump.</p>
    <h2 id="deployment">Deployment</h2>
    <p>Copy the files; there is no build step.</p>
