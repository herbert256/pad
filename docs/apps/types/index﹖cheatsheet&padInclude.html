Cheat sheet

How every tag type and subsystem family is used, by group.

Tags

app: A tag of the application, a file of a _tags/ directory from the page up to the root. 
{app:greeting name='Ann'/}
common: A tag or a snippet of the shared _common application. 
{common:demo}...{/common:demo}
{common:padFrame}...{/common:padFrame}
define: A tag defined in the template by {pad:define} - its body the template of the tag. 
{pad:define 'hello'}Hello {#name}{/pad:define}
{define:hello name='Ann'/}
function: A pipe function used as a tag, over the content between its tags. 
{function:upper}shout{/function:upper}
include: A snippet of the application, a file of an _include/ directory. 
{include:card/}
macro: A tag defined in the template by {pad:macro} - its body rendered once with the options as its fields. 
{pad:macro 'card', title}<b>{$title}</b>{/pad:macro}
{macro:card title='One'/}
pad: A built-in tag of the engine - a file of pad/tags/. 
{pad:if $count gt 0}...{/pad:if}
php: A PHP function called as a tag, its parameters the function's arguments. 
{php:strtoupper 'abc'/}
{pad:echo php:strtoupper('abc')/}
script: A shell script of a _scripts/ directory, its output the tag's. 
{script:backup/}

Stores and data

bool: A boolean store - a flag set by {pad:bool}, its pair showing when it is true. 
{bool:isAdmin}...@else@...{/bool:isAdmin}
{bool:isAdmin}...{/bool:isAdmin}
content: A content store - a piece of template kept by {pad:content} to be shown elsewhere. 
{content:footer/}
data: A data store - rows kept by {format:auto} or a file of _data/ read through the format registry. 
{data:colors}{$colors} {/data:colors}
local: A data file of a _data/ directory, read by its file name. 
{local:menu.json}{$label}{/local:menu.json}
pull: A stored sequence - the terms a {sequence:*} pushed to the store under a name. 
{pull:nums}{$sequence} {/pull:nums}
select: A table declared in $padSelect - its rows read from the database, joins and all. 
{select:users}{$name}{/select:users}

Values of the page

array: An array of the current row or of the page, its elements the rows of the tag. 
{array:items}{$items} {/array:items}
constant: A PHP constant, by its name. 
{constant:PHP_INT_SIZE/}
field: A field of the current row, or a variable of the page. 
{field:name/}
{$name}
level: An array field of a row of an enclosing tag, its elements the rows of the tag. 
{level:kids}{$name}{/level:kids}
parm: A parameter or option of the tag around it, read by its name. 
{parm:label/}
{#label}
property: A property of the tag around it - its count, its current row, whether it is the first. 
{property:count/}
{&count}

Sequences

action: A sequence action - reverse, sort, sum, first ... - over the terms it is given. 
{action:reverse '1..5'}{$sequence} {/action:reverse}
{pull:nums reverse}{$sequence} {/pull:nums}
flag: Every term a 1 or a 0: whether it belongs to the sequence type named. 
{flag:prime rows=8}{$sequence} {/flag:prime}
keep: The terms that belong to the sequence type named, the others left out. 
{keep:prime rows=5, from=10}{$sequence} {/keep:prime}
make: The terms of a sequence type, made as a play - the same terms {sequence:x} gives. 
{make:fibonacci rows=8}{$sequence} {/make:fibonacci}
remove: The terms that do not belong to the sequence type named. 
{remove:prime rows=6}{$sequence} {/remove:prime}
sequence: A sequence type of the sequence subsystem, its terms the rows of the tag. 
{sequence:fibonacci rows=10}{$fibonacci} {/sequence:fibonacci}
sequence:fibonacci(8)

Subsystems

ai: Text and validated JSON responses. 
{ai:anthropic 'Name three rivers.'/}
avatar: An identity picture: initials, identicons, rings, mosaic, pixelbot, Gravatar, geometric art or a photograph with a local fallback. 
{avatar:initials 'Ada Lovelace'/}
{avatar:geometric 'ada', style='rings'/}
barcode: A barcode symbology, a file of pad/subs/codes/types/, encoded on the server. 
{barcode:ean13 '400638133393'/}
{barcode:ean13 '400638133393'/}
calendar: A Gregorian calendar view from pad/subs/calendars/types/ - days, weeks, months, quarters, years and agendas. 
{calendar:month '2026-11'/}
{calendar:week '2026-11-02'/}
{calendar:year '2026'/}
chart: A chart type, a file of pad/subs/charts/types/, drawn as inline SVG. 
{chart:pie data='rows', label='name', value='amount'/}
{chart:pie data='rows', ...}
{chart:pie data='rows', .../}
diagram: A diagram type, a file of pad/subs/diagrams/types/, laid out on the server. 
{diagram:state}...{/diagram:state}
{diagram:state}...{/diagram:state}
diff: A comparison of texts, JSON or keyed records from pad/subs/diffs/types/. 
{diff:words $old, $new/}
{diff:json $old, $new/}
{diff:rows $old, $new, key='id'/}
effect: An effect, a file of pad/subs/widgets/effects/types/ - motion and decoration, CSS first, still under reduced motion. 
{effect:typewriter}Hello{/effect:typewriter}
{effect:typewriter}Hello{/effect:typewriter}
embed: An embed provider, a file of pad/subs/embeds/types/ - loaded only on a click. 
{embed:youtube 'aqz-KE-bpKQ', title='Big Buck Bunny'/}
{embed:auto 'https://youtu.be/aqz-KE-bpKQ'/}
{embed:youtube 'aqz-KE-bpKQ'/}
fake: A fake kind, a file of pad/subs/fakes/types/ - the same values for the same seed, never bare. 
{fake:email/}
{fake:email/}
{fake:rows 'name, email', rows=3}...{/fake:rows}
format: Read documents into named data stores. 
{format:json 'rows'}[1,2,3]{/format:json}
game: A game, a file of pad/subs/games/types/, played in the browser. 
{game:memory pairs=6/}
{game:memory/}
{game:memory/}
holidays: Country and regional public holidays. 
{holidays:nl year=2026/}
icon: An icon, a file of pad/subs/icons/types/, drawn as inline SVG - never bare. 
{icon:star size=24/}
{icon:star size=24/}
image: Local images as thumbnails, responsive pictures, captioned figures or contact sheets. 
{image:thumbnail 'photo.jpg', width=320, alt='A landscape'/}
{image:picture 'photo.jpg', widths='320,640,960', alt='A landscape'/}
input: A rich form field, a file of pad/subs/inputs/types/, posted by any form. 
{input:slider 'volume', label='Volume'/}
jsonld: A JSON-LD kind, a file of pad/subs/jsonld/types/ - the structured data of a page as a Schema.org object, never bare. 
{jsonld:article headline=$title, author=$author/}
{jsonld:article data='post'/}
{jsonld:faq data='questions'/}
map: Choropleths, markers and proportional bubbles. 
{map:europe width=540/}
notation: A notation, a file of pad/subs/notations/types/ - a formula, a tune, a word or a position drawn on the server. 
{notation:braille 'Hello'/}
{notation:braille 'Hello'/}
{notation:math}a/b{/notation:math}
pattern: A pattern, a file of pad/subs/images/patterns/types/ - a seeded SVG background, never bare. 
{pattern:topography seed=7/}
{pattern:topography seed=7/}
printable: A printable, a file of pad/subs/printables/types/ - pages made for paper, the same on the screen, printed and as a PDF, never bare. 
{printable:labels data='rows', sheet='a4-3x8'}...{/printable:labels}
{printable:labels data='rows'}...{/printable:labels}
search: Ranked search, exact filters and facets. 
{search:en 'documents', q='PAD'/}
section: A section of a landing page, a file of pad/subs/widgets/sections/types/ - pure CSS, coloured by the theme, never bare. 
{section:hero title='Build faster'}...{/section:hero}
{section:hero title='Build faster'}...{/section:hero}
sheet: Formula grids computed on the server. 
{sheet:grid}Name,Amount
One,12
Two,=B2*2{/sheet:grid}
sound: A sound, a file of pad/subs/sounds/types/ - a recipe the browser plays and the server writes as a WAV, never bare. 
{sound:chime/}
{sound:chime/}
{sound:pop on='click', target='#save'/}
table: A table of rows, grouped records, a pivot or a matrix from pad/subs/tables/types/. 
{table:standard data='orders', sortable/}
{table:grouped data='orders', group='region', totals='amount'/}
time: Time displays from pad/subs/calendars/times/types/ - countdown, relative time, world clocks and stopwatches. 
{time:countdown '2026-12-31', live/}
{time:relative '2026-11-01'/}
{time:clock timezone='Europe/Amsterdam'/}
{time:stopwatch/}
timeline: Event views from pad/subs/charts/timelines/types/ - horizontal, vertical, roadmap and swimlane. 
{timeline:horizontal data='events'/}
{timeline:roadmap data='events', lane='team'/}
{timeline:swimlane data='events', lane='team'/}
toy: A toy, a file of pad/subs/games/toys/types/ - a live simulation in the browser. 
{toy:life pattern='glider'/}
{toy:life/}
{toy:life/}
widget: A widget, a file of pad/subs/widgets/types/, that works without JavaScript. 
{widget:tabs}{widget:tab 'One'}...{/widget:tab}{/widget:tabs}
{widget:tabs}...{/widget:tabs}
{widget:tabs}...{/widget:tabs}

Options and helpers

Notification channels Delivery channels selected in the fourth argument of padNotify. 
padNotify ( $recipient, 'order-shipped', [ 'order' => 42 ], [ 'mail' ] );
$results = padNotifyResults ();
Sampling distributions Seeded samples through padSample. 
padSample ( 'normal', 100, [ 'seed' => 7 ] );
Image filters The filter= option of {image:thumbnail} selects a filter or placeholder. 
{image:thumbnail 'photo.jpg', alt='A landscape', width=320, filter='grayscale'/}
Spreadsheet functions Functions inside the formulas of {sheet:grid} cells. 
{sheet:grid formulas='G1=SUM(1, 2, 3)'}
Item,Qty,Price,Date,Flow
Apples,10,1.20,2024-01-15,-70000
Pears,5,0.80,2024-02-29,12000
Cherries,20,3.50,2024-03-31,15000
Apples,15,1.10,2024-04-01,18000
Plums,0,2.25,2024-12-31,21000
Figs,8,4.00,2025-06-30,26000
{/sheet:grid}
Geographic operations Plain data operations through padGeo, with longitude before latitude. 
padGeo ( 'distance', [4.9,52.37], [2.35,48.86] );
Syntax languages Languages selected by padHighlight and the highlight tag. 
padHighlight ( $source, 'python', TRUE );
OAuth providers The provider parameter of {widget:oauth}, padOAuthStart and padOAuthUser. 
{widget:oauth 'github', href='#example'/}
Colour palettes The name parameter of {widget:palette}, or palette= on a chart. 
{widget:palette 'viridis'/}
Calendar recurrences Bounded occurrences between explicit dates through padOccurrences. 
padOccurrences ( 'weekly', [ 'start' => '2026-11-02', 'count' => 4 ], '2026-11-01', '2031-12-01' );
Validation rules Rules passed to padValidate or a form field's rules= option. 
$errors = padValidate ( [ 'value' => 'required' ], $values );
Themes The name parameter of {widget:theme} selects page or box colours. 
{widget:theme 'paper'}<p>A box in the paper theme.</p>{/widget:theme}
Unit conversions Dimension-checked numeric conversion through padConvert. 
padConvert ( 100, 'cm', 'm' );
