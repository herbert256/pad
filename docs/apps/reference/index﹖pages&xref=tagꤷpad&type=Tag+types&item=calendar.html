Reference - Tag types - calendar

App: demo - Page: calendar
PHP
calendar.php 		HTML
calendar.pad 		Result 
<?php

  $title = 'Calendar';

  // The agenda of the month on show - the one the calendar's links ask for, else this
  // one: a stand-up every Monday, payday on the 25th, drinks on the last Friday and a
  // release on the second Tuesday.

  $shown = padCalendarMonth ( $_GET ['month'] ?? '' ) ?? padNow ( 'Y-m' );
  $first = new DateTimeImmutable ( "$shown-01" );

  $agenda = [];

  for ( $day = $first; $day->format ( 'Y-m' ) == $shown; $day = $day->modify ( '+1 day' ) )
    if ( $day->format ( 'N' ) == 1 )
      $agenda [] = [ 'when' => $day->format ( 'Y-m-d' ), 'what' => 'Stand-up' ];

  $agenda [] = [ 'when' => $first->modify ( 'second tuesday of this month' )->format ( 'Y-m-d' ), 'what' => 'Release' ];
  $agenda [] = [ 'when' => "$shown-25",                                                         'what' => 'Payday' ];
  $agenda [] = [ 'when' => $first->modify ( 'last friday of this month' )->format ( 'Y-m-d' ),   'what' => 'Drinks' ];

?>
 
<p>The <code>{ignore}{calendar}{/ignore}</code> tag draws a month with its events - from a <code>{ignore}{data}{/ignore}</code>
block, a page array or a <code>_data</code> file. The arrows move a month; today is marked.</p>

{calendar data='agenda', title='what'}

<p><code>{ignore}{calendar data='agenda', title='what'}{/ignore}</code></p>

<h2>Your own markup</h2>

<p>As a pair the tag hands over the weeks and their days as rows - <code>$day</code>, <code>$date</code>,
<code>$today</code>, <code>$count</code>, <code>$class</code>, the day's <code>events</code> - so a
mini calendar with a dot per busy day is a few lines:</p>

<table class="mini">
  <tr><th>Mo</th><th>Tu</th><th>We</th><th>Th</th><th>Fr</th><th>Sa</th><th>Su</th></tr>
  {calendar data='agenda'}
  <tr>
    {days}<td class="{$class}" title="{$date}">{$day}{if $count gt 0}<i></i>{/if}</td>{/days}
  </tr>
  {/calendar}
</table>

{ignore}{calendar data='agenda'}
  <tr>
    {days}<td class="{$class}">{$day}{if $count gt 0}<i></i>{/if}</td>{/days}
  </tr>
{/calendar}{/ignore}

App: regression/framework - Page: tags/calendar_and_timeline_put_a_moment_on_its_day_in_the_application_timezone
PHP
tags/calendar_and_timeline_put_a_moment_on_its_day_in_the_application_timezone.php 		HTML
tags/calendar_and_timeline_put_a_moment_on_its_day_in_the_application_timezone.pad 		Result 
<?php

  // A moment - a Unix timestamp, a date with its offset - falls on the day it is in the
  // application's timezone, the one today is: an event at local midnight in Amsterdam is
  // on the 13th, where the calendar put a timestamp and an offset date on their UTC day,
  // the 12th, and the timeline wrote them as 22:00 and 22:30 of the 12th.

  include_once PAD . 'tags/_lib/timeline.php';

  $padTimezone = 'Europe/Amsterdam';

  padNowFreeze ( '2025-10-13 00:30:00' );

  $agenda = [ [ 'when' => '1760306400',                'what' => 'stamp'  ],
              [ 'when' => '2025-10-13T00:30:00+02:00', 'what' => 'offset' ],
              [ 'when' => '2025-10-13 00:30:00',       'what' => 'plain'  ] ];

  $shown = padTimelineShow ( ...padTimelineDate ( '1760306400' ) );

?>
 
{calendar '2025-10', data='agenda', date='when', title='what'}{days}{events}{$date}={$what} {/events}{/days}{/calendar}
timeline: {$shown}
