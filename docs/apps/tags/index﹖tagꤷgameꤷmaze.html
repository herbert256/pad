Tags/Games/game:maze

{game:maze}

Find the way through a maze from its top left corner to the flag at the bottom right, with the arrow keys.

Games Either form

Syntax 

{game:maze/}
{maze/}

Description

One of the 18 games of {pad:game}, written {game:maze/}, {game 'maze'/}, {maze ...}, bare, when no tag, field or store has the name.

Find the way through a maze from its top left corner to the flag at the bottom right, with the arrow keys, by swiping or with the buttons under it. Every maze has one way through - a new one is dug each game, the same one for the same seed=. height= and width= its size in cells, 12 by 18 unless given (5 to 40).

Example

A game of maze

As the games application plays it.

Template 
{game:maze/}
Result
