<h1>Types by group</h1>
<p class="lead">Tag types and kind families by what they reach, in 6 groups.</p>

<nav class="jump" aria-label="Groups"><a href="#tags">Tags</a><a href="#stores">Stores and data</a><a href="#values">Values of the page</a><a href="#sequences">Sequences</a><a href="#subsystems">Subsystems</a><a href="#kinds">Options and helpers</a></nav>


<section class="section" id="tags">
  <div class="section-head"><h2>Tags</h2><span>Tags with code of their own - the engine&#039;s, the application&#039;s, the template&#039;s - 9 types</span></div>
  <ul class="list">
    
    <li><a class="name" href="?type/app">app:</a> <span class="about">A tag of the application, a file of a _tags/ directory from the page up to the root.</span></li>
    
    <li><a class="name" href="?type/common">common:</a> <span class="about">A tag or a snippet of the shared _common application.</span></li>
    
    <li><a class="name" href="?type/define">define:</a> <span class="about">A tag defined in the template by {pad:define} - its body the template of the tag.</span></li>
    
    <li><a class="name" href="?type/function">function:</a> <span class="about">A pipe function used as a tag, over the content between its tags.</span></li>
    
    <li><a class="name" href="?type/include">include:</a> <span class="about">A snippet of the application, a file of an _include/ directory.</span></li>
    
    <li><a class="name" href="?type/macro">macro:</a> <span class="about">A tag defined in the template by {pad:macro} - its body rendered once with the options as its fields.</span></li>
    
    <li><a class="name" href="?type/pad">pad:</a> <span class="about">A built-in tag of the engine - a file of pad/tags/.</span></li>
    
    <li><a class="name" href="?type/php">php:</a> <span class="about">A PHP function called as a tag, its parameters the function&#039;s arguments.</span></li>
    
    <li><a class="name" href="?type/script">script:</a> <span class="about">A shell script of a _scripts/ directory, its output the tag&#039;s.</span></li>
    
  </ul>
</section>

<section class="section" id="stores">
  <div class="section-head"><h2>Stores and data</h2><span>What a page keeps under a name and reads back - 6 types</span></div>
  <ul class="list">
    
    <li><a class="name" href="?type/bool">bool:</a> <span class="about">A boolean store - a flag set by {pad:bool}, its pair showing when it is true.</span></li>
    
    <li><a class="name" href="?type/content">content:</a> <span class="about">A content store - a piece of template kept by {pad:content} to be shown elsewhere.</span></li>
    
    <li><a class="name" href="?type/data">data:</a> <span class="about">A data store - rows kept by {format:auto} or a file of _data/ read through the format registry.</span></li>
    
    <li><a class="name" href="?type/local">local:</a> <span class="about">A data file of a _data/ directory, read by its file name.</span></li>
    
    <li><a class="name" href="?type/pull">pull:</a> <span class="about">A stored sequence - the terms a {sequence:*} pushed to the store under a name.</span></li>
    
    <li><a class="name" href="?type/select">select:</a> <span class="about">A table declared in $padSelect - its rows read from the database, joins and all.</span></li>
    
  </ul>
</section>

<section class="section" id="values">
  <div class="section-head"><h2>Values of the page</h2><span>Fields, arrays, parameters and properties where the tag stands - 6 types</span></div>
  <ul class="list">
    
    <li><a class="name" href="?type/array">array:</a> <span class="about">An array of the current row or of the page, its elements the rows of the tag.</span></li>
    
    <li><a class="name" href="?type/constant">constant:</a> <span class="about">A PHP constant, by its name.</span></li>
    
    <li><a class="name" href="?type/field">field:</a> <span class="about">A field of the current row, or a variable of the page.</span></li>
    
    <li><a class="name" href="?type/level">level:</a> <span class="about">An array field of a row of an enclosing tag, its elements the rows of the tag.</span></li>
    
    <li><a class="name" href="?type/parm">parm:</a> <span class="about">A parameter or option of the tag around it, read by its name.</span></li>
    
    <li><a class="name" href="?type/property">property:</a> <span class="about">A property of the tag around it - its count, its current row, whether it is the first.</span></li>
    
  </ul>
</section>

<section class="section" id="sequences">
  <div class="section-head"><h2>Sequences</h2><span>Number sequences and what is done to them - 6 types</span></div>
  <ul class="list">
    
    <li><a class="name" href="?type/action">action:</a> <span class="about">A sequence action - reverse, sort, sum, first ... - over the terms it is given.</span></li>
    
    <li><a class="name" href="?type/flag">flag:</a> <span class="about">Every term a 1 or a 0: whether it belongs to the sequence type named.</span></li>
    
    <li><a class="name" href="?type/keep">keep:</a> <span class="about">The terms that belong to the sequence type named, the others left out.</span></li>
    
    <li><a class="name" href="?type/make">make:</a> <span class="about">The terms of a sequence type, made as a play - the same terms {sequence:x} gives.</span></li>
    
    <li><a class="name" href="?type/remove">remove:</a> <span class="about">The terms that do not belong to the sequence type named.</span></li>
    
    <li><a class="name" href="?type/sequence">sequence:</a> <span class="about">A sequence type of the sequence subsystem, its terms the rows of the tag.</span></li>
    
  </ul>
</section>
