Tags/Widgets/widget:dropdown

{widget:dropdown}

A button and the menu it opens, on the popover attribute.

Widgets Either form

Syntax 

{widget:dropdown 'Account'}<a href="?profile">Profile</a>...{/widget:dropdown}

Description

One of the 13 widgets of {pad:widget}, written {widget:dropdown ...}, {widget 'dropdown', ...}, {dropdown ...}, bare, when no tag, field or store has the name.

{dropdown 'Account'}<a href="?profile">Profile</a>...{/dropdown} - a button and the menu it opens, on the popover attribute: the browser opens and closes the menu without a script - a click outside it or Escape closes it - and places it under its button by CSS anchor positioning. align='end' lines it up with the button's right edge. A small script (CSP nonce) adds the arrow keys between the items and places the menu where the browser cannot. widgets/_lib/dropdown.php.

Like {live} it runs twice: the content renders first, then the end walk puts it in the menu.

From the tags application

Its example on the page of {pad:widget}.

{/dropdown}
