Mathematics

Formulas written in AsciiMath and drawn as MathML Core - the <math> element that Chrome, Firefox and Safari draw themselves, no script, no font to load. AsciiMath reads the way a formula is typed in an e-mail: x^2, a/b, sqrt x, sum_(i=1)^n, alpha, ->. It is AsciiMath and not TeX because TeX's braces are PAD's own.

Written {notation:math 'a/b'/}, or with the formula between the tags, taken as written - braces and all. display='block' sets it on a line of its own; alttext= is what a screen reader without MathML says.

Powers, fractions and roots

A caret raises, an underscore lowers, a slash makes a fraction - the brackets around its parts are taken off - and sqrt and root draw the radical.

Template 
<p>{notation:math 'x^2 + y^2 = r^2'/} &middot; {notation:math 'a_1, a_2, ..., a_n'/} &middot; {notation:math 'e^(i pi) + 1 = 0'/}</p>
{notation:math display='block'}x = (-b +- sqrt(b^2 - 4ac))/(2a){/notation:math}
{notation:math display='block'}root(3)(8) = 2, quad 1/2 + 1/3 = 5/6, quad (a+b)/(c+d){/notation:math}
Result

x2+y2=r2 · a1,a2,...,an · eiπ+1=0

x=−b±b2−4ac2a 83=2,12+13=56,a+bc+d

Sums, integrals and limits

The limits of a sum go under and over it, those of an integral beside it; inline they move aside to keep the line low.

Template 
{notation:math display='block'}sum_(i=1)^n i^2 = (n(n+1)(2n+1))/6{/notation:math}
{notation:math display='block'}int_0^1 x^2 dx = 1/3, quad lim_(x->oo) (1 + 1/x)^x = e{/notation:math}
<p>Inline: {notation:math 'sum_(k=0)^oo 1/(k!) = e'/} and {notation:math}f'(x) = lim_(h->0) (f(x+h) - f(x))/h{/notation:math}.</p>
Result
∑i=1ni2=n(n+1)(2n+1)6 ∫01x2dx=13,limx→∞⁡(1+1x)x=e

Inline: ∑k=0∞1k!=e and f′(x)=limh→0⁡f⁡(x+h)−f⁡(x)h.

Matrices and cases

A bracketed list of bracketed rows of equal length is a matrix; {: and :} are brackets that draw nothing, which makes a function by cases.

Template 
{notation:math display='block'}[[a,b],[c,d]]^(-1) = 1/(ad-bc) [[d,-b],[-c,a]]{/notation:math}
{notation:math display='block'}det((1,2),(3,4)) = -2{/notation:math}
{notation:math display='block'}|x| = {(x, if x >= 0),(-x, if x < 0):}{/notation:math}
Result
[abcd]−1=1ad−bc[d−b−ca] det⁡(1234)=−2 |x|={xifx≥0−xifx<0

Letters, sets and logic

Greek letters by their names, the double-struck sets, relations, arrows and quantifiers - a formula with braces stands between the tags, where they are taken as written.

Template 
<p>{notation:math 'AA epsilon > 0, EE delta > 0 : |x - a| < delta => |f(x) - f(a)| < epsilon'/}</p>
<p>{notation:math 'NN sub ZZ sub QQ sub RR sub CC'/} &middot; {notation:math}A nn B = {x | x in A and x in B}{/notation:math}</p>
<p>{notation:math 'Delta x ~~ 0.01, quad alpha + beta + gamma = pi, quad x != y, quad a <= b'/}</p>
Result

∀ε>0,∃δ>0:|x−a|<δ⇒|f⁡(x)−f⁡(a)|<ε

ℕ⊂ℤ⊂ℚ⊂ℝ⊂ℂ · A∩B={x∣x∈Aandx∈B}
