Tickets

Barcode Aztec, the square code of train tickets, its bullseye in the middle, and PDF417, the stacked code of a boarding pass - its rows read in any order, each telling the scanner where it stands.

1 The template barcode/tickets.pad pad 
<div style="display:flex; flex-wrap:wrap; gap:18px; align-items:flex-start">
  <div style="display:flex; gap:16px; align-items:center; max-width:460px; padding:16px; background:#fff; color:#111; border:2px solid #111; border-radius:6px; font:14px/1.4 system-ui">
    {barcode:aztec 'PAD-RAIL|2026-11-01|UT|ASDZ|2|ADULT|0042', size=130, title='Ticket PAD-RAIL 0042'/}
