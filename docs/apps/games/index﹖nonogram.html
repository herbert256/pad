Nonogram

A picture to uncover: the numbers beside each row and over each column are the runs of filled squares in it, in order. Click a square to fill it, click it again to mark it empty (or switch to marking), until the picture is found. The picture is written between the tags, a line per row, # for a filled square and . for an empty one - else one of a few built in, the same for the same seed=.
