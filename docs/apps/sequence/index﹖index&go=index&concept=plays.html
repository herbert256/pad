Plays - Execute a Sequence on a Sequence

A play is a sequence, but not used to build a list, it is used to exucute on a sequence list.

There are 4 play operators

make Make all entries of a sequence list that sequence
keep Keep sequence list entries that are that sequence
remove Remove sequence list entries that are that sequence
flag Flag each sequence list entry with 1 when it is that sequence, else 0

HTML RESULT 
{sequence range='20..30', push='mySequence'}
 
{pull mySequence, make,   prime} {$sequence} {/pull}
 71 73 79 83 89 97 101 103 107 109 113 
{pull mySequence, keep,   prime} {$sequence} {/pull}
 23 29 
{pull mySequence, remove, prime} {$sequence} {/pull}
 20 21 22 24 25 26 27 28 30 
{pull mySequence, flag,   prime} {$sequence} {/pull}
 0 0 0 1 0 0 0 0 0 1 0
