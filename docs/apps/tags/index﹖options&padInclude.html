Tags by option

Every option a tag takes of its own, and what it does there. The handling options every tag takes - sort, where, first, rows, group and the rest - are not listed here.

OptionTagMeaning
access {pad:meta} Kept for access rules to read with padMeta ( 'access' ).
across {printable:*} The items across a sheet; down the items down.
action {pad:pull} Any sequence action written as an option (or named with action='last|2'), applied to the stored values in the order written: reverse, sort, sum, first=3, last=3, append='other', ... shift=n and pop=n also take the values out of the store.
{pad:resume} Any sequence action, as an option of its own or named with action='reverse' - reverse, sort, sum, first=3, ... - or a play with a type: add=10 (make), keep, prime, remove, even, flag, odd.
{sequence:*} Names an action explicitly, its value after a |: action='first|3'. Usually the action is written as an option of its own, applied to the result in the order written: sum, average, median, count, reverse, sort, shuffle, dedup, first=n, last=n, append='store', ...
active {widget:*} tabs, wizard: the tab or step shown first, by its number from 1 or its label.

ajax {pad:page} With app=: ajax=false fetches the other application's page on the server and inserts its body instead of leaving it to the browser.
