Reference - Parms functions - padGameTypes

App: manual - Page: pages/games
PHP
 HTML
pages/games.pad 		Result 
{pad:meta title='Games'/}

<p>{app:tag 'game:memory'/} puts a little game on the page that is played in the browser. The server checks
what the game is given and writes its board; the game's script, written once per page, plays it.
There are {pad:echo php:count(padGameTypes())/} of them - every game is a file of
<code>pad/subs/games/types/</code>, and the <a href="../games/">games</a> application plays them all.</p>

{common:example 'fragments/games_1'/}

<h2>Select a kind</h2>

<p>Use <code>{game:tictactoe/}</code> to select the kind.
<code>opens='computer'</code> lets the computer open, <code>two</code> makes it a game of two players
at one screen.</p>

<h2>Words, questions and pictures</h2>

<p>The games that play with words, questions or a picture take them between their tags, a line each,
as they are written - braces and all. A quiz line is the question with its answers after a bar, the
right one first; they are shuffled when shown.</p>

{common:example 'fragments/games_2'/}

<p>The same list can come from the page: <code>data=</code> names a store, an array of the page or a
<code>_data</code> file, as a chart's data does.</p>

{common:example 'fragments/games_3'/}

<h2>The same game every time</h2>

<p><code>seed=</code> makes a game's shuffles, boards and puzzles the same on every load - a page can
say which sudoku it hands out. Without a puzzle the sudoku makes a new one with one solution;
<code>givens=</code> says how many squares it shows. <code>paper</code> draws a sudoku or a crossword
to print instead, with no script, and <code>solve</code> - <code>solution</code> for a crossword -
fills in the answers.</p>

{common:example 'fragments/games_4'/}

<ul>
  <li>When a game ends its board carries <code>data-result="won"</code> or <code>"lost"</code>, and a
  <code>pad-game-end</code> event goes up from it - a page can count the games won.</li>
  <li>The colours are custom properties on <code>.pad-game</code> - <code>--pad-game-accent</code>,
  <code>--pad-game-good</code>, <code>--pad-game-bad</code> and their like - with light and dark
  defaults.</li>
  <li>The script carries the CSP nonce, as the interactive tags' scripts do, and a game a fragment
  or a live region brings later starts as well.</li>
</ul>
