Tags/Chart types/chart:density

{chart:density}

A smooth curve per group of label.

Chart types Either form

Syntax 

{chart:density data='rows', label='field', value='field'/}
{density data='rows', label='field', value='field'/}

Description

One of the 45 chart types of {pad:chart}, written {chart:density .../}, {chart 'density', .../}, {density ...}, bare, when no tag, field or store has the name.

A smooth curve per group of label (Gaussian kernel density, bandwidth or else Silverman's rule) over one value axis - a light wash, its line, the median dashed, a legend for several groups. Options: label, value, bandwidth; width= and height=, 600 x 300 unless given.

Example

From the charts application

Its example distribution/reaction there, with the data it draws.

Templatecharts/distribution/reaction.pad 
{chart 'density',
       data='trials',
       label='group',
       value='ms',
       title='Reaction time in ms, rested and after a sleepless night',
       width=640,
       height=320/}
PHPdistribution/reaction.php 
<?php

  // Reaction times in milliseconds of 150 trials rested and 150 after a night without
  // sleep, from a fixed seed: the tired ones slower and more spread, with a long tail of
  // lapses - two bell curves of their own, drawn as densities over one axis.

  mt_srand ( 11 );

  $bell = fn ( $mean, $sd ) => $mean + $sd * sqrt ( -2 * log ( max ( 1e-9, mt_rand () / mt_getrandmax () ) ) ) * cos ( 2 * M_PI * mt_rand () / mt_getrandmax () );

  $trials = [];

  for ( $i = 0; $i < 150; $i++ )
    $trials [] = [ 'group' => 'Rested', 'ms' => round ( $bell ( 285, 32 ) ) ];

  for ( $i = 0; $i < 150; $i++ )
    $trials [] = [ 'group' => 'Sleep-deprived', 'ms' => round ( $i % 6 ? $bell ( 340, 45 ) : $bell ( 480, 60 ) ) ];

?>
