{copy} shows a text in a <pre><code> block that selects as a whole with one click, and beside it a button that puts the text on the clipboard. The button needs scripting: a small script, written once per page (with the CSP nonce when one is asked for), copies through navigator.clipboard, or through the selection on a page over plain http, and says "Copied" on the button and to a screen reader. Without scripting there is no button and the text is selected and copied by hand.

The single tag takes the text as its first parameter - a value, so it is escaped and never read as template. As a pair the content is the text: it is rendered first, then trimmed, so fields and tags inside it are resolved - {copy}padSqlDatabase={$app}.sqlite{/copy}.

label= sets the text of the button. A single {copy} without a text is an error under the strict check. The colours are --pad-copy-accent, -text, -muted, -line, -surface and -done on .pad-copy.
