Types/Subsystems/diagram:

diagram:

A diagram type, a file of pad/diagrams/types/, laid out on the server.

Subsystems Tried 26 of 31 for a bare name

Syntax 

{diagram:state}...{/diagram:state}
{diagram type='state'}...{/diagram}

Description

A diagram of the kind the tag names, drawn from the lines between its tags - the diagram subsystem in PAD/diagrams/ lays it out, as the {diagram} tag lays out the kind its type= names. 

{diagram:flowchart direction='LR'}A[Order] --> B{Paid?}{/diagram:flowchart}
{diagram:sequence}Shop ->> Bank: Charge{/diagram:sequence}
{flowchart}A --> B{/flowchart}

Resolution: a file PAD/diagrams/types/<name>.php (padDiagramType() in PAD/diagrams/_lib/diagram.php): the files there are the kinds, and a kind is added by adding its file. Bare, a diagram kind comes after every other kind of tag, the chart kinds and the games too - so {sequence} is the sequence tag, and the sequence diagram is {diagram:sequence} or {diagram type='sequence'}.

The handler

pad/types/diagram.php: Type handler for a diagram kind: {diagram:sequence}...{/diagram:sequence}, or a bare pair naming a file of diagrams/types/ when nothing else has the name, {flowchart}...{/flowchart}. The kind is the tag's name, and the diagram is drawn as {diagram type='sequence'} draws it, by diagrams/diagram.php - run as a built-in tag's PHP half is run, types/_go/tag.php.

9 of them, each with its page in the tags application.
