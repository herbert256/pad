App: tags - Page: examples/exists/1-pair
PHP
 HTML
examples/exists/1-pair.pad 		Result 
{meta title='Content when the file is there', about='The path is used as given - built here from APP, the application\'s directory; @else@ renders when it is missing.'}
{set $notes = APP . '_data/filesDemo/notes.txt'}
{exists $notes}
  <p>The notes are there.</p>
@else@
  <p>No notes yet.</p>
{/exists}
{set $todo = APP . '_data/filesDemo/todo.txt'}
{exists $todo}
  <p>The to-do list is there.</p>
@else@
  <p>No to-do list yet.</p>
{/exists}
