A PAD page is a combination of a PHP file and/or HTML file, the home page did already show below example.

PHP HTML Result 
<?php

  $hi = 'Hello World !';

?>
 
<h3>
  {$hi}
</h3>

Hello World !

There are many other ways the application PHP code and the application HTML markup work together.

<h3>
  <?php echo 'Hello World'; ?>
</h3>

Hello World

 
<?php

  echo '<h3>Hello World</h3>';

?>

Hello World

Ok ok, above is standard PHP/HTML, existing PHP and HTML web pages can be wrapped in PAD as is. An existing .html file needs no wrapping at all: dropped in the application directory it is a page, a template exactly like a .pad - it pairs with a .php of the same name and PAD tags resolve in it. When both a .pad and an .html exist, the .pad wins.
