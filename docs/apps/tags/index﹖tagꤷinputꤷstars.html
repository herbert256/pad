Tags/Rich form fields/input:stars

{input:stars}

A rating to give: a row of max= stars, 5 unless given, each a native radio button of the value 1 to max.

Rich form fields Single tags

Syntax 

{input:stars 'name', label='...'/}

Description

One of the 20 rich form fields of input:*, written {input:stars 'name', label='...'/}.

A rating to give: a row of max= stars, 5 unless given, each a native radio button of the value 1 to max, in a fieldset whose legend is the label. The arrow keys move along them as along any radio group, and the style alone fills the stars up to the one chosen or pointed at. The script shows a button that takes the rating back, unless the field is required - a radio group, once chosen, cannot be emptied otherwise. The first star has the field's id, the others the id with their value, as the boxes of {input:field}'s group have.

Example

A field of a form

As the inputs application's form writes it - its rules= left out, which the page's own template must hold.

Template 
{input:form 'try'}
  {input:stars 'score', label='Your rating'/}
  <button>Send</button>
{/input:form}
Result
Your rating
