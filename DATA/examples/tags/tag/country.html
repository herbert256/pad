{country} turns a country code into its flag (lib/country.php). The code may be the two-letter alpha-2 (NL), the three-letter alpha-3 (NLD, as passports and sports use it) or the English name, in any case; the table holds the 249 entries of ISO 3166-1 with the names as CLDR gives them.

The flag is the code written as two regional indicator symbols - text, not an image - which a system with flag emoji draws as the flag and one without (Windows) as the two letters. Alone it is <span class="pad-country" role="img" aria-label="Netherlands">, with the name as its tooltip too. With name the English name is written beside it and the flag becomes decoration, so a screen reader says the name once.

A code that is no country is an error under the strict check, naming the nearest country when the text is close to a name; without the check the text is written as it was given. padCountry ( $code ) answers [ alpha-2, alpha-3, name ] to PHP. To colour countries by a value, see {map}.
