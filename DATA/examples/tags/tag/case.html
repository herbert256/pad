{pad:case value} evaluates its value once and keeps only the branch of the first {pad:when} that matches it. A {pad:when} may list several values separated by commas - {pad:when 'yellow', 'amber'} - and matches when any of them is equal. Each value is an expression of its own, so {pad:when $limit} or {pad:when 2 * 5} work too. The comparison is PHP's loose ==, so {pad:when 3} matches the text '3'.

A branch runs from its {pad:when} to the next one (or to {pad:else} or {/pad:case}). {pad:else} opens the default branch, rendered when no {pad:when} matched; without it nothing renders in that case. {pad:when 'default'} is not a default - it is an ordinary branch matching the text default. A nested {pad:case} or {pad:if} inside a branch keeps its own {pad:when} and {pad:else}.

Under the strict syntax check the tag is held to its shape: a {pad:case} without a value, without any {pad:when} or without its {/pad:case} is an error; so is text standing before the first {pad:when} (it would never render), a {pad:when} behind the {pad:else}, a {pad:when} without a value, and a value listed twice - only the first one could ever answer.

For a yes/no test use {pad:if}; for a heading each time a value changes inside a loop, {pad:ifchanged}.
