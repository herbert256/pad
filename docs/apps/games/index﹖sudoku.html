Sudoku

Fill the grid so that every row, column and box of three by three holds the digits 1 to 9 once. The puzzle is the first parameter, row by row - a digit for a given, . or 0 for an empty square, whitespace and the | and + of a drawn grid passed over - or without one, a new puzzle with one solution each game, the same for the same seed=, givens= how many squares it shows (24 to 45, 30 unless given). Select a square and type a digit or click one; notes writes small candidates, hint fills a square, check marks the wrong ones. paper draws the puzzle as a table to print instead, solve with its solution filled in; title= names it.
