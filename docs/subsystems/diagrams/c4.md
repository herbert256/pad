# c4

A deliberately bounded context/container architecture notation:

```
person user "Customer"
boundary shop "Shop" {
  container api "Order API" "PHP"
  container db "Orders" "PostgreSQL"
}
system payments "Payment provider"
user -> api: places order
api -> db: persists
api -> payments: authorizes
```

Element kinds are person, system and container, with an optional quoted technology. Boundaries open `{` and close on their own `}` line; they can nest four deep. Identifiers are unique; relationships reference existing elements or boundaries. Limits: 64 elements, 128 relationships, 100 KB source. Blank lines, `#` comments and a `c4` header are accepted. `{diagram:auto}` recognizes the c4 header too.

TB uses two-column groups; LR arranges long groups horizontally, BT reverses vertical placement and RL reverses horizontal placement. Boxes remain upright. Relationships use shared orthogonal routing with arrowheads, and cycles do not affect layout. Nested boundary membership is stated in the accessible description. Long labels wrap with full labels in tooltips/descriptions. Routes can cross intermediate elements; this is neither full C4-PlantUML nor Mermaid C4 compatibility. `title` names the SVG.
