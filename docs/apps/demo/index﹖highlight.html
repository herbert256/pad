Syntax Highlighting

The {pad:highlight} tag colours source code on the server - PAD, PHP, HTML, CSS, JavaScript, JSON, YAML, SQL and Bash. No JavaScript library, and the braces inside need no {pad:ignore}.

PHP, with line numbers and a marked line 

<?php

  $orders = db ( "ARRAY * FROM orders WHERE status = 'open'" );
  $total  = padArrSum ( $orders, 'amount' );

  if ( ! $orders )
    padRedirect ( 'empty' );

?>

{pad:highlight 'php', lines, mark='4'}...{/pad:highlight}
