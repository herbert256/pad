Examples Guide
● Any framework, one runtime

Islands of any kind
on one PAD page.

PAD writes the page and marks the places that move. A small runtime mounts a component on each - React here, Vue there, Svelte, Preact or Solid - and fetches a framework only when an island of it is on the page. Vite builds them; {vite} links the build.

See all five How it fits together 
<div data-island="VueCounter" data-props="{^vue}"></div>
<div data-island="SvelteCounter" data-load="visible"
     data-props="{^svelte}"></div>

{vite 'src/main.js'}
islands({
  VueCounter:    vue(() => import('./Counter.vue')),
  SvelteCounter: svelte(() => import('./Counter.svelte'))
});
