Cheat sheet

How every subsystem is used, by group.

Tag subsystems

AIText and validated JSON responses.
{ai:anthropic'Name three rivers.'/}
AvatarsAn identity picture: initials, identicons, rings, mosaic, pixelbot, Gravatar, geometric art or a photograph with a local fallback.
{avatar:initials'Ada Lovelace'/}{avatar:geometric'ada', style='rings'/}
BarcodesA barcode symbology, a file of pad/subs/codes/types/, encoded on the server.
{barcode:ean13'400638133393'/}{barcode:ean13'400638133393'/}
CalendarsA Gregorian calendar view from pad/subs/calendars/types/ - days, weeks, months, quarters, years and agendas.
{calendar:month'2026-11'/}{calendar:week'2026-11-02'/}{calendar:year'2026'/}
ChartsA chart type, a file of pad/subs/charts/types/, drawn as inline SVG.
{chart:piedata='rows', label='name', value='amount'/}{chart:piedata='rows', ...}{chart:piedata='rows', .../}
DiagramsA diagram type, a file of pad/subs/diagrams/types/, laid out on the server.
{diagram:state}...{/diagram:state}{diagram:state}...{/diagram:state}
DiffsA comparison of texts, JSON or keyed records from pad/subs/diffs/types/.
{diff:words$old, $new/}{diff:json$old, $new/}{diff:rows$old, $new, key='id'/}
EffectsAn effect, a file of pad/subs/effects/types/ - motion and decoration, CSS first, still under reduced motion.
{effect:typewriter}Hello{/effect:typewriter}{effect:typewriter}Hello{/effect:typewriter}
EmbedsAn embed provider, a file of pad/subs/embeds/types/ - loaded only on a click.
{embed:youtube'aqz-KE-bpKQ', title='Big Buck Bunny'/}{embed:auto'https://youtu.be/aqz-KE-bpKQ'/}{embed:youtube'aqz-KE-bpKQ'/}
FakesA fake kind, a file of pad/subs/fakes/types/ - the same values for the same seed, never bare.
{fake:email/}{fake:email/}{fake:rows'name, email', rows=3}...{/fake:rows}
FormatsRead documents into named data stores.
{format:json'rows'}[1,2,3]{/format:json}
GamesA game, a file of pad/subs/games/types/, played in the browser.
{game:memorypairs=6/}{game:memory/}{game:memory/}
HolidaysCountry and regional public holidays.
{holidays:nlyear=2026/}
IconsAn icon, a file of pad/subs/icons/types/, drawn as inline SVG - never bare.
{icon:starsize=24/}{icon:starsize=24/}
ImagesLocal images as thumbnails, responsive pictures, captioned figures or contact sheets.
{image:thumbnail'photo.jpg', width=320, alt='A landscape'/}{image:picture'photo.jpg', widths='320,640,960', alt='A landscape'/}
InputsA rich form field, a file of pad/subs/inputs/types/, posted by any form.
{input:slider'volume', label='Volume'/}
JSON-LDA JSON-LD kind, a file of pad/subs/jsonld/types/ - the structured data of a page as a Schema.org object, never bare.
{jsonld:articleheadline=$title, author=$author/}{jsonld:articledata='post'/}{jsonld:faqdata='questions'/}
MapsChoropleths, markers and proportional bubbles.
{map:europewidth=540/}
NotationsA notation, a file of pad/subs/notations/types/ - a formula, a tune, a word or a position drawn on the server.
{notation:braille'Hello'/}{notation:braille'Hello'/}{notation:math}a/b{/notation:math}
PatternsA pattern, a file of pad/subs/patterns/types/ - a seeded SVG background, never bare.
{pattern:topographyseed=7/}{pattern:topographyseed=7/}
PrintablesA printable, a file of pad/subs/printables/types/ - pages made for paper, the same on the screen, printed and as a PDF, never bare.
{printable:labelsdata='rows', sheet='a4-3x8'}...{/printable:labels}{printable:labelsdata='rows'}...{/printable:labels}
SearchRanked search, exact filters and facets.
{search:en'documents', q='PAD'/}
SectionsA section of a landing page, a file of pad/subs/sections/types/ - pure CSS, coloured by the theme, never bare.
{section:herotitle='Build faster'}...{/section:hero}{section:herotitle='Build faster'}...{/section:hero}
SheetsFormula grids computed on the server.
{sheet:grid}Name,AmountOne,12Two,=B2*2{/sheet:grid}
SoundsA sound, a file of pad/subs/sounds/types/ - a recipe the browser plays and the server writes as a WAV, never bare.
{sound:chime/}{sound:chime/}{sound:popon='click', target='#save'/}
TablesA table of rows, grouped records, a pivot or a matrix from pad/subs/tables/types/.
{table:standarddata='orders', sortable/}{table:groupeddata='orders', group='region', totals='amount'/}
TimelinesEvent views from pad/subs/timelines/types/ - horizontal, vertical, roadmap and swimlane.
{timeline:horizontaldata='events'/}{timeline:roadmapdata='events', lane='team'/}{timeline:swimlanedata='events', lane='team'/}
TimesTime displays from pad/subs/times/types/ - countdown, relative time, world clocks and stopwatches.
{time:countdown'2026-12-31', live/}{time:relative'2026-11-01'/}{time:clocktimezone='Europe/Amsterdam'/}{time:stopwatch/}
ToysA toy, a file of pad/subs/toys/types/ - a live simulation in the browser.
{toy:lifepattern='glider'/}{toy:life/}{toy:life/}
WidgetsA widget, a file of pad/subs/widgets/types/, that works without JavaScript.
{widget:tabs}{widget:tab'One'}...{/widget:tab}{/widget:tabs}{widget:tabs}...{/widget:tabs}{widget:tabs}...{/widget:tabs}

Options and helpers

Calendar recurrencesBounded occurrences between explicit dates through padOccurrences.
padOccurrences('weekly',['start'=>'2026-11-02','count'=>4],'2026-11-01','2031-12-01');
Colour palettesThe name parameter of {widget:palette}, or palette= on a chart.
{widget:palette'viridis'/}
Constraint solversBounded exact cover, bipartite matching and assignment through padSolve.
padSolve('assignment',['rows'=>['Ada','Bo'],'columns'=>['edit','test'],'costs'=>[[2,5],[4,1]]],['maxSteps'=>100000]);
Geographic operationsPlain data operations through padGeo, with longitude before latitude.
padGeo('distance',[4.9,52.37],[2.35,48.86]);
Graph algorithmsDependency order, components, shortest and critical paths through padGraph.
padGraph('toposort',['a','b','c'],[['a','b'],['b','c']]);
Image filtersThe filter= option of {image:thumbnail} selects a filter or placeholder.
{image:thumbnail'photo.jpg', alt='A landscape', width=320, filter='grayscale'/}
Notification channelsDelivery channels selected in the fourth argument of padNotify.
padNotify($recipient,'order-shipped',['order'=>42],['mail']);$results=padNotifyResults();
OAuth providersThe provider parameter of {widget:oauth}, padOAuthStart and padOAuthUser.
{widget:oauth'github', href='#example'/}
Sampling distributionsSeeded samples through padSample.
padSample('normal',100,['seed'=>7]);
Schema validationExplicit contracts for JSON values, records and rowsets through padSchema.
$schema=['type'=>'object','properties'=>['name'=>['type'=>'string']],'required'=>['name'],'additionalProperties'=>false];padSchema('jsonschema',(object)['name'=>'Ada'],$schema);
Spreadsheet functionsFunctions inside the formulas of {sheet:grid} cells.
{sheet:gridformulas='G1=SUM(1, 2, 3)'}Item,Qty,Price,Date,FlowApples,10,1.20,2024-01-15,-70000Pears,5,0.80,2024-02-29,12000Cherries,20,3.50,2024-03-31,15000Apples,15,1.10,2024-04-01,18000Plums,0,2.25,2024-12-31,21000Figs,8,4.00,2025-06-30,26000{/sheet:grid}
StatisticsBounded descriptive statistics and regression through padStats.
padStats('describe',[1,2,2,3,5,8]);
Syntax languagesLanguages selected by padHighlight and the highlight tag.
padHighlight($source,'python',TRUE);
Text analysisUnicode counts, n-grams and lexical similarity through padTextAnalysis.
padTextAnalysis('counts','Red blue, red green.');
ThemesThe name parameter of {widget:theme} selects page or box colours.
{widget:theme'paper'}<p>A box in the paper theme.</p>{/widget:theme}
Unit conversionsDimension-checked numeric conversion through padConvert.
padConvert(100,'cm','m');
Validation rulesRules passed to padValidate or a form field's rules= option.
$errors=padValidate(['value'=>'required'],$values);
