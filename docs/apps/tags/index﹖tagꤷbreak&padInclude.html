{break} stops a loop dead, like PHP's break: what is left of the current pass after the tag is dropped, and no further row follows. It is usually written inside an {if} - stop at the first row that matches. The tag prints nothing.

It works on rows and on conditions alike: in a data tag or a {sequence} the rows still to come are emptied, and in a {while} or {until} the loop asks for no further pass. For a stop that lets the current pass finish, use {cease}; to skip one pass only, {continue}.

Without a parameter it leaves the nearest enclosing level that is not an {if} or a {case}. A name - {break 'orders'}, a tag's name or its name= - leaves an outer loop, and the inner loops with it; a level number or a negative offset picks the level by position. Under the strict syntax check a name no enclosing level has is an error.
