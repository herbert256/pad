Tags/Chart types/chart:column

{chart:column}

Bar by another name, drawn as bar.

Chart types Either form

Syntax 

{chart:column data='rows', label='field', value='field'/}
{column data='rows', label='field', value='field'/}

Description

One of the 45 chart types of {pad:chart}, written {chart:column .../}, {chart 'column', .../}, {column ...}, bare, when no tag, field or store has the name.

Bar by another name, drawn as bar: columns from a zero baseline; several value fields side by side, or one on the other with stacked. Options: label, value, stacked; width= and height=, 600 x 300 unless given.

Example

From the charts application

Its example bars/profit there, with the data it draws.

Templatecharts/bars/profit.pad 
{chart 'column',
       data='profit',
       label='quarter',
       value='result',
       title='Result per quarter, in thousands',
       width=640,
       height=340/}
