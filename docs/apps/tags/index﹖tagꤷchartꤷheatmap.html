Tags/Chart types/chart:heatmap

{chart:heatmap}

A grid of the categories x.

Chart types Either form

Syntax 

{chart:heatmap data='rows', label='field', value='field'/}
{heatmap data='rows', label='field', value='field'/}

Description

One of the 45 chart types of {pad:chart}, written {chart:heatmap .../}, {chart 'heatmap', .../}, {heatmap ...}, bare, when no tag, field or store has the name.

A grid of the categories x (columns) and y (rows), each cell one of seven steps of one hue; rows with the same cell add up. Options: x, y, value; width= and height=, 600 x 300 unless given.

Example

From the charts application

Its example heatmap/rainfall there, with the data it draws.

Templatecharts/heatmap/rainfall.pad 
{chart 'heatmap',
       data='rainfall',
       x='month',
       y='city',
       value='mm',
       title='Rainfall in millimetres',
       width=640,
       height=300/}
