Regression

The regression tests of the PAD framework. Every suite fetches real pages over HTTP - Pages from regression2, which runs with _common switched off, Common from regression3, the pages that use it, and Framework from regression4, where every engine case is a page of its own; the scan crawls every application and compares each page against its stored copy, keeping no baseline for the three suite apps, whose pages the suites already assert. Each line reports the last run - Test on a suite's own page reruns it.
