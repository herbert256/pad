Squares that grow with the text

Barcode Data Matrix takes the smallest of its square sizes that holds the text, from 10 by 10 modules up; QR does the same with its versions; with gs1 it holds the GS1 element strings of a medicine pack.

1 The data barcode/squares.php php 
<?php

  $texts = [
    [ 'text' => '42',                            'size' => 60,  'label' => 'two digits' ],
    [ 'text' => 'PAD-2026-0042',                 'size' => 90,  'label' => 'a part number' ],
    [ 'text' => 'https://example.com/order/42',  'size' => 120, 'label' => 'an address' ],
    [ 'text' => str_repeat ( 'Data Matrix ECC 200. ', 8 ), 'size' => 150, 'label' => 'a paragraph' ] ];

?>
2 The template barcode/squares.pad pad 
<div style="display:flex; flex-wrap:wrap; gap:24px; align-items:flex-end">
  {array:texts}
  <figure style="margin:0; text-align:center">{barcode:datamatrix $text, size=$size/}<figcaption>{$label}</figcaption></figure>
  {/array:texts}
  <figure style="margin:0; text-align:center">{barcode:qr 'https://example.com/order/42', size=150/}<figcaption>the same order as QR</figcaption></figure>
  <figure style="margin:0; text-align:center">{barcode:datamatrix '(01)09501101530003(17)261231(10)AB-123(21)PAD0042', gs1, size=110/}<figcaption>GS1, a medicine pack</figcaption></figure>
</div>
