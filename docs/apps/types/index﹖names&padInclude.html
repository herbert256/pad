Types by name

All 69 tag types and kind families from A to Z.

  • action: A sequence action - reverse, sort, sum, first ... - over the terms it is given. Sequences
  • ai: Text and validated JSON responses. Subsystems
  • app: A tag of the application, a file of a _tags/ directory from the page up to the root. Tags
  • array: An array of the current row or of the page, its elements the rows of the tag. Values of the page
  • avatar: An identity picture: initials, identicons, rings, mosaic, pixelbot, Gravatar, geometric art or a photograph with a local fallback. Subsystems
  • barcode: A barcode symbology, a file of pad/subs/codes/types/, encoded on the server. Subsystems
  • bool: A boolean store - a flag set by {pad:bool}, its pair showing when it is true. Stores and data
  • calendar: A Gregorian calendar view from pad/subs/calendars/types/ - days, weeks, months, quarters, years and agendas. Subsystems
  • Notification channels Delivery channels selected in the fourth argument of padNotify. Options and helpers
  • chart: A chart type, a file of pad/subs/charts/types/, drawn as inline SVG. Subsystems
  • common: A tag or a snippet of the shared _common application. Tags
  • constant: A PHP constant, by its name. Values of the page
  • content: A content store - a piece of template kept by {pad:content} to be shown elsewhere. Stores and data
  • data: A data store - rows kept by {format:auto} or a file of _data/ read through the format registry. Stores and data
  • define: A tag defined in the template by {pad:define} - its body the template of the tag. Tags
  • diagram: A diagram type, a file of pad/subs/diagrams/types/, laid out on the server. Subsystems
  • diff: A comparison of texts, JSON or keyed records from pad/subs/diffs/types/. Subsystems
  • Sampling distributions Seeded samples through padSample. Options and helpers
  • effect: An effect, a file of pad/subs/effects/types/ - motion and decoration, CSS first, still under reduced motion. Subsystems
  • embed: An embed provider, a file of pad/subs/embeds/types/ - loaded only on a click. Subsystems
  • fake: A fake kind, a file of pad/subs/fakes/types/ - the same values for the same seed, never bare. Subsystems
  • field: A field of the current row, or a variable of the page. Values of the page
  • Image filters The filter= option of {image:thumbnail} selects a filter or placeholder. Options and helpers
  • flag: Every term a 1 or a 0: whether it belongs to the sequence type named. Sequences
  • format: Read documents into named data stores. Subsystems
  • Spreadsheet functions Functions inside the formulas of {sheet:grid} cells. Options and helpers
  • function: A pipe function used as a tag, over the content between its tags. Tags
  • game: A game, a file of pad/subs/games/types/, played in the browser. Subsystems
  • Geographic operations Plain data operations through padGeo, with longitude before latitude. Options and helpers
  • Syntax languages Languages selected by padHighlight and the highlight tag. Options and helpers
  • holidays: Country and regional public holidays. Subsystems
  • icon: An icon, a file of pad/subs/icons/types/, drawn as inline SVG - never bare. Subsystems
  • image: Local images as thumbnails, responsive pictures, captioned figures or contact sheets. Subsystems
  • include: A snippet of the application, a file of an _include/ directory. Tags
  • input: A rich form field, a file of pad/subs/inputs/types/, posted by any form. Subsystems
  • jsonld: A JSON-LD kind, a file of pad/subs/jsonld/types/ - the structured data of a page as a Schema.org object, never bare. Subsystems
  • keep: The terms that belong to the sequence type named, the others left out. Sequences
  • level: An array field of a row of an enclosing tag, its elements the rows of the tag. Values of the page
  • local: A data file of a _data/ directory, read by its file name. Stores and data
  • macro: A tag defined in the template by {pad:macro} - its body rendered once with the options as its fields. Tags
  • make: The terms of a sequence type, made as a play - the same terms {sequence:x} gives. Sequences
  • map: Choropleths, markers and proportional bubbles. Subsystems
  • notation: A notation, a file of pad/subs/notations/types/ - a formula, a tune, a word or a position drawn on the server. Subsystems
  • OAuth providers The provider parameter of {widget:oauth}, padOAuthStart and padOAuthUser. Options and helpers
  • pad: A built-in tag of the engine - a file of pad/tags/. Tags
  • Colour palettes The name parameter of {widget:palette}, or palette= on a chart. Options and helpers
  • parm: A parameter or option of the tag around it, read by its name. Values of the page
  • pattern: A pattern, a file of pad/subs/patterns/types/ - a seeded SVG background, never bare. Subsystems
  • php: A PHP function called as a tag, its parameters the function's arguments. Tags
  • printable: A printable, a file of pad/subs/printables/types/ - pages made for paper, the same on the screen, printed and as a PDF, never bare. Subsystems
  • property: A property of the tag around it - its count, its current row, whether it is the first. Values of the page
  • pull: A stored sequence - the terms a {sequence:*} pushed to the store under a name. Stores and data
  • Calendar recurrences Bounded occurrences between explicit dates through padOccurrences. Options and helpers
  • remove: The terms that do not belong to the sequence type named. Sequences
  • Validation rules Rules passed to padValidate or a form field's rules= option. Options and helpers
  • script: A shell script of a _scripts/ directory, its output the tag's. Tags
  • search: Ranked search, exact filters and facets. Subsystems
  • section: A section of a landing page, a file of pad/subs/sections/types/ - pure CSS, coloured by the theme, never bare. Subsystems
  • select: A table declared in $padSelect - its rows read from the database, joins and all. Stores and data
  • sequence: A sequence type of the sequence subsystem, its terms the rows of the tag. Sequences
  • sheet: Formula grids computed on the server. Subsystems
  • sound: A sound, a file of pad/subs/sounds/types/ - a recipe the browser plays and the server writes as a WAV, never bare. Subsystems
  • table: A table of rows, grouped records, a pivot or a matrix from pad/subs/tables/types/. Subsystems
  • Themes The name parameter of {widget:theme} selects page or box colours. Options and helpers
  • time: Time displays from pad/subs/times/types/ - countdown, relative time, world clocks and stopwatches. Subsystems
  • timeline: Event views from pad/subs/timelines/types/ - horizontal, vertical, roadmap and swimlane. Subsystems
  • toy: A toy, a file of pad/subs/toys/types/ - a live simulation in the browser. Subsystems
  • Unit conversions Dimension-checked numeric conversion through padConvert. Options and helpers
  • widget: A widget, a file of pad/subs/widgets/types/, that works without JavaScript. Subsystems
