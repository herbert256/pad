Tags/Widgets/pad:widget

{pad:widget}

An interactive part of the page that works without JavaScript - 13 of them, from tabs, a modal and a carousel to a toast, a dropdown and a wizard.

Widgets Either form

Syntax 

{widget 'name', ...} ... {/widget}
{widget:name ...} ... {/widget:name}
{tabs active='label'} {tab 'label'} ... {/tab} ... {/tabs}
{accordion single, open=1} {tab 'label'} ... {/tab} ... {/accordion}
{carousel label='name'} {tab 'caption'} ... {/tab} ... {/carousel}
{wizard active=1, next='Next', back='Back'} {tab 'step'} ... {/tab} ... {/wizard}
{lightbox label='name'} {tab 'caption'} <img ...> {/tab} ... {/lightbox}
{modal 'name', title='heading', button='text'} ... {/modal}
{drawer 'name', title='heading', button='text', side='left'} ... {/drawer}
{dropdown 'text', align='end'} <a href="..."> ... </a> ... {/dropdown}
{tooltip 'tip'} ... {/tooltip}
{toast 'title', tone='success', place='top', timeout=5} ... {/toast}
{copy 'text', label='Copy'/}
{poll 'name', options='Yes, No', title='question', button='Vote', results/}
{breadcrumb home='Home', label='Breadcrumb'/}

Parameters

name
The widget, a file of pad/widgets/types/: accordion, breadcrumb, carousel, copy, drawer, dropdown, lightbox, modal, poll, tabs, toast, tooltip, wizard. The widget: type names it as well - {widget:modal 'terms'} - and so does the bare name, {modal 'terms'}, after every other kind of tag: a store, a field or an array of the name wins.
first
The widget's own first parameter, the second of {widget}: the name of a modal, a drawer or a poll, the text of a copy box, the title of a toast, the button of a dropdown, the tip of a tooltip.

Options

active
tabs, wizard: the tab or step shown first, by its number from 1 or its label.
single
Bare option, accordion: one item open at a time.
open
accordion: the item open at first, by its number or its label; bare, every item.
label
carousel, lightbox, wizard, breadcrumb: the name for a screen reader; copy: the button's text.
title
modal, drawer: the heading that names the dialog; poll: the question.
button
modal, drawer: the text of the button that opens it (Open); poll: the vote button.
side
drawer: right (the default), left or bottom.
align
dropdown: start (the default) or end - the menu's edge under the button's.
place
tooltip: top or bottom; toast: inline, top or bottom - in the flow, or in that corner of the window.
tone
toast: info, success, warning or error.
timeout
toast: seconds, 1 to 600, after which it closes by itself, which its script does.
next
wizard: the text of the Next button (Next).
back
wizard: the text of the Back button (Back).
options
poll: the answers, separated by commas - two or more.
results
Bare option, poll: the results to everyone, also before a vote.
home
breadcrumb: the first step's text when the trail is the page's path (Home).
data
breadcrumb: the steps from rows - their label and link fields - of a store, the page's array or a _data file.

Description

{widget} puts an interactive part on the page - tabs, an accordion, a carousel, a wizard, a lightbox, a modal, a drawer, a dropdown, a tooltip, a toast, a copy box, a poll, a breadcrumb. Every one is built on the server and works without JavaScript: radio buttons and CSS, <details>, <dialog>, the popover attribute, :target. Where a widget has a script it only makes it handier - Escape, the arrow keys, the focus - and is written once per page, with the CSP nonce. Every widget is a file of pad/widgets/types/, its functions in pad/widgets/_lib/, its style and script in pad/widgets/assets/; the files of types/ are the widgets there are.

A widget is written three ways, the same widget each time: the tag with the widget's name, {widget 'modal', 'terms'}, whose second parameter is the widget's own first; the widget: type, {widget:modal 'terms'}; and the bare name, {modal 'terms'}. The bare name comes after every other kind of tag, so a store, a field or an array of the name wins - a page's $tabs array is the data of {tabs}. Two names stay built-in tags: {copy}, as PHP has a copy() function a bare name would reach first, and {tab}, the item of the widgets that take a list of labelled parts - tabs, accordion, carousel, wizard and lightbox.

  • tabs - panels behind a row of tabs: a radio button and a label per tab, the arrow keys move between them, printed every panel shows. accordion - every item a <details>; single one open at a time. carousel - slides that scroll and snap sideways, links to the slides before and after, a dot per slide, no autoplay. wizard - steps one at a time, numbered above, Back and Next under each. lightbox - thumbnails whose picture opens large over the page.
  • modal - a <dialog> and its button, opened by the invoker commands, a script where the browser has none, or a :target link without scripting. drawer - the same along the side of the window.
  • dropdown - a menu under a button, a popover the browser opens, closes and places. tooltip - a tip on hover and focus, by CSS; Escape hides it. toast - a notice in an open <dialog> whose button closes it by an invoker command, a script where the browser has none - no form of its own, so it stands inside a form too; timeout= closes it by itself.
  • copy - a text and a copy-to-clipboard button. poll - a vote once per visitor, the results as bars. breadcrumb - the trail from home to the page, from the page's path, the lines of a pair or data=.

The colours are custom properties on .pad-<widget> - --pad-tabs-accent, --pad-toast-success ... - with light-dark() defaults, so a page of color-scheme: light dark gets the dark ones in dark mode. A name that is no widget, an option a widget does not know and a widget without what it needs - a name, a label, a tab - are errors under the strict check. The poll's examples are shown but not run: what it shows depends on the votes and the visitor's session.

Three ways to write one

The widget tag, the widget: type and the bare name - the same toast each time.

Templateexamples/widget/0-forms.pad 
{widget 'toast', 'The widget tag', tone='success'}{open/}widget 'toast', 'The widget tag'{close/} - the second parameter is the toast's title.{/widget}
{widget:toast 'The widget: type'}{open/}widget:toast 'The widget: type'{close/}{/widget:toast}
{toast 'The bare name', tone='warning'}{open/}toast 'The bare name'{close/} - when no store, field or array has the name.{/toast}

A FAQ, one open at a time

single makes opening one question close the other; open=1 opens the first.

Templateexamples/widget/accordion-1-faq.pad 
{accordion single, open=1}
  {tab 'When will my order arrive?'}
    <p>Orders placed before 22:00 on a working day are delivered the next day.</p>
  {/tab}
  {tab 'Can I return something?'}
    <p>Yes - within 30 days, unused and in its box.</p>
  {/tab}
  {tab 'Is there a warranty?'}
    <p>Two years on every appliance.</p>
  {/tab}
{/accordion}
Resultopen alone

All open, from data

A bare open opens every item; the items come from a loop.

Templateexamples/widget/accordion-2-all-open.pad 
{accordion open}
  {steps}
    {tab $step}<p>{$detail}</p>{/tab}
  {/steps}
{/accordion}
