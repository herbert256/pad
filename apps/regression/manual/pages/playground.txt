<p>The <a href="http://localhost/pad/playground/">playground</a> is an application for trying templates:
type a template and its data - JSON, YAML, XML or CSV, its type recognised on sight as the
data tag recognises it, a record's keys becoming variables and a list the variable
<code>rows</code>, or, switched with the button beside it, PHP code written as a page's
<code>.php</code> - and the result shows beside it. The address bar always holds both, so a link shares the example.</p>

<p>It renders the way a page's PHP can render any PAD source, with <code>padCode()</code>:</p>

<p>Because it runs what it is given, the playground answers this machine only, and a template
there may not call PHP functions, sees no request values and no database, and gets five
seconds, 64 KB of source and 256 KB of output. The output shows in a sandboxed frame, where
the rendered page's scripts run in an origin of their own, out of reach of the playground. Tags that read files or fetch URLs still work - on
this machine, for its own user - and the PHP code of the data runs as written.</p>
